# 门户改成「工作台壳」：左栏常驻 + 单列卡片 + 朱色降为内容语义色

Status: accepted

用户原话：「首页像宣传页，入口要滚才点到」「模仿这个 UI」「重新设计一下本项目的 UI」，参照对象是一台本地部署的 MyHOT（`http://10.6.2.241:9527/`）。于是把门户从「标语 hero + 编号入口行」改成常驻左栏 + 单列卡片的工作台壳，并把这套壳推到全站。

## Context

- 现状：`index.html` 2204 行、CSS 全内联；第一屏是 30px 级大标题 hero，11 个模块入口排在下方，1440×900 下要滚 1.5 屏才看全。
- 参照站实测（1440×900）：左栏 180px（项高 40px / 字号 14px / 图标 17px / 圆角 8px），正文区**无 max-width**（内容 x=208→1412），文章卡标题 17px/650、摘要 15px/1.75 两行。
- `ADR-0002` 当年明确否决「样张 D 侧栏工作台」，理由是会把 7 个模块降成二级入口、与「语言学习仍是主场」不符。本次**推翻该结论**：站点定位已从「JLPT 学习站」转为「个人工作台」（见 `ADR-0007`），而痛点恰恰是入口拿不到手。
- 硬约束不变：零构建、`file://` 优先（禁 `fetch`）、无外部依赖、行尾 LF、生成物不手改。

## Decision

### 结构

1. **左栏两层常显**：4 个区（语言学习 / 调查报告 / 工具开发 / 斯诺克信息）+ 语言学习区内 11 个模块（日 7 / 英 4）。「语言学习」是 `<details>` 分组，默认展开、可折叠，折叠后只剩 4 个区。
2. 左栏底部：外观三档（浅色/护眼/深色）+ 关于 / 更新日志 / 反馈，三者**全外链 GitHub**（不新建页面）。
   外观控件照参照站做成 **三格 `radiogroup` + 14px 图标（太阳/眼睛/月亮）+ 滑动指示块**，`sr-only` 文字留给读屏；   56px 图标条里竖排、展开后横排。PDF 导出按钮是「动作」不是「环境」，单独留在右上角。
3. **去掉 hero**，第一屏直接模块卡片列表。
4. **去掉 `data-lang` 整根轴**：不再有日本語/English 开关，主区用「日本語 / English」两个分组小标题；`<title>` 与 `#paths` / `#en-paths` 锚点一并整理。`localStorage` 的 `jlpt-lang` 键废弃但**不清除**（读到即忽略），避免老用户报错。
5. 顶栏 = 区名 + 模块类型标签筛选（全部/资料/词汇/听力/真题/练习/工具）+ 搜索框外观（**不接数据**，真检索另立票）+ `/` 快捷键提示；高 48px。
6. N5–N1 级别条 → 卡片内嵌 chip 行；77 个英语词表单元 + 30 篇阅读**留在门户、折叠收起**（`data-en-key` 107 项不搬家，`en-accept.mjs` 门禁不动）。
7. 子页（单元页 / 做题页 / 阅读页）：左栏收成 **56px 图标条**，展开为 184px **浮层**（不挤压正文），支持 hover / `focus-within` / 点击 QY 钉住三种展开。

### 卡片

8. **行序照 MyHOT**：首行「元信息 + 能力 pill」→ 标题（17px/650）→ 摘要（14.5px/1.6，2 行）→ chip 行；右侧独立指标栏（168px，垂直居中右对齐）。
9. 右栏 = 进度胶囊（`已看 42/168`，内层填充即完成比例）+「继续 N3 · 第 12 课 →」+「导出进度」。「继续」由 `done` 时间戳 + 单元清单推导最近完成项，**不新增存储字段、不造收藏这类新状态**。
10. 窄屏 ≤760px：右栏落到卡底横排，加一条分隔线。

### 视觉

11. 暖白 `#faf9f6` + 深青 `#176b75` 接管交互；**朱色降为内容语义色**，只留【済】章与和纸 PDF 朱线，favicon 底色改深青。
12. 三主题保留（浅色/护眼/深色），**默认从护眼改浅色**。护眼主题 accent 用 `#145f68`（`#176b75` 在绿底只有 4.39，不达 AA）。
13. 全站 sans；serif 只留品牌 QY 与【済】章。字号阶照第 8 条实测值。
14. 左栏补 6 个新线描图标，由 `.scratch/icons/gen-icon-css.mjs` 生成 `--ic-*`（`ADR-0005` 禁止手写 data URI）。

### 工程

15. **范围 = 全站**：门户、168 个手写单元页、9 份子应用 CSS、6 个生成器模板、4 份报告（含正文排版）。
16. 左栏/顶栏 **内联同一份 markup**（不用脚本注入，避免关 JS 无导航与首屏闪烁）；168 个手写页由入库的 `tools/rail.mjs gen|check` 写入，并加一条「全仓左栏块逐字节一致」check。
17. 六个生成器的壳抽成单一真源 `tools/shell.mjs`（head 片段 / 左栏 / 顶栏 / 令牌），`en-vocab`、`en-reading`、`research`、`pi-changelog-gen`、`jp-vocab/gen`、`verb/gen` 都 import。
18. 报告正文排版统一在 `SHELL_CSS` 的 `.prose` 里定义，`pi-changelog-gen.mjs` 跟着重跑。
19. 迁移批次：**令牌 → 生成器 → 门户 → 子应用**；每步跑 `node tools/test.mjs` 全绿再进下一步。

## Considered Options

- **只换皮（不搬左栏）**：否决——用户主痛点是入口拿不到手，换色不解决。
- **左栏只放 4 个区 / 扁平模块清单**：否决——7 个模块仍需回主区找，且四区的区分被抹平。
- **全部 180px 常驻（子页也用）**：否决——听力/打字/真题的中心交互区会被挤掉，长读正文也变窄。
- **56px 条用脚本注入（单一真源）**：否决——关 JS 无导航、首屏闪烁，且要处理 1–3 层相对路径；改由 `tools/rail.mjs` 写入内联 markup + 一致性 check 兜底。
- **双列卡片墙（一屏 10 张）**：样张里试过，信息密度最高，但偏离 MyHOT 的单列信息流，且长描述会把行撑乱。
- **卡内加竖线分栏**：样张里试过，视觉更「有骨架」，但 1180px 宽的卡被竖线切成两半后读起来像表格，最终取「无竖线的右栏」。
- **每个生成器各自内联壳**：否决——历史上 favicon 就因常量抄两份而 110 页集体停在旧标记（见 `ADR-0005`）。

## Consequences

- **111 个 favicon 字节重生**：favicon 底色朱 → 深青，须同时改 `tools/brand.mjs`、`index.html` head、`tools/research.mjs` 的 `SHELL_*`，再跑 `add-shell`；`tools/tests/icon-set.js` 逐字节比对会立刻抓到漏改。
- **`data-lang` 移除**会动 `<title>`、两个锚点与 head 内状态机（约 90 行）；`jlpt-lang` 键废弃不清除。
- **`progress.js` 的 `boot()`** 在门户直接跳过；要让进度胶囊与「继续」生效需扩它或新增 `assets/portal.js`，并由新生成器 `tools/portal.mjs gen|check` 产出 `assets/units.js`（`window.WB_UNITS`，含 path/title/module）。
- **318 页 `<link>` + 16 页内联 `<style>`**：令牌换色牵动 9 份 CSS（`assets/style.css` 1042 行 + `en/reader.css` 623 + `en/unit.css` 576 + `jp-vocab/vocab.css` 516 + `typing/typing.css` 467 + `dictation/dictation.css` 432 + `listening/listening.css` 319 + `exam/exam.css` 282 + `verb/vocab.css` 74），逐份核对硬编码色值。
- **`data-en-key` 107 项**折叠进 `<details>` 后 DOM 仍在，但两个英语生成器的写入位置要跟着改标记区。
- **新增三条 check**（进 `tools/test.mjs`）：① 全仓左栏/顶栏块逐字节一致；② 新 CSS 不得出现裸色值（必须走令牌）；③ 三主题关键前景/背景对比度 ≥ AA。
- `ADR-0005` 的品牌标记、图标集、`--ic-*` 生成规则**继续有效**；`ADR-0002` 被本 ADR 取代并标 superseded。
- 样张与设计依据留在 `.scratch/ui-redesign/`（不入库）：`sample.html` / `sample-sub.html` + 9 张截图 + `README.md`（22 条定案与 MyHOT 实测表）。
