知识点详解

1动词三分类复习与五段陷阱词

【讲解】日语动词按活用分为五段、一段、サ变、カ变。不是所有「る」结尾都是一段：先看「る」前一拍是否在い段或え段；若不是，通常是五段。即使前一拍在い/え段，也有固定陷阱词要按五段记。

判断法：不以「る」结尾多为五段；「る」前为あ・う・お段多为五段；「る」前为い・え段时，再排除陷阱词。

知しる・切きる・帰かえる・入はいる・走はしる・要いる・喋しゃべる・滑すべる は五段です。

这些虽然容易被误判为一段，但都按五段活用。

今日きょうは早はやく帰かえります。

今天早点回去。

注意：「見みる」「起おきる」「食たべる」是一段；「走はしる」「帰かえる」是五段。

【讲解】先横向看同一个动词，再纵向比较同类词尾。五段动词的核心是词尾在あ・い・う・え・お段之间移动；一段动词多为去「る」后接固定词尾；「する」「来る」需要单独记。

3て形・た形的音便规则总结

【讲解】五段动词接「て/た」时常发生音便，按词尾记最快。く多变いて，ぐ变いで；う・つ・る变って/った；ぬ・ぶ・む变んで/んだ；す不音便，直接して/した。

イ音便：書かく → 書かいて、泳およぐ → 泳およいで
促音便：待まつ・買かう・乗のる → って／った
拨音便：死しぬ・遊あそぶ・読よむ → んで／んだ

昨日きのう、駅えきまで走はしった。

昨天跑到了车站。

特例：行いく → 行いって；「す」结尾如 話はなす → 話はなして。

4可能・受身・使役形态对照与一段「られる」歧义

【讲解】五段可能用え段＋る，受身用あ段＋れる，使役用あ段＋せる；一段动词去「る」后接られる、られる、させる，所以可能和受身在形态上会重合，需要靠上下文判断。

分类可能受身使役例子
五段え段＋るあ段＋れるあ段＋せる読よめる／読よまれる／読よませる
一段去る＋られる去る＋られる去る＋させる見みられる／見みられる／見みさせる
するできるされるさせる勉強べんきょうできる／勉強べんきょうされる／勉強べんきょうさせる

この映画えいがは家いえで見みられる。

这部电影可以在家看。

有名ゆうめいな人ひとに見みられた。

被有名的人看见了。

注意：見みられる 可以是「被看」也可以是「能看」。口语里常听到ら抜き「見みれる」，多表示可能；正式学习和写作仍建议掌握「見みられる」。

5活用记忆技巧

【讲解】五段动词可以把最后一个假名放进五十音表观察：い段接ます，あ段接ない・れる・せる，え段接ば・命令・可能，お段接う表意向。这样比逐个死背更容易形成系统。

あ段：書かかない／書かかれる／書かかせる
え段：書かける／書かけば／書かけ
お段＋う：書かこう、読よもう、乗のろう

明日あした、いっしょに図書館としょかんへ行いこう。

明天一起去图书馆吧。

小技巧：一段动词先去「る」：食たべない、食たべられる、食たべさせる、食たべよう。

✏ 自测练习

1「帰かえる」の分類はどれですか。

  1. 1一段
  2. 2五段
  3. 3サ変
  4. 4カ変
答案与解析

正确答案：2（五段）

「帰かえる」是常见陷阱词，虽以「える」结尾，仍按五段活用。【译文】「帰る」属于哪一类？

2毎日まいにち日記にっきを（　　）。

  1. 1書かいて
  2. 2書かって
  3. 3書かんで
  4. 4書かして
答案与解析

正确答案：1（書かいて）

「書かく」是く结尾五段，て形为イ音便「書かいて」。【译文】每天写日记。

3「読よむ」の可能形はどれですか。

  1. 1読よまれる
  2. 2読よませる
  3. 3読よめる
  4. 4読よもう
答案与解析

正确答案：3（読よめる）

五段可能形是え段＋る，所以「む」变「める」。【译文】「読む」的可能形是哪一个？

4先生せんせいが学生がくせいに本ほんを（　　）。

  1. 1読よめる
  2. 2読よまれる
  3. 3読よませる
  4. 4読よもう
答案与解析

正确答案：3（読よませる）

「老师让学生读书」要用使役形。五段「読む」的使役是あ段＋せる，即「読よませる」。【译文】老师让学生读书。

5「見みられる」について正しい説明はどれですか。

  1. 1只能表示命令
  2. 2只能表示过去
  3. 3可能和受身都可以表示
  4. 4一定是サ変
答案与解析

正确答案：3（可能和受身都可以表示）

一段动词「見みる」的可能形和受身形都可写作「見みられる」，要看上下文。【译文】关于「見られる」，正确说明是哪一个？
