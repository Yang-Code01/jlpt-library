N4 基础 · 01 汉字音读规律进阶

从声旁、韵尾和音变入手，把零散的音读记忆整理成可预测的线索。

本单元共 5 个知识点，单元末附自测练习。

1 声旁推读原理2 中文韵尾对应3 吴音与汉音4 二字熟语音便5 N4 常见多音字✏ 自测练习

知识点详解

1声旁推读原理：形声字的音读线索

【讲解】很多汉字由表示意义的部件和提示读音的声旁组成。看到同一声旁家族时，可以先猜一个常见音读，再用词汇确认。它不是百分百规则，但能大幅减少死记硬背。

声旁常见音读例词记忆提示
青セイ・ショウ晴天せいてん、清潔せいけつ、精算せいさん「青」旁常提示 セイ。
生セイ・ショウ学生がくせい、生活せいかつ、一生いっしょうセイ 多见，ショウ 常见于固定词。
交コウ学校がっこう、効果こうか、郊外こうがい「交」系多读 コウ。
司シ司会しかい、品詞ひんし、飼育しいく司、詞、飼在音读中常靠近 シ。
工コウ工場こうじょう、成功せいこう、攻撃こうげき不要把所有含「工」的字都套成 コウ。
可カ可能かのう、河川かせん、許可きょか可旁常提示 カ。
寺ジ・シ時間じかん、持参じさん、詩人しじん浊化后的 ジ 很常见。
反ハン反対はんたい、販売はんばい、出版しゅっぱん反、販、版常连到 ハン。
注意：声旁只能用来“猜读音”，不能替代查词；遇到常用词请按整词记忆。

2中文韵尾对应规律：从尾音猜日语音读

【讲解】音读保留了古汉语的一些尾音痕迹。现代中文普通话的 -n、-ng 以及古入声 -k/-t/-p，有时能对应到日语的 ン、长音、く/き、つ/ち、う长音化。

中文线索日语倾向例字说明
-nン安アン、三サン、本ホン鼻音尾常转为拨音 ン。
-ng长音中チュウ、京キョウ、明メイ常见为 う/い 表示的长音。
入声 -kく・き学ガク、力リョク、駅エキ短促收尾常保留为 k 行音。
入声 -tつ・ち一イチ、八ハチ、日ニチ常表现为 つ 或 ち。
入声 -pう长音化十ジュウ、入ニュウ、合ゴウ不少字在现代音读中变成长音。
辨析：这些对应关系适合辅助记忆，不适合直接造读音；同一个汉字还可能有吴音、汉音或惯用音。

3吴音 vs 汉音：同一汉字为什么有两套音读

【讲解】吴音较早传入日本，常保存在佛教、古典和生活化词中；汉音较晚传入，常见于制度、学术和一般汉语词。N4 阶段只需认识常见对比，不必系统追溯来源。

汉字吴音倾向汉音倾向例词
行ギョウコウ行列ぎょうれつ、銀行ぎんこう、旅行りょこう
明ミョウメイ明日みょうにち、説明せつめい、明確めいかく
京キョウケイ京都きょうと、京阪けいはん

京都きょうとへ旅行りょこうします。

我要去京都旅行。

注意：佛教词里常见吴音，如 経きょう、行事ぎょうじ；考试中按词记忆最稳。

4二字熟语音便：促音化与连浊

【讲解】两个汉字合成词时，前后音节相遇会变得更顺口。常见现象是促音化（小っ）和连浊（后项清音变浊音）。这些变化会影响听力和拼写，需要整词记住。

促音化：学がく＋校こう → 学校がっこう、一いち＋回かい → 一回いっかい、出しゅつ＋発はつ → 出発しゅっぱつ
连浊：時々ときどき、人々ひとびと、株式会社かぶしきがいしゃ、手紙てがみ

学校がっこうで手紙てがみを出だしました。

我在学校寄出了信。

注意：不是所有复合词都会音变；先把高频词作为整体读音背熟。

5N4 常见多音字表

【讲解】N4 阅读中常遇到同一汉字在不同词里读音不同。判断时先看词性、是否有送假名、是否是二字熟语，再结合固定搭配确认。

汉字常见读音例词提示
上うえ・あ・ジョウ上うえ、上あがる、屋上おくじょう方位多训读，熟语多音读。
下した・さ・カ・ゲ下した、下さげる、地下鉄ちかてつ、上下じょうげ送假名要拆出。
外そと・はず・ガイ外そと、外はずす、外国がいこく动作词常用训读。
間あいだ・ま・カン間あいだ、時間じかん、人間にんげん「人間」读 にんげん。
分わ・フン・ブン分わかる、三分さんぷん、自分じぶん分钟读法会有促音、半浊音。
通とお・かよ・ツウ通とおる、通かよう、交通こうつう两个常见训读意义不同。
重おも・かさ・ジュウ重おもい、重かさねる、体重たいじゅう形容词和动词读法不同。
楽たの・ラク・ガク楽たのしい、楽らくな、音楽おんがく「楽な」是 な形容词。

✏ 自测练习

1声旁「青」常提示哪个音读？

  1. 1セイ
  2. 2カン
  3. 3トウ
  4. 4ハク
答案与解析

正确答案：1（セイ）

如 清潔せいけつ、精算せいさん 都可用「青」旁辅助记忆。

2「中チュウ」「京キョウ」体现了哪类对应？

  1. 1-n → ン
  2. 2-ng → 长音
  3. 3入声 -t → ち
  4. 4训读固定读法
答案与解析

正确答案：2（-ng → 长音）

普通话 -ng 尾的字，在日语音读中常见 う/い 表示的长音。

3哪个词的「行」读 コウ？

  1. 1行列ぎょうれつ
  2. 2銀行ぎんこう
  3. 3修行しゅぎょう
  4. 4行事ぎょうじ
答案与解析

正确答案：2（銀行ぎんこう）

「銀行」中的行读 こう；其他选项中多读 ぎょう。

4「一回いっかい」中的小っ属于什么现象？

  1. 1连浊
  2. 2促音化
  3. 3熟字训
  4. 4外来语化
答案与解析

正确答案：2（促音化）

一＋回读作 いっかい，小っ让发音更短促清晰。

5「通かよう」的 ruby 标法为什么正确？

  1. 1送假名「う」拆在 ruby 外
  2. 2假名词必须注音
  3. 3整词都必须放进 ruby
  4. 4它是片假名词
答案与解析

正确答案：1（送假名拆出）

送假名必须拆出，所以写 通かよう，而不是把「通う」整体注音。
