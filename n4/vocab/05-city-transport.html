自测练习

1「空港くうこう」的正确意思是？

  1. 1港口
  2. 2机场
  3. 3停车场
  4. 4会场
答案与解析

正确答案：2（机场）

「空港」读作「くうこう」，意思是机场。

2次つぎの駅えきで（　　）。

  1. 1乗のり換かえます
  2. 2迎むかえます
  3. 3泊とまります
  4. 4戻もどります
答案与解析

正确答案：1（乗り換えます）

在车站换乘用「乗り換える」。【译文】在下一站换乘。

3「田舎いなか」的读音是？

  1. 1とかい
  2. 2こうがい
  3. 3いなか
  4. 4しない
答案与解析

正确答案：3（いなか）

「田舎」是熟字训，整词读作「いなか」，意思是乡下。

4車くるまを（　　）に止とめます。

  1. 1美術館びじゅつかん
  2. 2駐車場ちゅうしゃじょう
  3. 3横断歩道おうだんほどう
  4. 4市役所しやくしょ
答案与解析

正确答案：2（駐車場）

停车的地方是「駐車場」。【译文】把车停在停车场。

5「真まん中なか」是什么意思？

  1. 1外侧
  2. 2角落
  3. 3正中间
  4. 4背面
答案与解析

正确答案：3（正中间）

「真ん中」表示正中央、正中间。
