自测练习

1「梅雨つゆ」的正确意思是？

  1. 1台风
  2. 2梅雨季
  3. 3彩虹
  4. 4雾
答案与解析

正确答案：2（梅雨季）

「梅雨」读作「つゆ」，指初夏连续下雨的梅雨季。

2夜よる、星ほしが（　　）。

  1. 1光る
  2. 2植える
  3. 3育てる
  4. 4濡れる
答案与解析

正确答案：1（光る）

星星会发光，所以用「光る」。【译文】夜里，星星发光。

3「地震じしん」的正确读音是？

  1. 1たいふう
  2. 2じしん
  3. 3しぜん
  4. 4きおん
答案与解析

正确答案：2（じしん）

「地震」读作「じしん」，意思是地震。

4休日きゅうじつに友達ともだちと（　　）に行いきます。

  1. 1湿度
  2. 2花見
  3. 3根
  4. 4霧
答案与解析

正确答案：2（花見）

「花見に行く」表示去赏花。【译文】假日和朋友去赏花。

5「乾かわく」的正确意思是？

  1. 1干；干燥
  2. 2摇晃
  3. 3凋谢
  4. 4鸣叫
答案与解析

正确答案：1（干；干燥）

「乾く」读作「かわく」，表示东西变干。
