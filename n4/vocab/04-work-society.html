✏ 自测练习

1「給料きゅうりょう」的正确读音是？

  1. 1きゅうりょう
  2. 2きょうりょう
  3. 3きゅりょう
  4. 4ぎゅうりょう
答案与解析

正确答案：1（きゅうりょう）

「給料」读作「きゅうりょう」，意思是工资。

2銀行ぎんこうに（　　）ています。

  1. 1勤め
  2. 2届け
  3. 3輸入し
  4. 4嘘をつい
答案与解析

正确答案：1（勤め）

表示在某处任职用「～に勤めています」。【译文】在银行工作。

3「無料むりょう」的正确意思是？

  1. 1工资
  2. 2免费
  3. 3税金
  4. 4价格
答案与解析

正确答案：2（免费）

「無料」表示不需要费用、免费。

4警察けいさつが（　　）を探さがします。

  1. 1犯人
  2. 2会議室
  3. 3給料
  4. 4名刺
答案与解析

正确答案：1（犯人）

「犯人を探します」表示寻找犯人。【译文】警察寻找犯人。

5外国がいこくから品物しなものを（　　）します。

  1. 1輸入
  2. 2輸出
  3. 3出張
  4. 4会議
答案与解析

正确答案：1（輸入）

从国外买进物品是「輸入する」。【译文】从国外进口商品。
