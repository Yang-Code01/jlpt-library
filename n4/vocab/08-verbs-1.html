自测练习

1雪ゆきの道みちで（　　）ました。

  1. 1滑すべり
  2. 2包つつみ
  3. 3比くらべ
  4. 4飾かざり
答案与解析

正确答案：1（滑すべり）

「滑すべる」表示打滑、滑倒。【译文】在雪地路上滑倒了。

2「増ふえる」的正确词性是？

  1. 1一段自
  2. 2一段他
  3. 3五段自
  4. 4五段他
答案与解析

正确答案：1（一段自）

「増ふえる」是自动词，表示数量自然增加。

3荷物にもつを駅えきに（　　）。

  1. 1預あずけます
  2. 2濡ぬれます
  3. 3決きまります
  4. 4逃にげます
答案与解析

正确答案：1（預あずけます）

「預あずける」表示把东西寄存或托付给别人。【译文】把行李寄存在车站。

4「見みつかる」的意思是？

  1. 1被找到
  2. 2弄坏
  3. 3发胖
  4. 4涂抹
答案与解析

正确答案：1（被找到）

「見みつかる」是自动词，常说「鍵かぎが見みつかる」。

5古ふるい電池でんちを（　　）ます。

  1. 1取とり替かえ
  2. 2倒たおれ
  3. 3眠ねむり
  4. 4下さがり
答案与解析

正确答案：1（取とり替かえ）

「取とり替かえる」表示更换。【译文】更换旧电池。
