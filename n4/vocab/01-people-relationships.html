✏ 自测练习

1「祖母」的正确读音是？

  1. 1そふ
  2. 2そぼ
  3. 3まご
  4. 4おや
答案与解析

正确答案：2（そぼ）

「祖母」读作「そぼ」，意思是祖母或外祖母。

2先輩せんぱいに（　　）します。

  1. 1相談
  2. 2誕生
  3. 3成人
  4. 4孫
答案与解析

正确答案：1（相談）

向前辈商量时说「先輩に相談します」。【译文】向前辈商量。

3「優しい」的意思是？

  1. 1严格
  2. 2寂寞
  3. 3温柔
  4. 4遗憾
答案与解析

正确答案：3（温柔）

「優しい」表示温柔、和善。

4姉あねは来月らいげつ（　　）します。

  1. 1結婚
  2. 2血
  3. 3講義
  4. 4下敷き
答案与解析

正确答案：1（結婚）

人生大事中，「結婚する」表示结婚。【译文】姐姐下个月结婚。

5「お客様」的正确意思是？

  1. 1前辈
  2. 2客人（敬称）
  3. 3儿子
  4. 4梦想
答案与解析

正确答案：2（客人（敬称））

「お客様」是对客人的礼貌说法。
