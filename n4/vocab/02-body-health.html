自测练习

1「喉」的正确读音是？

  1. 1くび
  2. 2のど
  3. 3こし
  4. 4むね
答案与解析

正确答案：2（のど）

「喉」读作「のど」，意思是喉咙。

2熱ねつがあるので（　　）へ行いきます。

  1. 1薬局
  2. 2講堂
  3. 3親戚
  4. 4黒板
答案与解析

正确答案：1（薬局）

发烧时去药局或医院处理，这里应选「薬局」。【译文】因为发烧，所以去药店。

3「退院」的意思是？

  1. 1住院
  2. 2出院
  3. 3午睡
  4. 4烫伤
答案与解析

正确答案：2（出院）

「退院」表示从医院出院。

4食たべすぎると（　　）ます。

  1. 1太り
  2. 2折れ
  3. 3眠り
  4. 4冷え
答案与解析

正确答案：1（太り）

「太る」表示发胖。【译文】吃太多会发胖。

5「怪我」的正确意思是？

  1. 1受伤
  2. 2睡眠
  3. 3肩膀
  4. 4接待处
答案与解析

正确答案：1（受伤）

「怪我」读作「けが」，意思是受伤或伤。
