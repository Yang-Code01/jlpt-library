✏ 自测练习

1家賃やちんを（　　）払はらいます。

  1. 1毎月
  2. 2鏡
  3. 3畳
  4. 4味噌
答案与解析

正确答案：1（毎月）

「家賃を毎月払います」表示“每个月付房租”。【译文】每个月付房租。

2「布団ふとん」的正确意思是？

  1. 1毛线
  2. 2被褥
  3. 3屋顶
  4. 4煤气
答案与解析

正确答案：2（被褥）

「布団」读作「ふとん」，指日式被褥或铺盖。

3お湯ゆを（　　）してください。

  1. 1冷房
  2. 2沸かして
  3. 3下宿
  4. 4指輪
答案与解析

正确答案：2（沸かして）

「沸かす」是他动词，表示把水烧开。【译文】请把热水烧开。

4「忘わすれ物もの」的读音是？

  1. 1わすれもの
  2. 2わかもの
  3. 3しょくりょうひん
  4. 4ようじ
答案与解析

正确答案：1（わすれもの）

「忘れ物」读作「わすれもの」，表示遗忘的东西或遗失物。

5旅行りょこうの（　　）を始はじめます。

  1. 1袖
  2. 2天井
  3. 3支度
  4. 4漬物
答案与解析

正确答案：3（支度）

「旅行の支度」表示“旅行的准备”。【译文】开始准备旅行。
