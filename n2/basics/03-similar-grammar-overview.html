N2 基础 · 03 近义语法辨析总览

把 N2 最容易混淆的近义句型放在同一视野中，对比意义、接续、语感和例句。

本单元共 12 个知识点，单元末附自测练习。

1 时机表达2 结果表达3 原因评价4 条件范围5 依据表达6 变化伴随7 不得不8 负面可能9 强烈感情10 忠告与常理11 断定表达12 同时与对比✏ 自测练习

知识点详解

1〜に際して／〜にあたって／〜折に／〜際に

【讲解】四者都表示“在……之际”。「に際して」正式，强调重要时点；「にあたって」多用于开始做大事前；「折に」带客气书信语感；「際に」最中性。

接续：动词辞书形／名词＋に際して・にあたって・際に；动词辞书形／た形／名词の＋折に
句型意义接续语感例句
に際して在重要时点辞书形/名词正式书面契約けいやくに際さいして、条件じょうけんを確認かくにんします。
签约之际确认条件。
にあたって开始做大事前辞书形/名词郑重出発しゅっぱつにあたって、安全あんぜんを祈いのります。
出发之际祈愿安全。
折に趁某机会辞书形/た形/名词の客气近ちかくへお越こしの折おりにお寄よりください。
您来附近时请顺便来坐坐。
際に在……时辞书形/名词中性入室にゅうしつする際さいに名札なふだを見みせてください。
进入房间时请出示名牌。

2〜た末に／〜たあげく

【讲解】二者都表示经过一番过程后的结果。「た末に」结果可好可坏，强调长时间努力后的最终结论；「たあげく」多为负面结果，带“折腾到最后竟然”的语气。

接续：动词た形／名词の＋末に・あげく
句型意义接续语感例句
た末に经过……之后终于た形/名词の中性，重过程何度なんども話はなし合あった末すえに、結論けつろんが出でました。
多次商量后得出了结论。
たあげく折腾到最后却た形/名词の多负面悩なやんだあげく、何なにも決きめられませんでした。
苦恼到最后什么也没决定。

3〜ばかりに／〜だけに／〜おかげで／〜せいで

【讲解】这组都与原因和评价有关。「ばかりに」强调正因某一点导致坏结果；「だけに」表示正因为如此更……；「おかげで」多为好结果；「せいで」多为坏结果。

接续：普通形＋ばかりに・だけに・おかげで・せいで；名词常接 の 或 で
句型意义接续语感例句
ばかりに只因……而坏结果普通形遗憾一言ひとこと余計よけいなことを言いったばかりに、彼かれを怒おこらせました。
只因多说了一句话，惹他生气了。
だけに正因为……更普通形/名词评价加强期待きたいしていただけに、失望しつぼうも大おおきいです。
正因为期待过，所以更失望。
おかげで多亏……普通形/名词の感谢，正面先生せんせいのおかげで合格ごうかくできました。
多亏老师，我通过了考试。
せいで由于……害得普通形/名词の责怪，负面雨あめのせいで試合しあいが中止ちゅうしになりました。
因为下雨，比赛取消了。

4〜を問わず／〜にかかわらず／〜はともかく

【讲解】「を問わず」表示不问类别差异；「にかかわらず」表示不受条件影响；「はともかく」表示先把某事放一边，后项才是重点。

接续：名词＋を問わず；名词/普通形＋にかかわらず；名词＋はともかく
句型意义接续语感例句
を問わず不问……名词正式列举范围年齢ねんれいを問とわず参加さんかできます。
不论年龄都能参加。
にかかわらず不管……都名词/普通形条件不影响天候てんこうにかかわらず実施じっしします。
不论天气如何都实施。
はともかく……暂且不论名词转入重点値段ねだんはともかく、品質ひんしつは良よいです。
价格暂且不说，品质很好。

5〜に基づいて／〜をもとに／〜に沿って

【讲解】三者都可译为“根据”。「に基づいて」根据事实、数据、法律；「をもとに」以素材或原型为基础再加工；「に沿って」按方针、路线、说明推进。

接续：名词＋に基づいて／をもとに／に沿って
句型意义接续语感例句
に基づいて基于依据名词客观正式資料しりょうに基もとづいて判断はんだんします。
根据资料判断。
をもとに以……为素材名词可再创作実話じつわをもとに映画えいがが作つくられました。
电影以真实故事为基础制作。
に沿って按照路线/方针名词顺着既定方向計画けいかくに沿そって作業さぎょうを進すすめます。
按照计划推进工作。

6〜に従って／〜に伴って／〜につれて／〜とともに

【讲解】这组表示变化伴随。「に従って」随某基准变化或遵从；「に伴って」正式表示伴随发生；「につれて」强调一方变化另一方自然变化；「とともに」可表示同时、一起、伴随。

接续：动词辞书形／名词＋に従って・につれて；名词/动词辞书形＋に伴って・とともに
句型意义接续语感例句
に従って随着/按照辞书形/名词基准或命令年としを取とるに従したがって、体力たいりょくが落おちます。
随着年龄增长，体力下降。
に伴って伴随名词/辞书形正式人口じんこうの増加ぞうかに伴ともなって、問題もんだいも増ふえました。
随着人口增加，问题也增加了。
につれて随着自然变化辞书形/名词自然联动暗くらくなるにつれて、気温きおんが下さがりました。
随着天色变暗，气温下降了。
とともに同时/伴随名词/辞书形范围宽卒業そつぎょうとともに上京じょうきょうしました。
毕业的同时去了东京。

7〜ざるを得ない／〜ないわけにはいかない／〜よりほかない

【讲解】三者都表示没有其他选择。「ざるを得ない」客观不得不；「ないわけにはいかない」因责任、人情、社会常识不能不做；「よりほかない」只能选择某办法。

接续：动词未然形＋ざるを得ない（する→せざるを得ない）；ない形＋わけにはいかない；辞书形＋よりほかない
句型意义接续语感例句
ざるを得ない不得不未然形客观被迫台風たいふうで計画けいかくを変更へんこうせざるを得えません。
因台风不得不改变计划。
ないわけにはいかない不能不ない形责任义务上司じょうしに頼たのまれたので、断ことわらないわけにはいきません。
上司拜托了，不能不答应。
よりほかない只能辞书形别无他法証拠しょうこがないので、信しんじるよりほかありません。
没有证据，只能相信。

8〜かねない／〜おそれがある

【讲解】二者都表示可能发生坏事。「かねない」常含说话人担忧判断，接动词ます形词干；「おそれがある」更客观、正式，常见于新闻和说明文。

接续：动词ます形词干＋かねない；动词辞书形／名词の＋おそれがある
句型意义接续语感例句
かねない可能会造成坏结果ます形词干主观担忧このままでは事故じこが起おこりかねません。
这样下去可能会发生事故。
おそれがある有……危险辞书形/名词の客观正式大雨おおあめで川かわが氾濫はんらんするおそれがあります。
大雨可能导致河水泛滥。

9〜てならない／〜てたまらない／〜てしょうがない

【讲解】三者都表示感情或感觉强烈到无法抑制。「てならない」偏书面，常用于自然涌现的感情；「てたまらない」身体感觉和欲望强烈；「てしょうがない」口语，表示非常……。

接续：动词て形／い形容词て形／な形容词で＋ならない・たまらない・しょうがない
句型意义接续语感例句
てならない不由得非常て/で书面，心理将来しょうらいが不安ふあんでなりません。
对将来不安得不得了。
てたまらない……得受不了て/で强烈感觉歯はが痛いたくてたまりません。
牙疼得受不了。
てしょうがない非常……て/で口语眠ねむくてしょうがありません。
困得不得了。

10〜ものだ／〜ことだ

【讲解】「ものだ」可表示一般常理、感慨或回忆；「ことだ」多用于给对方建议，表示“最好……”。两者都可出现在句末，但功能完全不同。

接续：普通形＋ものだ；动词辞书形／ない形＋ことだ
句型意义接续语感例句
ものだ常理/感慨/回忆普通形说明规律人ひとは失敗しっぱいから学まなぶものです。
人总是从失败中学习。
ことだ最好……辞书形/ない形忠告建议健康けんこうのために、毎日まいにち歩あるくことです。
为了健康，最好每天走路。

11〜に決まっている／〜に相違ない／〜にほかならない

【讲解】三者都带断定。「に決まっている」口语感强，表示确信；「に相違ない」正式书面，表示无疑；「にほかならない」强调“正是……，不是别的”。

接续：普通形＋に決まっている・に相違ない；名词＋にほかならない
句型意义接续语感例句
に決まっている一定是普通形口语确信そんな話はなしは嘘うそに決きまっています。
那种话肯定是假的。
に相違ない必定无疑普通形正式この署名しょめいは本人ほんにんのものに相違そういありません。
这个签名无疑是本人所写。
にほかならない正是名词强调本质成功せいこうは努力どりょくの結果けっかにほかなりません。
成功正是努力的结果。

12〜ながら／〜つつ／〜一方で

【讲解】「ながら」可表示同时做两事，也可表示逆接“虽然”；「つつ」较书面，也可表示同时或逆接；「一方で」用于对比两个方面，常连接句子或名词。

接续：动词ます形词干＋ながら／つつ；普通形＋一方で；名词である＋一方で
句型意义接续语感例句
ながら一边/虽然ます形词干口语也常用音楽おんがくを聞ききながら勉強べんきょうします。
一边听音乐一边学习。
つつ一边/虽然ます形词干书面悪わるいと知しりつつ、黙だまっていました。
明知不好却沉默了。
一方で另一方面普通形/名词对比两面この町まちは便利べんりな一方いっぽうで、家賃やちんが高たかいです。
这个城市方便，但另一方面房租很高。

✏ 自测练习

1長ながい議論ぎろんの（　　）、ようやく結論けつろんが出でた。

  1. 1あげく
  2. 2末すえに
  3. 3せいで
  4. 4ものだ
答案与解析

正确答案：2（末に）

经过长时间讨论后终于得出结论，结果中性偏正面，用「末に」。 「あげく」多接负面结果。【译文】长时间讨论后终于得出了结论。

2年齢ねんれいを（　　）、だれでも参加さんかできます。

  1. 1基もとに
  2. 2問とわず
  3. 3沿そって
  4. 4つれて
答案与解析

正确答案：2（問わず）

「年齢を問わず」表示不问年龄、不论年龄。【译文】不论年龄，谁都可以参加。

3このままでは大おおきな事故じこに（　　）。

  1. 1なりかねない
  2. 2なりたがる
  3. 3なることだ
  4. 4なるものだ
答案与解析

正确答案：1（なりかねない）

「かねない」表示可能导致不好的结果，符合事故这一负面情况。【译文】这样下去可能会酿成大事故。

4先生せんせいのおかげで、試験しけんに（　　）。

  1. 1落おちました
  2. 2合格ごうかくできました
  3. 3中止ちゅうしになりました
  4. 4遅おくれました
答案与解析

正确答案：2（合格できました）

「おかげで」通常表示多亏某人某事带来好结果，所以选通过考试。【译文】多亏老师，我通过了考试。

5健康けんこうのためには、毎日まいにち少すこしでも歩あるく（　　）。

  1. 1ものだ
  2. 2ことだ
  3. 3に相違そういない
  4. 4にほかならない
答案与解析

正确答案：2（ことだ）

「動詞辞書形＋ことだ」用于建议，表示“最好……”。【译文】为了健康，最好每天多少走一走。

6悪わるいと知しり（　　）、彼かれは何なにも言いわなかった。

  1. 1つつ
  2. 2に際さいして
  3. 3をもとに
  4. 4だけに
答案与解析

正确答案：1（つつ）

「知りつつ」表示“明知……却……”，是书面逆接用法。【译文】明知不好，他却什么也没说。
