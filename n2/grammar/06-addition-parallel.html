知识点详解

1上に　「不仅～而且」

【讲解】表示在前项基础上再加上后项，多为同方向评价：好上加好或坏上加坏。语体中性，日常和商务都常用。后项通常进一步增强整体评价。

接续：动词普通形／い形容词普通形／な形容词词干＋な／名词＋の ＋ 上に

この資料しりょうは内容ないようが正確せいかくな上うえに、図ずも見みやすい。

这份资料内容准确，而且图表也容易看懂。

駅えきから遠とおい上うえに、家賃やちんも高たかい。

不仅离车站远，房租也贵。

辨析：「に加えて」客观追加；「上に」常带评价累积的语感。

2に加えて　「加上～」

【讲解】表示在既有事项之外再追加另一事项。语体正式，常用于新闻、报告和商务说明。前后项可同类，也可为相关因素的叠加。

接续：名词 ＋ に加えて；句子＋の＋に加えて

人件費じんけんひの上昇じょうしょうに加くわえて、材料費ざいりょうひも高たかくなっている。

除了人工费上涨，材料费也在变高。

会議かいぎが長引ながびいたのに加くわえて、電車でんしゃも遅おくれた。

会议拖长了，加上电车也晚点了。

辨析：「上に」多用于评价叠加；「に加えて」偏客观追加因素，正式度更高。

3のみならず　「不仅～」

【讲解】表示不仅前项，后项也成立。语体书面、正式，常用于演讲、论文和新闻。后项常与「も」「まで」呼应，强调范围扩大。

接续：动词普通形／い形容词普通形／な形容词词干＋である／名词＋である ＋ のみならず；名词 ＋ のみならず

この政策せいさくは企業きぎょうのみならず、消費者しょうひしゃにも影響えいきょうを与あたえる。

这项政策不仅影响企业，也影响消费者。

彼かれは専門知識せんもんちしきがあるのみならず、交渉力こうしょうりょくも高たかい。

他不仅有专业知识，谈判能力也强。

辨析：「に限らず」强调不限范围；「のみならず」强调正式地追加后项。

4ばかりか　「不但～甚至」

【讲解】表示不只是前项，后项达到更进一步或出乎意料的程度。语气比「のみならず」更强调，口语和书面均可。常用于负面事态扩展，也可用于正面评价。

接续：动词普通形／い形容词普通形／な形容词词干＋な／名词 ＋ ばかりか

彼かれは謝あやまらないばかりか、責任せきにんを部下ぶかに押おし付つけた。

他不但不道歉，甚至把责任推给下属。

このアプリは便利べんりなばかりか、操作そうさもとても簡単かんたんだ。

这个应用不仅方便，操作也很简单。

辨析：「のみならず」正式、平稳；「ばかりか」更有“甚至”的推进感。

5はもとより　「不用说～，连～也」

【讲解】表示前项当然如此，后项也成立。语体正式，常见于演讲、书面介绍和新闻。前项通常是理所当然的范围，后项是进一步扩展。

接续：名词 ＋ はもとより

この施設しせつは学生がくせいはもとより、地域ちいきの住民じゅうみんにも開放かいほうされている。

这个设施不用说学生，连当地居民也可使用。

品質ひんしつはもとより、環境かんきょうへの配慮はいりょも求もとめられる。

品质自不必说，也要求对环境的考虑。

辨析：「もちろん」是普通副词；「はもとより」是书面句型，后面必须继续追加说明。

6も～ば～も　「既～又～」

【讲解】列举两个并列方面，表示两者都成立。语体中性，常用于概括优缺点、能力或条件。第二项常使用ば形构成平衡结构。

接续：名词＋も＋动词ば形／い形容词ければ／な形容词词干・名词＋なら ＋ 名词＋も；常见「AもVばBもV」

この町まちは海うみもあれば山やまもあり、観光かんこうに向むいている。

这个城市既有海也有山，适合观光。

彼女かのじょは経験けいけんもあれば資格しかくもある。

她既有经验也有资格证。

辨析：「やら～やら」常带杂乱、列举很多的感觉；「も～ば～も」更整齐地并列两项。

7やら～やら　「又是～又是～」

【讲解】列举多个同类事项，常带事情很多、杂乱或困扰的语感。口语和随笔中常见。通常只举两项代表，暗示还有其他类似事项。

接续：动词辞书形／い形容词普通形／名词 ＋ やら ＋ 动词辞书形／い形容词普通形／名词 ＋ やら

会議かいぎの準備じゅんびやら資料しりょうの修正しゅうせいやらで、午後ごごはずっと忙いそがしかった。

又是准备会议又是修改资料，整个下午都很忙。

急きゅうに寒さむいやら眠ねむいやらで、仕事しごとに集中しゅうちゅうできなかった。

又冷又困，没法专心工作。

辨析：「といった」用于举例说明类别；「やら～やら」强调列举纷杂事项，常有困扰感。

8につけ（～につけ）　「每当～；无论～」

【讲解】表示一遇到某事就自然产生后项感情，或列举正反两面都如此。语体书面，常用于感想、回忆、评论。固定搭配「何かにつけ」表示动不动、凡事。

接续：动词辞书形／い形容词辞书形／名词 ＋ につけ；AにつけBにつけ

写真しゃしんを見みるにつけ、入社にゅうしゃした頃ころを思おもい出だす。

每当看到照片，就想起刚进公司时。

良よいにつけ悪わるいにつけ、結果けっかはチーム全体ぜんたいで受うけ止とめるべきだ。

无论结果好坏，团队都应该共同接受。

辨析：「ごとに」强调规律性“每一次”；「につけ」多引出感情、判断或正反列举。

9といった　「诸如～之类的」

【讲解】举出几个代表例，说明后面的类别或范围。语体中性，常用于说明、报道和介绍。前项一般列举名词。

接续：名词＋や＋名词 ＋ といった ＋ 名词

営業えいぎょうや広報こうほうといった部署ぶしょでは、対人たいじんスキルが重視じゅうしされる。

在销售、宣传等部门，人际沟通能力受到重视。

地震じしんや台風たいふうといった災害さいがいに備そなえる必要ひつようがある。

有必要防备地震、台风等灾害。

辨析：「か何か」是不确定地举一例；「といった」是列举代表例来概括类别。

10か何か　「～什么的」

【讲解】表示不确定地举出一个可能对象，语气口语化。常用于提议、推测或记不清具体名称时。比「といった」随意，不适合正式文件。

接续：名词 ＋ か何か；动词普通形＋か何か

会議かいぎの前まえに、コーヒーか何なにか買かっていきましょう。

会议前买杯咖啡什么的过去吧。

彼かれは風邪かぜか何なにかで、今日きょうは休やすんでいるらしい。

他好像因为感冒什么的，今天休息了。

辨析：「といった」清楚列举类别；「か何か」表示说话人不确定或随意举例。

11ごとに　「每～」

【讲解】表示以某单位为间隔或每当某动作发生时，后项都会发生。语体中性，常用于规则、统计、工作流程。强调规律性和反复性。

接续：动词辞书形 ＋ ごとに；名词 ＋ ごとに

このアプリは一時間いちじかんごとにデータを自動じどうで保存ほぞんする。

这个应用每隔一小时自动保存数据。

会あうごとに、彼女かのじょの日本語にほんごは上手じょうずになっている。

每次见面，她的日语都在进步。

辨析：「たびに」也表示每次，但「ごとに」更适合客观单位和规则。

12すら・ですら　「连～都」

【讲解】举出极端例子，强调连这个都如此，其他更不用说。语体偏书面，「ですら」更加强调或更郑重。常用于负面、意外或评价强烈的句子。

接续：名词 ＋ すら・ですら；助词は・が・を常被替换，其他助词后可接「すら」

専門家せんもんかですら、この問題もんだいの原因げんいんを説明せつめいできない。

连专家都无法说明这个问题的原因。

忙いそがしすぎて、昼食ちゅうしょくを取とる時間じかんすらなかった。

忙得连吃午饭的时间都没有。

辨析：「さえ」口语和书面都常用；「すら」更书面，强调程度更硬。

✏ 自测练习

1このホテルは部屋へやが広ひろい（　　）、サービスも丁寧ていねいだ。

  1. 1上に
  2. 2やら
  3. 3か何か
  4. 4すら
答案与解析

正确答案：1（上に）

好评价的追加，用「広い上に」。【译文】这家酒店房间宽敞，而且服务也周到。

2交通費こうつうひの増加ぞうか（　　）、宿泊費しゅくはくひも高たかくなった。

  1. 1につけ
  2. 2に加えて
  3. 3に限らず
  4. 4ごとに
答案与解析

正确答案：2（に加えて）

名词＋に加えて，表示追加因素。【译文】除了交通费增加，住宿费也变高了。

3彼かれは資料しりょうを出ださない（　　）、会議かいぎにも遅おくれて来きた。

  1. 1ばかりか
  2. 2はもとより
  3. 3といった
  4. 4も～ば～も
答案与解析

正确答案：1（ばかりか）

不只是没交资料，还迟到，后项进一步追加负面事实，用「ばかりか」。【译文】他不但没交资料，还迟到了会议。

4契約けいやくの確認かくにんやら請求書せいきゅうしょの作成さくせい（　　）で、月末げつまつは忙いそがしい。

  1. 1やら
  2. 2ごとに
  3. 3すら
  4. 4か何か
答案与解析

正确答案：1（やら）

「AやらBやら」列举纷杂事项，后面说明很忙。【译文】又是确认合同又是制作发票，月底很忙。

5地震じしんや台風たいふう（　　）災害さいがいへの備そなえが必要ひつようだ。

  1. 1といった
  2. 2か何か
  3. 3のみならず
  4. 4につけ
答案与解析

正确答案：1（といった）

列举地震、台风作为灾害的代表例，用「といった」修饰「災害」。【译文】有必要防备地震、台风等灾害。

6専門家せんもんか（　　）判断はんだんが難むずかしい問題もんだいだ。

  1. 1ですら
  2. 2ごとに
  3. 3はもとより
  4. 4やら
答案与解析

正确答案：1（ですら）

举出“专家”这一极端例，表示连专家都难判断，用「ですら」。【译文】这是连专家都难以判断的问题。
