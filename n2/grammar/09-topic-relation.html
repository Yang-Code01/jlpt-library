N2 语法 · 第 9 单元　话题・关联与范围

围绕话题、契机、范围、媒介、代表与情感投入，组织更成熟的新闻和职场表达。

本单元共 12 个知识点，单元末附自测练习。

知识点详解

1〜をめぐって・〜をめぐり　「围绕～」

【讲解】表示以问题、事件、政策等为中心，发生争论、讨论、对立或报道。语气正式，新闻评论中常见，强调多方围绕同一话题展开动作。

接续：名词 ＋ をめぐって／をめぐり／をめぐる ＋ 名词

新あたらしい税制ぜいせいをめぐって、与党よとうと野党やとうの対立たいりつが続つづいている。

围绕新税制，执政党与在野党的对立仍在持续。

再開発さいかいはつをめぐる住民じゅうみん説明会せつめいかいが開ひらかれた。

召开了围绕再开发的居民说明会。

辨析：「をめぐって」多用于争论、讨论、事件发展；「について」只是一般“关于”。

2〜をきっかけに　「以～为契机」

【讲解】表示某事成为开始行动、变化或认识的触发点。口语和书面都常用，比「を契機に」柔和日常，常接个人经历、偶然事件、相遇、报道等。

接续：名词 ＋ をきっかけに／をきっかけとして／をきっかけにして

海外かいがい出張しゅっちょうをきっかけに、英語えいごを学まなび直なおすことにした。

以海外出差为契机，我决定重新学习英语。

新聞しんぶんの記事きじをきっかけに、食品しょくひんロスへの関心かんしんが高たかまった。

因为一篇新闻报道，人们对食品浪费的关注提高了。

辨析：个人、小规模契机多用「をきっかけに」；正式重大转折多用「を契機けいきに」。

3〜を契機に・〜を契機として　「以～为契机」

【讲解】表示某事件成为重大变化、发展、改革的正式契机。语气书面正式，常用于新闻、企业公告、历史说明，规模感比「きっかけ」大。

接续：名词 ＋ を契機けいきに／を契機けいきとして／を契機けいきとした ＋ 名词

創立そうりつ五十ごじゅう周年しゅうねんを契機けいきに、会社かいしゃは海外かいがい事業じぎょうを拡大かくだいした。

以创立五十周年为契机，公司扩大了海外业务。

震災しんさいを契機けいきとして、防災ぼうさい教育きょういくの見直みなおしが進すすんだ。

以地震灾害为契机，防灾教育的重新审视得以推进。

注意：多接可成为转折点的正式事件；日常小事用「きっかけ」更自然。

4〜にかかわる　「关系到～、涉及～」

【讲解】表示与重大事项有关系，或影响到某核心问题。语气正式，常接生命、安全、名誉、责任、制度等重要名词，比「関係する」更严肃。

接续：名词 ＋ にかかわる

個人こじん情報じょうほうにかかわる資料しりょうは、厳重げんじゅうに管理かんりする。

涉及个人信息的资料要严格管理。

これは会社かいしゃの信用しんようにかかわる問題もんだいだ。

这是关系到公司信用的问题。

辨析：重大、严肃的关联用「にかかわる」；普通话题关联可用「について」「に関かんして」。

5〜を通じて・〜を通して　「通过～、在整个～期间」

【讲解】表示以某媒介、手段或经验为渠道；也可表示贯穿某期间或范围。语气中性偏正式，「通じて」更书面，「通して」稍口语但也正式。

接续：名词 ＋ を通つうじて／を通とおして

研修けんしゅうを通つうじて、他ほかの部署ぶしょの仕事しごとを理解りかいできた。

通过培训，了解了其他部门的工作。

一年いちねんを通とおして、この地域ちいきには観光客かんこうきゃくが訪おとずれる。

全年都有游客来到这个地区。

辨析：表示媒介时多可互换；「にわたって」更强调范围广、持续久。

6〜にわたって　「历时～、遍及～」

【讲解】表示时间、空间、范围延伸得广或持续较久，语气正式。常用于调查、活动、影响、地区、年代等，强调跨度。

接续：名词 ＋ にわたって／にわたり／にわたる ＋ 名词

三日間みっかかんにわたって、国際こくさい会議かいぎが開ひらかれた。

国际会议持续召开了三天。

台風たいふうの影響えいきょうは広ひろい地域ちいきにわたって及およんだ。

台风影响波及了广大地区。

辨析：「にわたって」强调跨度大；「を通とおして」强调从头到尾、贯穿全程。

7〜を〜として・〜を〜とする　「把～作为～」

【讲解】表示把某人、事物、目标、对象定位为某种身份、用途或标准。语气正式，常见于计划、制度、研究、声明。

接续：名词A ＋ を ＋ 名词B ＋ として／とする／とした ＋ 名词

若者わかものを対象たいしょうとして、就職しゅうしょく支援しえんセミナーを開ひらいた。

以年轻人为对象，举办了就业支援研讨会。

環境かんきょう保護ほごを目的もくてきとする法律ほうりつが改正かいせいされた。

以环境保护为目的的法律被修订了。

辨析：「AをBとして」强调定位或用途；「Bとして」只表示“作为B”的身份。

8〜をこめて　「倾注～、带着～」

【讲解】表示把感情、愿望、敬意、感谢等放入动作或礼物中。语气温和，常用于致辞、书信、礼物、创作说明。

接续：名词（感情、愿望、心意） ＋ をこめて

感謝かんしゃの気持きもちをこめて、退職たいしょくする先輩せんぱいに花束はなたばを贈おくった。

带着感谢之情，给离职的前辈送了花束。

平和へいわへの願ねがいをこめて、市民しみんが千羽鶴せんばづるを折おった。

市民怀着对和平的愿望折了千纸鹤。

注意：通常接抽象心情名词，不能用来表达“投入资金”。

9〜をはじめ　「以～为首、包括～在内」

【讲解】举出代表性例子，表示同类事物还有很多。语气正式，常用于介绍参加者、地区、产品、影响范围。

接续：名词 ＋ をはじめ／をはじめとして／をはじめとする ＋ 名词

社長しゃちょうをはじめ、多おおくの社員しゃいんが式典しきてんに参加さんかした。

以社长为首，许多员工参加了典礼。

東京とうきょうをはじめとする大都市だいとしで、家賃やちんが上昇じょうしょうしている。

以东京为代表的大城市房租正在上涨。

辨析：「をはじめ」举代表例；「など」只是列举，代表性和正式度较弱。

10〜といったら　「说到～那可真是」

【讲解】以某话题为提示展开评价，常带强烈感叹或强调。口语感较强，也可用于随笔式书面语，后项多是程度高或难以形容的评价。

接续：名词／普通形句 ＋ といったら

決算けっさん前まえの忙いそがしさといったら、食事しょくじをする時間じかんもないほどだ。

要说决算前的忙碌，那真是连吃饭时间都没有。

初はじめて契約けいやくが取とれた時ときの喜よろこびといったら、忘わすれられない。

第一次拿下合同时的喜悦，真让人忘不了。

辨析：「といったら」强调感叹；「といえば」更中性，表示“说到……就……”。

11〜にて　「在～、用～」

【讲解】是「で」的书面正式表达，可表示地点、时间、手段、方式。常见于通知、公告、商务邮件和会场说明，日常会话中显得生硬。

接续：名词 ＋ にて

説明会せつめいかいは本社ほんしゃ二階にかいの会議室かいぎしつにて行おこないます。

说明会将在总公司二楼会议室举行。

結果けっかはメールにてお知しらせいたします。

结果将通过邮件通知。

辨析：「にて」基本等于「で」，但正式度更高；日常口语建议用「で」。

12〜ふうに・〜というふうに　「以～方式、像～这样」

【讲解】表示样子、方式、说明角度或表达方式，常用于举例说明“像这样”。口语和说明性书面语都常见，「というふうに」可把前面内容整体作为方式。

接续：动词普通形／い形容词普通形／な形容词词干 ＋ な／名词 ＋ の ＋ ふうに；句子 ＋ というふうに

相手あいてを責せめるふうに言いうと、話はなし合あいは進すすまない。

如果用责备对方的方式说，讨论就无法推进。

問題もんだいを小ちいさく分わけるというふうに考かんがえると、解決かいけつしやすい。

如果像“把问题拆小”这样思考，就更容易解决。

辨析：「ように」更标准、范围更广；「ふうに」更强调外观、语气或处理方式。

✏ 自测练习

1予算よさんの配分はいぶん（　　）、激はげしい議論ぎろんが行おこなわれた。

  1. 1をめぐって
  2. 2をこめて
  3. 3にて
  4. 4にわたって
答案与解析

正确答案：1（をめぐって）

围绕预算分配发生激烈讨论，用「をめぐって」。【译文】围绕预算分配进行了激烈讨论。

2留学りゅうがく（　　）、日本にほんの文化ぶんかに興味きょうみを持もつようになった。

  1. 1を契機けいきとして
  2. 2をきっかけに
  3. 3にかかわる
  4. 4をはじめ
答案与解析

正确答案：2（をきっかけに）

个人经历成为兴趣产生的契机，用较自然的「をきっかけに」。【译文】以留学为契机，我开始对日本文化感兴趣。

3命いのち（　　）問題もんだいなので、慎重しんちょうに対応たいおうすべきだ。

  1. 1にかかわる
  2. 2を通とおして
  3. 3として
  4. 4といったら
答案与解析

正确答案：1（にかかわる）

「命にかかわる問題」表示关系到生命的重大问题。【译文】因为是关系到生命的问题，应该谨慎处理。

4四よん年間ねんかん（　　）、全国ぜんこくで調査ちょうさが続つづけられた。

  1. 1にて
  2. 2をこめて
  3. 3にわたって
  4. 4をはじめ
答案与解析

正确答案：3（にわたって）

「四年間にわたって」强调持续四年这一时间跨度。【译文】调查在全国持续进行了四年。

5感謝かんしゃの気持きもち（　　）、先生せんせいに手紙てがみを書かいた。

  1. 1をこめて
  2. 2をめぐって
  3. 3を通つうじて
  4. 4にかかわって
答案与解析

正确答案：1（をこめて）

把感谢的心情倾注在信中，用「をこめて」。【译文】我怀着感谢之情给老师写了信。

6結果けっかはメール（　　）お知しらせします。

  1. 1として
  2. 2にて
  3. 3をはじめ
  4. 4といったら
答案与解析

正确答案：2（にて）

「メールにて」是正式表达，相当于「メールで」，表示通知手段。【译文】结果将通过邮件通知。
