N2 语法 · 第 11 单元　否定表现（一）不得不与禁止

掌握“不做不行”“不能做”“顾不上做”等否定形式构成的义务与限制表达。

本单元共 12 个知识点，单元末附自测练习。

知识点详解

1ざるを得ない　「不得不～」

【讲解】表示虽然不情愿，但客观情况逼得只能那样做。书面、正式语感较强，常用于报告、新闻和郑重说明。N2 必须记住「する」变为「せざるを得ない」。

接续：动词ない形去ない ＋ ざるを得えない（する → せざるを得えない）

予算よさんが削減さくげんされ、計画けいかくを見直みなおさざるを得えない。

预算被削减，不得不重新审视计划。

証拠しょうこが出でた以上いじょう、方針ほうしんを変更へんこうせざるを得えない。

既然证据出现，就不得不改变方针。

辨析：「ざるを得ない」强调客观别无选择；「ないわけにはいかない」强调责任、人情上不能不做；「よりほかない」更直接表示没有其他办法。

2ずにはいられない・ないではいられない　「忍不住～」

【讲解】表示感情或生理反应强烈，无法抑制自己不做某事。口语和书面都可用，「ずにはいられない」稍书面。常用于笑、哭、担心、同情、提醒等自然反应。

接续：动词ない形去ない ＋ ずにはいられない（する → せずにはいられない）／动词ない形 ＋ ないではいられない

彼かれの誠実せいじつな姿勢しせいを見みると、応援おうえんせずにはいられない。

看到他真诚的态度，就忍不住支持他。

その事故じこを聞きいて、家族かぞくに連絡れんらくしないではいられなかった。

听到那起事故，我忍不住联系了家人。

辨析：「ずにはいられない」是不由自主；「ないわけにはいかない」是责任上不能不做；「ざるを得ない」是被情况逼迫。

3ないわけにはいかない　「不能不～」

【讲解】表示由于责任、常识、人情或社会规则，不做不合适。常用于职场、约定、礼仪和家庭责任。比「ざるを得ない」更强调道义或立场。

接续：动词ない形 ＋ わけにはいかない

上司じょうしから正式せいしきに依頼いらいされたので、引ひき受うけないわけにはいかない。

因为是上司正式委托的，不能不接。

大切たいせつな取引先とりひきさきが来くるので、出席しゅっせきしないわけにはいかない。

重要客户要来，所以不能不出席。

辨析：「ないわけにはいかない」多是义务、人情和立场；「ねばならない」是较硬的必须；「ざるを得ない」是不情愿但被情况逼迫。

4ねばならない　「必须～」

【讲解】表示义务、必要性，相当于较书面的「なければならない」。多用于演讲、文章、制度说明，日常口语中较硬。也可写作「ねばならぬ」。

接续：动词ない形去ない ＋ ねばならない（する → せねばならない）

企業きぎょうは社会的責任しゃかいてきせきにんも考かんがえねばならない。

企业也必须考虑社会责任。

再発さいはつを防ふせぐには、原因げんいんを明あきらかにせねばならない。

为了防止再次发生，必须查明原因。

辨析：「ねばならない」正式、硬；「なければならない」中性；「ないといけない」口语性更强。

5てはならない　「不得～」

【讲解】表示正式而强烈的禁止。常用于法律、规章、公司守则、考试注意事项等。日常会话中直接使用可能显得严厉。

接续：动词て形 ＋ はならない

契約内容けいやくないようを第三者だいさんしゃに漏もらしてはならない。

不得将合同内容泄露给第三方。

災害時さいがいじには不確ふたしかな情報じょうほうを広ひろめてはならない。

灾害时不得传播不确切的信息。

辨析：「てはならない」是正式禁止；「てはいけない」较日常；「べきではない」是不应该，像建议或评价。

6ぬ（文语否定）　「不～」

【讲解】「ぬ」是文语否定，相当于现代语「ない」。常在固定表达、标题、格言或较硬文章中出现。N2 阅读中常见，写作时要注意语体统一。

接续：动词ない形去ない ＋ ぬ（する → せぬ）

予想よそうせぬ事態じたいに備そなえ、複数ふくすうの案あんを用意よういした。

为了应对意想不到的情况，准备了多个方案。

彼かれは最後さいごまで誤あやまりを認みとめぬままだった。

他直到最后都没有承认错误。

辨析：「ぬ」相当于「ない」，但古雅、书面；「ず」多用于连接，如「知らずに」。

7まい　「不会～吧／绝不～」

【讲解】表示否定推量“不会～吧”，也可表示否定意志“绝不～”。书面、男性化或郑重语感较强，日常口语中不如「ないだろう」常见。阅读中要根据主语和上下文判断用法。

接续：五段动词辞书形 ＋ まい；一段动词辞书形／ます形词干 ＋ まい；する → するまい・すまい・しまい；来くる → 来くるまい・来こまい

この様子ようすでは、交渉こうしょうは簡単かんたんにはまとまるまい。

看这个样子，谈判不会轻易达成吧。

同おなじ失敗しっぱいは二度にどとすまいと心こころに決きめた。

我下定决心绝不再犯同样的错误。

辨析：「まい」可表否定推量或意志；「そうにない」只根据迹象判断；「っこない」是口语强烈否定。

8よりほかない　「只好～」

【讲解】表示除此之外没有其他选择。书面和正式说明中常用，语气比「しかない」更郑重。常用于决策、应对措施和困境说明。

接续：动词辞书形 ＋ よりほかない

納期のうきまで時間じかんがないので、人員じんいんを増ふやすよりほかない。

离交期没有时间了，只能增加人员。

資料しりょうが残のこっていない以上いじょう、関係者かんけいしゃに聞きくよりほかない。

既然资料没有留下，只能去问相关人员。

辨析：「よりほかない」强调选择被限定；「ざるを得ない」带不情愿；「ないわけにはいかない」强调责任。

9ないで済む・ずに済む　「不用～也行」

【讲解】表示本来可能需要做某事，但结果没有必要做，常带幸好省掉的语感。日常和商务场景都常见。「ずに済む」稍书面，且「する」变为「せずに済む」。

接续：动词ない形 ＋ ないで済すむ／动词ない形去ない ＋ ずに済すむ（する → せずに済すむ）

早はやめに修理しゅうりしたので、部品ぶひんを交換こうかんしないで済すんだ。

因为提前修好了，所以不用更换零件。

担当者たんとうしゃが説明せつめいし、私わたしは出席しゅっせきせずに済すんだ。

负责人做了说明，我不用出席也可以了。

辨析：「ないで済む」表示免于做某事；「なくて済む」多表示无需处于某种状态，如「心配しなくて済む」。

10てはいられない　「不能再～下去」

【讲解】表示由于情况紧急或责任在身，不能继续保持某种状态或动作。常用于工作压力、危机应对、时间紧迫等场景。语气中含必须行动的紧迫感。

接续：动词て形 ＋ はいられない

締切しめきりが明日あしたなので、もう迷まよってはいられない。

截止日期是明天，不能再犹豫了。

被害ひがいが広ひろがり、政府せいふは黙だまってはいられない。

受害正在扩大，政府不能再沉默。

辨析：「てはいられない」强调不能继续；「てばかりはいられない」强调不能只做某一件事。

11てばかりはいられない　「不能光是～」

【讲解】表示不能一直只做某事，必须转向下一步行动。常用于从反省、等待、担心、依赖中切换到行动。语气强调不能停留在这一点。

接续：动词て形 ＋ ばかりはいられない

失敗しっぱいを悔くやんでばかりはいられない。原因げんいんを分析ぶんせきしよう。

不能光后悔失败。来分析原因吧。

市場しじょうの回復かいふくを待まってばかりはいられない。

不能光等市场恢复。

辨析：「ばかり」提示偏在某一动作上；「てはいられない」更宽泛地表示不能继续。

12ていては　「如果一直～就会（不好）」

【讲解】表示如果持续某状态或做法，就会产生不好的结果。常用于提醒、批评、建议改进。后项多为否定或消极结果。

接续：动词て形 ＋ いては（口语可缩约为「てちゃ」）

このまま議論ぎろんしていては、結論けつろんが出でない。

如果继续这样讨论，就得不出结论。

古ふるい方法ほうほうにこだわっていては、競争きょうそうに勝かてない。

如果拘泥于旧方法，就无法在竞争中获胜。

辨析：「ていては」表示持续状态导致坏结果；「てはならない」是禁止；「てはいられない」是不能继续而必须行动。

自测练习

1証拠しょうこが十分じゅうぶんに集あつまった以上いじょう、会社かいしゃは事実じじつを認みとめ（　　）。

  1. 1ざるを得えない
  2. 2ずにはいられない
  3. 3てはならない
  4. 4ないで済すむ
答案与解析

正确答案：1（ざるを得ない）

客观状况迫使公司承认，用「ざるを得ない」。【译文】既然证据已充分，公司不得不承认事实。

2災害時さいがいじには、不確ふたしかな情報じょうほうを広ひろめ（　　）。

  1. 1てはならない
  2. 2よりほかない
  3. 3ずに済すむ
  4. 4まい
答案与解析

正确答案：1（てはならない）

正式禁止“不得传播”用「てはならない」。【译文】灾害时不得传播不确切的信息。

3彼かれの苦労くろうを聞きくと、同情どうじょうせ（　　）。

  1. 1ずにはいられない
  2. 2ねばならない
  3. 3まい
  4. 4ていては
答案与解析

正确答案：1（ずにはいられない）

感情上忍不住同情，用「せずにはいられない」。【译文】听到他的辛苦经历，就忍不住同情。

4締切しめきりが近ちかい。もう迷まよっ（　　）。

  1. 1てはいられない
  2. 2てはならない
  3. 3ないで済すむ
  4. 4まい
答案与解析

正确答案：1（てはいられない）

情况紧急，不能继续犹豫，用「てはいられない」。【译文】截止日期近了，不能再犹豫。

5資料しりょうが残のこっていないなら、関係者かんけいしゃに聞きく（　　）。

  1. 1よりほかない
  2. 2ずにはいられない
  3. 3てばかりはいられない
  4. 4まい
答案与解析

正确答案：1（よりほかない）

表示唯一选择，用「辞书形＋よりほかない」。【译文】如果资料没有留下，就只能去问相关人员。

6早はやめに相談そうだんしたので、大おおきな問題もんだいになら（　　）。

  1. 1ずに済すんだ
  2. 2ざるを得えなかった
  3. 3ねばならなかった
  4. 4てはならなかった
答案与解析

正确答案：1（ずに済んだ）

避免变成大问题，用「ならずに済んだ」。【译文】因为提前商量了，所以没有发展成大问题。
