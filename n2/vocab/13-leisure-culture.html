✏ 自测练习

1舞台ぶたいで俳優はいゆうが長ながい（　　）を言いった。

  1. 1台詞
  2. 2光線
  3. 3祭日
  4. 4扇子
答案与解析

正确答案：1（台詞）

「台詞」は演员在舞台上说的台词。其他选项分别是光线、节日、折扇。【译文】演员在舞台上说了很长的台词。

2勝かつか負まけるか、（　　）はまだ分わからない。

  1. 1工芸
  2. 2勝敗
  3. 3写生
  4. 4盆
答案与解析

正确答案：2（勝敗）

「勝敗」は胜负、胜败的意思，适合表示结果尚未确定。【译文】是赢是输，胜败还不知道。

3週末しゅうまつ、駅前えきまえで音楽おんがくの（　　）が開ひらかれる。

  1. 1催し
  2. 2寺院
  3. 3送り仮名
  4. 4中世
答案与解析

正确答案：1（催し）

「催し」は活动、集会的意思，可用于音乐活动。【译文】周末车站前会举办音乐活动。

4公共こうきょうの場ばでは（　　）を守まもるべきだ。

  1. 1エチケット
  2. 2コレクション
  3. 3ダイヤモンド
  4. 4テニスコート
答案与解析

正确答案：1（エチケット）

「エチケット」は礼仪、礼节，常与「守る」搭配。【译文】在公共场合应该遵守礼仪。

5この小説しょうせつは時代じだいを超こえた（　　）だ。

  1. 1遠足
  2. 2名作
  3. 3宴会
  4. 4扇風機
答案与解析

正确答案：2（名作）

「名作」は优秀且有名的作品，符合评价小说的语境。【译文】这部小说是跨越时代的名作。
