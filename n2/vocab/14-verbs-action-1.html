自测练习

1濃こすぎるスープは、水みずで（　　）とよい。

  1. 1薄める
  2. 2焦がす
  3. 3縛る
  4. 4追い越す
答案与解析

正确答案：1（薄める）

「薄める」は把浓的东西稀释，最符合语境。【译文】太浓的汤用水稀释就好。

2皿さらが床ゆかに落おちて（　　）。

  1. 1砕けた
  2. 2補った
  3. 3うなずいた
  4. 4耕した
答案与解析

正确答案：1（砕けた）

「砕ける」是自动词，表示东西破碎。【译文】盘子掉到地上碎了。

3会議かいぎの時間じかんを一時間いちじかん（　　）ください。

  1. 1ずらして
  2. 2しゃがんで
  3. 3しびれて
  4. 4茂って
答案与解析

正确答案：1（ずらして）

「ずらす」表示挪动时间，可用于推迟会议。【译文】请把会议时间错后一小时。

4警察けいさつは行方ゆくえの分わからない子こどもを（　　）いる。

  1. 1捜して
  2. 2浮かべて
  3. 3剃って
  4. 4区切って
答案与解析

正确答案：1（捜して）

「捜す」常用于寻找失踪的人或物。【译文】警察正在寻找下落不明的孩子。

5失礼しつれいですが、その件けんは以前いぜんから（　　）おります。

  1. 1存じて
  2. 2暴れて
  3. 3縮れて
  4. 4あぶって
答案与解析

正确答案：1（存じて）

「存じる」は「知る」的谦让语，适合正式场合。【译文】恕我冒昧，那件事我以前就知道。
