自测练习

1説明せつめいが（　　）で、結論けつろんがわからない。

  1. 1あいまい
  2. 2透明
  3. 3四角い
  4. 4塩辛い
答案与解析

正确答案：1（あいまい）

「あいまい」表示含糊不清。【译文】说明很含糊，不明白结论。

2年末ねんまつで職場しょくばが（　　）。

  1. 1慌ただしい
  2. 2軟らかい
  3. 3茶色い
  4. 4なだらかだ
答案与解析

正确答案：1（慌ただしい）

「慌ただしい」表示忙乱、匆忙。【译文】年末职场很忙乱。

3彼かれの助言じょげんは（　　）だった。

  1. 1的確
  2. 2下品
  3. 3煙い
  4. 4真っ黒
答案与解析

正确答案：1（的確）

「的確」表示准确、恰当。【译文】他的建议很准确。

4外そとが（　　）ので、窓まどを閉しめた。

  1. 1騒がしい
  2. 2妥当
  3. 3稀
  4. 4手頃
答案与解析

正确答案：1（騒がしい）

「騒がしい」表示吵闹。【译文】外面很吵，所以关上了窗。

5予想よそう（　　）の結果けっかに驚おどろいた。

  1. 1外
  2. 2形
  3. 3色
  4. 4副詞
答案与解析

正确答案：1（外）

「予想外」表示出乎意料。【译文】对意料之外的结果感到惊讶。
