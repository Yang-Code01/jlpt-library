✏ 自测练习

1会議かいぎの（　　）は午後ごご三時さんじです。

  1. 1給与
  2. 2締切
  3. 3牧畜
  4. 4全集
答案与解析

正确答案：2（締切）

表示期限的词是「締切しめきり」。其他选项分别表示工资、畜牧和全集。【译文】会议的截止时间是下午三点。

2新あたらしい支店してんの責任者せきにんしゃに（　　）した。

  1. 1就任
  2. 2縮む
  3. 3応接
  4. 4私鉄
答案与解析

正确答案：1（就任）

担任新职位用「就任しゅうにんする」。其他选项不能表示上任。【译文】他就任了新分店的负责人。

3作業さぎょうの（　　）を上あげるため、手順てじゅんを見直みなおした。

  1. 1役目
  2. 2能率
  3. 3会館
  4. 4主役
答案与解析

正确答案：2（能率）

提高工作的效率说「能率のうりつを上あげる」。其他选项语义不合。【译文】为了提高作业效率，重新检查了流程。

4入口いりぐちの（　　）を強化きょうかしてください。

  1. 1警備
  2. 2創作
  3. 3商店
  4. 4抽象
答案与解析

正确答案：1（警備）

入口需要加强的是「警備けいび」。其他选项表示创作、商店和抽象。【译文】请加强入口的安保。

5彼かれは経験けいけん豊ゆたかな（　　）の技術者ぎじゅつしゃだ。

  1. 1定休日
  2. 2ベテラン
  3. 3官庁
  4. 4当日
答案与解析

正确答案：2（ベテラン）

经验丰富的人是「ベテラン」。其他选项分别表示固定休息日、政府机关和当天。【译文】他是一位经验丰富的老手工程师。
