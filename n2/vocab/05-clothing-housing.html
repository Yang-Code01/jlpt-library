自测练习

1寒さむいので、（　　）を首くびに巻まいた。

  1. 1マフラー
  2. 2バケツ
  3. 3判子
  4. 4瓦
答案与解析

正确答案：1（マフラー）

「首に巻く」保暖用品是围巾。「バケツ」是水桶，「判子」是印章，「瓦」是屋瓦。【译文】因为冷，把围巾围在脖子上。

2部屋へやの空気くうきが悪わるいので、窓まどを開あけて（　　）した。

  1. 1貯蔵
  2. 2換気
  3. 3起床
  4. 4分布
答案与解析

正确答案：2（換気）

开窗让空气流通叫「換気する」。其他选项分别是储藏、起床、分布。【译文】房间空气不好，所以开窗通风了。

3客きゃくを通とおす部屋へやを（　　）という。

  1. 1客間
  2. 2肌着
  3. 3毛糸
  4. 4目覚し
答案与解析

正确答案：1（客間）

「客間」是招待客人的会客室。「肌着」是内衣，「毛糸」是毛线，「目覚し」是闹钟。【译文】招待客人的房间叫会客室。

4玄関げんかんで靴くつを二に（　　）そろえた。

  1. 1着
  2. 2足
  3. 3枚
  4. 4本
答案与解析

正确答案：2（足）

鞋袜的量词用「足」，二足读作「にそく」。【译文】在玄关把两双鞋摆整齐了。

5柄がらのないシャツは（　　）のシャツだ。

  1. 1無地
  2. 2縞
  3. 3紺
  4. 4灰色
答案与解析

正确答案：1（無地）

没有花纹、图案的布料或衣服叫「無地」。其他选项是条纹、藏青色、灰色。【译文】没有图案的衬衫是素色衬衫。
