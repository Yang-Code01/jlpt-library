✏ 自测练习

1文章ぶんしょうの（　　）を読よめば、全体ぜんたいの流ながれがわかる。

  1. 1粗筋あらすじ
  2. 2定規じょうぎ
  3. 3改札かいさつ
  4. 4大木たいぼく
答案与解析

正确答案：1（粗筋）

「粗筋」是故事或文章的梗概，能帮助把握整体内容。【译文】读一下文章梗概，就能了解整体脉络。

2試験しけんの答案とうあんを（　　）する。

  1. 1採点さいてん
  2. 2田植たうえ
  3. 3裁縫さいほう
  4. 4温泉おんせん
答案与解析

正确答案：1（採点）

给试卷或答案打分用「採点する」。其他词分别是插秧、缝纫、温泉。【译文】给考试答案评分。

3文ぶんの中なかで動作どうさの主体しゅたいを表あらわす言葉ことばは（　　）だ。

  1. 1主語しゅご
  2. 2述語じゅつご
  3. 3索引さくいん
  4. 4通帳つうちょう
答案与解析

正确答案：1（主語）

动作或状态的主体是「主語」。谓语说明主语，索引和存折不属于语法成分。【译文】句中表示动作主体的词是主语。

4大学だいがくを卒業そつぎょうしてから、（　　）で研究けんきゅうを続つづける。

  1. 1大学院だいがくいん
  2. 2回数券かいすうけん
  3. 3塵紙ちりがみ
  4. 4謎謎なぞなぞ
答案与解析

正确答案：1（大学院）

大学毕业后继续研究的场所通常是「大学院」。其他选项语境不合。【译文】大学毕业后，在研究生院继续研究。

5名前なまえの漢字かんじに（　　）を付つけてください。

  1. 1振ふり仮名がな
  2. 2方程式ほうていしき
  3. 3標本ひょうほん
  4. 4満点まんてん
答案与解析

正确答案：1（振り仮名）

给汉字标注读音用「振り仮名を付ける」。【译文】请给名字的汉字加上注音假名。
