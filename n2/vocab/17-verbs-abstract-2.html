✏ 自测练习

1締切しめきりが（　　）いるので、急いそいでください。

  1. 1迫って
  2. 2逸れて
  3. 3膨らんで
  4. 4巡って
答案与解析

正确答案：1（迫って）

「迫る」表示时间逼近，适合截止日期快到的语境。【译文】截止日期快到了，请抓紧。

2説明せつめいに（　　）があり、確認かくにんが必要ひつようだ。

  1. 1矛盾
  2. 2送料
  3. 3先端
  4. 4算盤
答案与解析

正确答案：1（矛盾）

「矛盾がある」表示前后不一致。【译文】说明里有矛盾，需要确认。

3事故じこで電車でんしゃが（　　）した。

  1. 1停止
  2. 2相互
  3. 3速力
  4. 4瀬戸物
答案与解析

正确答案：1（停止）

「停止する」表示运行停止。【译文】电车因事故停止运行了。

4来年らいねんの合格ごうかくを（　　）。

  1. 1目指す
  2. 2跳ねる
  3. 3隔てる
  4. 4更ける
答案与解析

正确答案：1（目指す）

「目指す」表示以某事为目标。【译文】以明年合格为目标。

5会議かいぎで教育きょういくの問題もんだいを（　　）。

  1. 1論じた
  2. 2清掃した
  3. 3引き返した
  4. 4膨らんだ
答案与解析

正确答案：1（論じた）

「論ずる」表示讨论、论述。【译文】在会议上讨论了教育问题。
