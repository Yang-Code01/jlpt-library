✏ 自测练习

1彼かれの説明せつめいは（　　）で、すぐ理解りかいできた。

  1. 1はきはき
  2. 2どきどき
  3. 3そうっと
  4. 4めちゃくちゃ
答案与解析

正确答案：1（はきはき）

“はきはき”表示说话清楚利落，符合句意。其他选项分别表示心跳紧张、轻轻地、乱七八糟。【译文】他的说明很清楚，我马上就理解了。

2「謙虚けんきょ」の意味いみとして正ただしいものはどれですか。

  1. 1自慢ばかりする
  2. 2素直で控えめだ
  3. 3乱暴に話す
  4. 4すぐ油断する
答案与解析

正确答案：2（素直で控えめだ）

“謙虚”指谦虚、谦逊，即坦率而不张扬。【译文】“謙虚”的正确意思是哪一个？

3失敗しっぱいしても（　　）な顔かおをしている。

  1. 1平気
  2. 2憎い
  3. 3純情
  4. 4不運
答案与解析

正确答案：1（平気）

“平気な顔”是固定搭配，表示一副不在乎、镇定的样子。【译文】即使失败了，也摆出一副镇定的表情。

4「弱点じゃくてん」の読よみ方かたはどれですか。

  1. 1よわてん
  2. 2じゃくてん
  3. 3しょうてん
  4. 4じゃってん
答案与解析

正确答案：2（じゃくてん）

“弱点”读作“じゃくてん”，表示弱点、短处。【译文】“弱点”的读音是哪一个？

5卒直そっちょくな意見いけんを（　　）。

  1. 1威張りたい
  2. 2聞かせてください
  3. 3嫌がっています
  4. 4油断しました
答案与解析

正确答案：2（聞かせてください）

“卒直な意見を聞かせてください”表示“请告诉我坦率的意见”，搭配自然。【译文】请告诉我坦率的意见。
