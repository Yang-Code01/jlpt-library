  4. 4リットル
答案与解析

正确答案：1（とっくに）

「とっくに」表示早就已经发生。译文：会议早就开始了。

2（　　）行いくなら、早はやく出でよう。

  1. 1どうせ
  2. 2ぴかぴか
  3. 3未満
  4. 4附属
答案与解析

正确答案：1（どうせ）

「どうせ」表示“反正、终归”。译文：反正要去的话，就早点出发吧。

3資料しりょうを（　　）集あつめた。

  1. 1残らず
  2. 2のろのろ
  3. 3ダブル
  4. 4翌～
答案与解析

正确答案：1（残らず）

「残らず」表示一个不剩、全部。译文：资料全部收齐了。

4彼かれは遅刻ちこくし（　　）だ。

  1. 1がち
  2. 2艘
  3. 3羽
  4. 4史
答案与解析

正确答案：1（がち）

「～がち」表示容易出现某种倾向。译文：他容易迟到。

5この商品しょうひんは子供こども（　　）に作つくられた。

  1. 1向け
  2. 2滴
  3. 3遍
  4. 4号
答案与解析

正确答案：1（向け）

「～向け」表示面向某对象。译文：这个商品是面向儿童制作的。
