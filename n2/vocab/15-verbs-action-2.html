自测练习

1予約よやくを（　　）と、キャンセル料りょうがかかる。

  1. 1取り出す
  2. 2取り消す
  3. 3見送る
  4. 4掘る
答案与解析

正确答案：2（取り消す）

「予約を取り消す」表示取消预约。

2新あたらしい方法ほうほうを授業じゅぎょうに（　　）。

  1. 1取り入れる
  2. 2逃がす
  3. 3凹む
  4. 4怒鳴る
答案与解析

正确答案：1（取り入れる）

「取り入れる」表示引进、采用新方法。

3駅えきの前まえを（　　）とき、先生せんせいに会あった。

  1. 1通り掛かる
  2. 2留まる
  3. 3塞がる
  4. 4曲げる
答案与解析

正确答案：1（通り掛かる）

「通り掛かる」表示碰巧经过某处。

4説明せつめいが長ながいので、細こまかい部分ぶぶんは（　　）。

  1. 1狙う
  2. 2略す
  3. 3撫でる
  4. 4彫る
答案与解析

正确答案：2（略す）

「略す」表示省略。

5風船ふうせんを（　　）すぎて、割われてしまった。

  1. 1膨らます
  2. 2濁る
  3. 3見下ろす
  4. 4もたれる
答案与解析

正确答案：1（膨らます）

「風船を膨らます」表示把气球吹大。
