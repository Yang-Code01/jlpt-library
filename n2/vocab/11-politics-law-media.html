自测练习

1この道みちは港みなとへ（　　）。

  1. 1通ずる
  2. 2通知する
  3. 3防止する
  4. 4録音する
答案与解析

正确答案：1（通ずる）

「通ずる」は道路等が某处に通じる意思。其他选项分别是通知、防止、录音，语义不合。【译文】这条路通往港口。

2新聞しんぶんの（　　）で政府せいふの方針ほうしんを批判ひはんした。

  1. 1宛名
  2. 2社説
  3. 3内線
  4. 4受話器
答案与解析

正确答案：2（社説）

批判政府方针的是报纸的「社説」（社论）。其他选项分别为收件信息、内线、听筒。【译文】报纸社论批评了政府方针。

3被害ひがいを減へらすため、盗難とうなん（　　）の対策たいさくを強つよめた。

  1. 1接近
  2. 2防止
  3. 3解散
  4. 4反映
答案与解析

正确答案：2（防止）

「盗難防止」是固定搭配，表示防止失窃。其他选项不能自然连接。【译文】为了减少损失，加强了防盗措施。

4封筒ふうとうに（　　）を書かいてから郵送ゆうそうした。

  1. 1宛名
  2. 2表紙
  3. 3領事
  4. 4法則
答案与解析

正确答案：1（宛名）

寄信前写在信封上的是「宛名」。其他选项是封面、领事、法则。【译文】在信封上写好收件信息后寄出了。

5市民しみんの声こえを政策せいさくに（　　）する。

  1. 1反映
  2. 2解散
  3. 3命ずる
  4. 4傾く
答案与解析

正确答案：1（反映）

「意見・声を政策に反映する」表示把意见体现在政策里。其他选项语义不合。【译文】把市民的声音反映到政策中。
