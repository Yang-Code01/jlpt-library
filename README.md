# JLPT Library

JLPT（日本語能力試験）N1～N5 的日语学习资料库——词汇、语法、真题、模拟题。

🌐 **在线浏览**：https://Yang-Code01.github.io/jlpt-library/

## 目录结构

```
├── index.html              ← 首页（资料导航）
├── LICENSE                 ← CC BY-NC 4.0 许可证
├── assets/
│   └── style.css           ← 全站样式
└── n1/ … n5/               ← 各等级的学习页面
```

每个 N 级别下按 `vocab/`（词汇）、`grammar/`（语法）、`exam/`（真题） 等子目录组织。

## 本地预览

任何浏览器直接打开 `index.html` 即可，无构建步骤、无依赖。
