# en/data —— 英语侧数据（生成物）

这个目录里的文件**全部是生成物，勿手改**。改数据请改源文件或生成脚本，然后重跑生成器。

| 文件 | 内容 |
|---|---|
| `vocab.js` | 全量词表，注入 `window.EN_VOCAB`（`meta` + `words[]`），约 1.53 MB |

页面通过 `<script src>` 加载它，不经过 `fetch()` —— 站点必须能在 `file://` 下完整工作。

## 生成

```bash
node tools/en-vocab.mjs gen      # 重写本目录的 vocab.js、各单元页、门户里的清单区
node tools/en-vocab.mjs check    # 只校验，不改文件；有问题退出码 1
```

默认从 `.scratch/en-module/research/ecdict.csv` 读源文件（`.scratch/` 不在仓库里，
克隆下来的人自己建目录或用 `--src` 指定）：

```bash
node tools/en-vocab.mjs gen --src /path/to/ecdict.csv
```

只用了 ECDICT 的这些字段：`word`（词形）、`phonetic`（音标）、`definition`（英释）、
`translation`（中释）、`collins`（柯林斯星级）、`oxford`（牛津三千标记）、`tag`（考纲标签）、
`bnc` / `frq`（词频位次）、`exchange`（词形变化）。

两处实测注意：

- **`pos` 列全表为空**（770,612 行只有表头有值），所以词典里不存 ECDICT 的词性字段，
  页面上的词性是从中文释义的行首前缀（`n.` / `vt.` / `adj.` …）反推出来的。
- `detail`（例句）与 `audio`（读音）两列全表为空 —— 例句不是「这版先不做」，是拿不到。

## 选词与分档

1. 只取词形匹配 `^[a-z][a-z'-]*$`、中文释义非空、词频字段大于 0 的条目（41,409 个候选）。
2. 按词频升序取前 **3,766** 个。
3. 按**排序位次**（不是词频数值）切成四档：`1k` 1–1000、`2k` 1001–2000、
   `3k` 2001–2809、`4k` 2810–3766。
4. 每档内每 **50** 词一个单元，单元号**全局连续** `01`–`77`，末单元允许不足 50 词。

| 档 | 位次 | 词数 | 单元 | 单元号 |
|---|---|---|---|---|
| 1k | 1–1000 | 1000 | 20 | 01–20 |
| 2k | 1001–2000 | 1000 | 20 | 21–40 |
| 3k | 2001–2809 | 809 | 17 | 41–57 |
| 4k | 2810–3766 | 957 | 20 | 58–77 |

76 是 `3766 / 50` 的算法结果，**77 才对** —— 单元是按档分别切出来的。
