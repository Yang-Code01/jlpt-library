知识点详解

1なり～なり　「或～或～；可以～也可以～」

【讲解】列举几个可选做法，提示对方从中选择一个行动。常用于建议、催促或提出最低限度的处理办法，语气比单纯「か」更带“总之做点什么”的感觉。

接续：动词辞书形 ＋ なり ＋ 动词辞书形 ＋ なり／名词 ＋ なり ＋ 名词 ＋ なり。后项多接命令、依赖、建议、可能表达。

担当者たんとうしゃに確認かくにんするなり、資料しりょうを調しらべるなりして、早急そうきゅうに返答へんとうしてください。

请向负责人确认也好，查资料也好，尽快回复。

不明点ふめいてんがあれば、上司じょうしなり同僚どうりょうなりに相談そうだんすればいい。

有不明白的地方，找上司或同事商量就好。

黙だまっていないで、反論はんろんするなり説明せつめいするなりしたらどうか。

别沉默不语，反驳也好说明也好，做点什么如何？

辨析：「なり～なり」表示选择建议，重点是“任选其一并采取行动”；「といい～といい」表示列举两个方面来作总体评价，不能替换成建议语气。

2だの～だの　「什么～啦什么～啦；又是～又是～」

【讲解】随意列举多个事物、理由或说法，常带抱怨、轻视、厌烦等感情色彩。口语性强，但在叙述批评和人物发言时也常见。

接续：名词／普通形句子 ＋ だの ＋ 名词／普通形句子 ＋ だの。常与「と言う」「と文句を言う」「で騒ぐ」等搭配。

予算よさんが足たりないだの、人手ひとでが足たりないだのと、現場げんばから不満ふまんが相次あいついだ。

现场接连抱怨预算不够、人手不够之类的问题。

彼かれは忙いそがしいだの体調たいちょうが悪わるいだのと言いって、会議かいぎへの出席しゅっせきを避さけている。

他嘴上说忙啦身体不舒服啦，回避出席会议。

机つくえの上うえには契約書けいやくしょだの請求書せいきゅうしょだのが山積やまづみになっていた。

桌上合同、账单之类的文件堆积如山。

注意：正式报告中列举中性项目时，优先用「や」「および」「ならびに」。

3といい～といい　「无论～还是～；从～和～来看」

【讲解】列举同一对象的两个方面，并据此作整体评价。常用于赞叹、批判或判断，后项往往是对该对象的综合评价。

接续：名词 ＋ といい ＋ 名词 ＋ といい。只列举代表性方面，不表示从中选择。

品質ひんしつといい価格かかくといい、この製品せいひんは競合品きょうごうひんを大おおきく上回うわまわっている。

无论质量还是价格，这款产品都大幅优于竞品。

発想はっそうといい実行力じっこうりょくといい、彼女かのじょは次世代じせだいのリーダーリーダーにふさわしい。

从想法到执行力，她都适合成为下一代领导者。

立地りっちといい設備せつびといい、この施設しせつは研究拠点けんきゅうきょてんとして申もうし分ぶんない。

无论地段还是设备，这个设施作为研究基地都无可挑剔。

4というか～というか　「该说是～呢，还是～呢」

【讲解】在寻找更贴切说法时列举两个近似评价，表示难以一句话定性，或对前一说法进行修正、补充。口语到评论文均可见。

接续：普通形句子／名词・な形容词词干 ＋ というか ＋ 普通形句子／名词・な形容词词干 ＋ というか。

今回こんかいの決定けっていは慎重しんちょうというか消極的しょうきょくてきというか、市場しじょうには物足ものたりなく映うつった。

这次决定该说慎重还是消极，市场看来并不满意。

彼かれの説明せつめいは簡潔かんけつというか不親切ふしんせつというか、初はじめて聞きく人ひとには分わかりにくい。

他的说明该说简洁还是不够体贴，对初次听的人来说很难懂。

安心あんしんしたというか力ちからが抜ぬけたというか、合格ごうかくを知しった瞬間しゅんかんに涙なみだが出でた。

知道合格的瞬间，该说安心还是一下子松了劲，我流下了眼泪。

5つ～つ　「一会儿～一会儿～；互相～」

【讲解】表示两个动作交替反复，或双方互相作用。现代日语中多为固定惯用对，文章和演讲中用于凝练描写。

接续：动词ます形词干 ＋ つ ＋ 动词ます形词干 ＋ つ。多为惯用对，如「行ゆきつ戻もどりつ」「持もちつ持もたれつ」。

交渉こうしょうは進すすみつ戻もどりつしながらも、ようやく合意ごういに近ちかづいた。

谈判虽进进退退，但终于接近达成协议。

駅前えきまえを行ゆきつ戻もどりつして、待まち合あわせ場所ばしょを探さがした。

我在车站前来回走动，寻找碰头地点。

地域ちいき社会しゃかいと企業きぎょうは、持もちつ持もたれつの関係かんけいにある。

社区与企业处于相互扶持的关系之中。

注意：不能自由套用所有动词；学习时优先掌握固定搭配。

6かれ～かれ　「或早或晚；或多或少」

【讲解】用成对形容词概括范围，表示无论程度差异如何，结果大体成立。多见于固定表达，书面语色彩较强。

接续：い形容词词干 ＋ かれ ＋ い形容词词干 ＋ かれ。常见「遅おそかれ早はやかれ」「多おおかれ少すくなかれ」。

遅おそかれ早はやかれ、この制度せいどは見直みなおしを迫せまられるだろう。

或早或晚，这项制度恐怕都会被迫重新审视。

多おおかれ少すくなかれ、誰だれもが環境かんきょう変化へんかの影響えいきょうを受うけている。

或多或少，每个人都受到了环境变化的影响。

良よかれ悪あしかれ、彼かれの発言はつげんは議論ぎろんを活性化かっせいかさせた。

不论好坏，他的发言激活了讨论。

7やれ～やれ　「又是～又是～；这个那个地」

【讲解】列举接连出现的事情或别人反复提出的要求，常带忙乱、抱怨或讽刺。比「や」感情色彩更强。

接续：やれ ＋ 名词／普通形句子 ＋ だ、やれ ＋ 名词／普通形句子 ＋ だ（と）。也常见「やれ～やれ～と」。

会議かいぎでは、やれ資料しりょうが足たりない、やれ説明せつめいが不十分ふじゅうぶんだと、批判ひはんが相次あいついだ。

会上又说资料不足，又说说明不充分，批评接连不断。

年度末ねんどまつは、やれ報告書ほうこくしょだ、やれ予算案よさんあんだと、部署全体ぶしょぜんたいが慌あわただしい。

年度末又是报告书又是预算案，整个部门都忙得不可开交。

住民説明会じゅうみんせつめいかいでは、やれ騒音そうおんだ、やれ安全性あんぜんせいだと、質問しつもんが途切とぎれなかった。

居民说明会上，噪音啦安全性啦，提问一直没有中断。

8わ～わで　「又～又～，所以～」

【讲解】列举多个突发或不利状况，表示这些事情叠加导致后项结果。常用于口语叙述，也可写入随笔、报道中的现场描写。

接续：普通形句子 ＋ わ ＋ 普通形句子 ＋ わで。名词・な形容词多用「だわ」。后项常为困惑、混乱、疲劳等结果。

道みちは込こむわ雨あめは降ふるわで、到着とうちゃくが大幅おおはばに遅おくれた。

又堵车又下雨，抵达时间大幅延误。

電話でんわは鳴なり続つづくわ来客らいきゃくは相次あいつぐわで、午前中ごぜんちゅうは仕事しごとにならなかった。

电话一直响，访客又接连不断，上午根本没法工作。

資料しりょうは古ふるいわ数値すうちは合あわないわで、分析ぶんせきをやり直なおすしかなかった。

资料陈旧，数据又对不上，只能重新分析。

9のやら～のやら・ものやら・ことやら　「是～还是～；该如何～；不知～」

【讲解】表示说话人无法判断、难以说明或不知如何处理。「のやら～のやら」列举两种不确定状态；「ものやら」常用于“该怎么办”；「ことやら」常带感叹式不确定。

接续：普通形句子 ＋ のやら ＋ 普通形句子 ＋ のやら／疑问词 ＋ ものやら／疑问词 ＋ ことやら。な形容词・名词用「なのやら」。

彼かれの表情ひょうじょうからは、喜よろこんでいるのやら困こまっているのやら判断はんだんできなかった。

从他的表情无法判断他是高兴还是为难。

計画けいかくがここまで遅おくれてしまっては、どこから立たて直なおしたものやら見当けんとうもつかない。

计划已经延误到这个地步，真不知道该从哪里开始重整。

十年後じゅうねんごの働はたらき方かたがどう変かわっていることやら、誰だれにも予測よそくできない。

十年后的工作方式会变成什么样，谁也无法预测。

10とも～とも　「说是～还是～；既难说～也难说～」

【讲解】并列两个判断或立场，表示无法明确归入其中任一方。常与「言えない」「つかない」「判断しかねる」等否定或保留判断表达搭配。

接续：普通形句子／名词・な形容词词干 ＋ とも ＋ 普通形句子／名词・な形容词词干 ＋ とも。い形容词可用普通形，如「いいとも悪いとも」。

委員会いいんかいは、その提案ていあんについて賛成さんせいとも反対はんたいとも結論けつろんを出ださなかった。

委员会对那项提案既未作出赞成也未作出反对的结论。

この文章ぶんしょうは随筆ずいひつとも評論ひょうろんともつかない独特どくとくの文体ぶんたいで書かかれている。

这篇文章以一种既不像随笔也不像评论的独特文体写成。

今回こんかいの結果けっかは、いいとも悪わるいとも言いえず、評価ひょうかには時間じかんが必要ひつようだ。

这次结果还不能说好也不能说坏，评价它需要时间。

11が/も～なら、～も～だ　「～也真是～，～也真是～」

【讲解】用同一名词重复评价双方，表示一方如此，另一方也同样如此。多用于批评双方都有问题，也可用于感叹彼此相称。

接续：名词 ＋ が／も ＋ 名词 ＋ なら、名词 ＋ も ＋ 名词 ＋ だ。常见「親が親なら子も子だ」「上司も上司なら部下も部下だ」。

親おやが親おやなら子こも子こで、二人ふたりとも約束やくそくを軽かるく考かんがえている。

父母不像样，孩子也一样，两人都把约定看得很轻。

上司じょうしも上司じょうしなら部下ぶかも部下ぶかで、責任せきにんの所在しょざいがまったく見みえない。

上司有上司的问题，下属也有下属的问题，责任归属完全看不清。

企画きかくが企画きかくなら宣伝せんでんも宣伝せんでんで、この失敗しっぱいは当然とうぜんだった。

策划不像样，宣传也不像样，这次失败是理所当然的。

注意：后项常省略具体评价，靠上下文表达“双方都不怎么样”。

12といわず～といわず　「不论～还是～；到处都～」

【讲解】列举两个部位、时间或范围，表示不加区分地全部如此。常用于描写全身、全场、昼夜等范围被同一状态覆盖。

接续：名词 ＋ といわず ＋ 名词 ＋ といわず。后项多为「全体が～」「至る所が～」的状态。

顔かおといわず手てといわず、子こどもたちは泥どろだらけになって帰かえってきた。

孩子们脸也好手也好，浑身是泥地回来了。

昼ひるといわず夜よるといわず、研究室けんきゅうしつでは実験じっけんが続つづけられた。

不分昼夜，研究室里一直进行着实验。

会場かいじょうは入口いりぐちといわず通路つうろといわず、熱心ねっしんな来場者らいじょうしゃであふれていた。

会场入口也好通道也好，到处挤满了热心的来访者。

13もしくは　「或者；或」

【讲解】表示二者择一，语气正式，常用于通知、规章、申请说明和商务文件。比「または」略显书面；在法律文书中需注意层级区分。

接续：名词 ＋ もしくは ＋ 名词／句子 ＋ もしくは ＋ 句子。连接句子时前后结构宜保持并列。

申請書しんせいしょは郵送ゆうそうもしくはオンラインで提出ていしゅつしてください。

请通过邮寄或在线方式提交申请书。

本人確認ほんにんかくにんには、運転免許証うんてんめんきょしょうもしくは旅券りょけんの提示ていじが必要ひつようです。

身份确认需要出示驾驶证或护照。

期限きげんまでに回答かいとうするか、もしくは担当窓口たんとうまどぐちへ延長えんちょうを申もうし出でてください。

请在期限前答复，或向负责窗口申请延期。

注意：日常会话中更常用「または」「それとも」。正式规则文本中避免与「および」混用造成范围歧义。

1不明点ふめいてんは上司じょうし（　　）同僚どうりょう（　　）に相談そうだんしてください。

  1. 1なり／なり
  2. 2といい／といい
  3. 3といわず／といわず
  4. 4やれ／やれ
答案与解析

正确答案：1（なり／なり）

提示从上司或同事中任选对象去咨询，用「なり～なり」。【译文】不明白的地方请找上司或同事商量。

2品質ひんしつ（　　）価格かかく（　　）、この製品せいひんは高たかく評価ひょうかできる。

  1. 1だの／だの
  2. 2といい／といい
  3. 3わ／わで
  4. 4とも／とも
答案与解析

正确答案：2（といい／といい）

列举两个方面后作整体评价，用「といい～といい」。【译文】无论质量还是价格，这款产品都值得高度评价。

3道みちは込こむ（　　）雨あめは降ふる（　　）、到着とうちゃくが遅おくれた。

  1. 1つ／つ
  2. 2かれ／かれ
  3. 3わ／わで
  4. 4ものやら／ことやら
答案与解析

正确答案：3（わ／わで）

多个不利状况叠加导致结果，用「わ～わで」。【译文】又堵车又下雨，抵达晚了。

4遅おそ（　　）早はや（　　）、この問題もんだいは表面化ひょうめんかするだろう。

  1. 1とも／とも
  2. 2かれ／かれ
  3. 3だの／だの
  4. 4なり／なり
答案与解析

正确答案：2（かれ／かれ）

固定表达「遅かれ早かれ」表示或早或晚。【译文】这个问题或早或晚都会浮出水面吧。

5顔かお（　　）手て（　　）、子こどもたちは泥どろだらけだった。

  1. 1といわず／といわず
  2. 2というか／というか
  3. 3もしくは／もしくは
  4. 4やれ／やれ
答案与解析

正确答案：1（といわず／といわず）

不区分部位、全都如此，用「といわず～といわず」。【译文】孩子们脸也好手也好，全是泥。

6申請しんせいは郵送ゆうそう（　　）オンラインで受うけ付つけます。

  2. 2とも
  3. 3もしくは
