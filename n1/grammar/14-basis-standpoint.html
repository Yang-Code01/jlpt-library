N1 语法 · 第 14 单元　基准・对照・无视

整理以事实、前提、立场为基准的判断表达，以及对照、叠加、无视和不顾阻碍的高频句型。

本单元共 13 个知识点，单元末附自测练习。

知识点详解

1を踏まえて　「基于～；踏实考虑～」

【讲解】表示把经验、事实、意见、结果等作为基础，在充分考虑后作出判断或行动。语气正式，常用于会议、报告、政策。

接续：名词 ＋ を踏まえて／を踏まえた ＋ 名词。

調査ちょうさ結果けっかを踏ふまえて、来年度らいねんどの方針ほうしんを決定けっていする。

将基于调查结果决定下一年度方针。

専門家せんもんかの意見いけんを踏ふまえた上うえで、慎重しんちょうに判断はんだんしたい。

希望在参考专家意见后慎重判断。

2を前提として　「以～为前提」

【讲解】表示某判断、计划或制度是在特定条件成立的基础上构成的。常用于合同、制度设计、计划说明。

接续：名词／普通形句子 ＋ こと ＋ を前提として。

来月らいげつの開業かいぎょうを前提ぜんていとして、人員じんいんの配置はいちを進すすめている。

正以次月开业为前提推进人员配置。

双方そうほうが合意ごういすることを前提ぜんていとして、契約けいやく内容ないようを見直みなおす。

以双方同意为前提，重新审视合同内容。

注意：若前提不成立，后续判断或计划也可能失效。

3に言わせれば　「照～说来；让～来说」

【讲解】表示从某人的立场、经验或价值观看，结论会如此。常带主观评价色彩。

接续：人名・身份名词 ＋ に言わせれば。

現場げんばの技術者ぎじゅつしゃに言いわせれば、この計画けいかくはまだ検証けんしょうが足たりない。

照现场技术人员说来，这个计划验证还不充分。

地元じもと住民じゅうみんに言いわせれば、再開発さいかいはつは生活せいかつの便利べんりさだけを高たかめるものではない。

照当地居民说来，重开发并不只是提高生活便利性。

4に引き換え　「与～相反；相比之下」

【讲解】用于对比两个差异明显的对象，后项常带说话人的评价。比「に比べて」对比更鲜明，常含不满或赞叹。

接续：名词／普通形句子 ＋ の ＋ に引き換え。

都市部としぶでは人口じんこうが増ふえているのに引ひき換かえ、地方ちほうでは医療いりょう体制たいせいの維持いじが難むずかしい。

城市人口在增加，相比之下，地方维持医疗体制却很困难。

兄あにが慎重しんちょうなのに引ひき換かえ、弟おとうとは何事なにごとにも大胆だいたんだ。

哥哥谨慎，相比之下弟弟做什么都大胆。

5にも増して　「比～更加～」

【讲解】表示后项程度超过前项，常接时间、以往经验、其他对象。书面语、演讲和报道中常见。

接续：名词 ＋ にも増して。

今年ことしの暑あつさは昨年さくねんにも増まして厳きびしい。

今年的酷暑比去年更加严峻。

品質ひんしつにも増まして重要じゅうようなのは、利用者りようしゃへの説明責任せつめいせきにんである。

比质量更重要的是对用户的说明责任。

6と相まって　「与～相互作用；再加上～」

【讲解】表示两个因素相互结合，使结果更明显。常用于正式分析，后项可为积极或消极结果。

接续：名词 ＋ と相まって。

円安えんやすが原材料高げんざいりょうだかと相あいまって、企業きぎょうの負担ふたんは一段いちだんと増ましている。

日元贬值与原材料上涨相互叠加，企业负担进一步加重。

豊ゆたかな自然しぜんが歴史的れきしてき景観けいかんと相あいまって、多おおくの観光客かんこうきゃくを引ひきつけている。

丰富的自然与历史景观相互映衬，吸引了众多游客。

7をいいことに　「仗着～；利用～」

【讲解】表示利用某种有利条件做不当行为，带明显批判。常见于“无人监督、对方沉默、地位优势”等语境。

接续：名词／普通形句子 ＋ の ＋ をいいことに。

管理者かんりしゃが不在ふざいなのをいいことに、一部いちぶの社員しゃいんが規則きそくを破やぶっていた。

仗着管理人员不在，部分员工违反了规则。

相手あいてが反論はんろんしないのをいいことに、彼かれは責任せきにんを押おし付つけた。

他利用对方不反驳，把责任推给了对方。

8をよそに　「不顾～；置～于不顾」

【讲解】表示无视周围的担心、批评、期待或状况而照常行动。也可表示外部状况没有影响到主体。

接续：名词 ＋ をよそに。

周囲しゅういの心配しんぱいをよそに、彼かれは危険きけんな投資とうしを続つづけた。

他不顾周围人的担心，继续进行危险投资。

市場しじょうの混乱こんらんをよそに、同社どうしゃの株価かぶかは上昇じょうしょうを続つづけた。

不受市场混乱影响，该公司股价继续上涨。

辨析：「をよそに」偏“无视/不受影响”，可含负面或客观；「をものともせずに」偏“把困难不当回事并勇敢克服”，多为正面褒义。

9をものともせずに　「不把～当回事；不畏～」

【讲解】表示面对困难、危险、批评等仍不退缩并坚持行动。多用于赞扬勇气、韧性和突破力。

接续：困难・障碍・危险等名词 ＋ をものともせずに。

厳きびしい批判ひはんをものともせずに、彼女かのじょは研究けんきゅうを続つづけた。

她不畏严厉批评，继续进行研究。

悪天候あくてんこうをものともせずに、救助隊きゅうじょたいは捜索そうさくを続行ぞっこうした。

救援队不惧恶劣天气，继续搜救。

辨析：与「をよそに」相比，本句型更突出挑战阻碍的积极姿态，褒义更强。

10を顧みず・も顧みず　「不顾～；不惜～」

【讲解】表示不考虑危险、损失、个人利益等而采取行动。常用于英雄行为或强烈批判，需看上下文判断褒贬。

接续：名词 ＋ を顧みず／名词 ＋ も顧みず。常见「危険を顧みず」「身の危険も顧みず」。

消防士しょうぼうしは身みの危険きけんも顧かえりみず、建物たてものに取とり残のこされた人ひとを救出きゅうしゅつした。

消防员不顾自身危险，救出了被困在建筑物里的人。

会社かいしゃは環境かんきょうへの影響えいきょうを顧かえりみず、開発かいはつを進すすめた。

公司不顾对环境的影响推进了开发。

11を押して・を押し切って　「冒着～；排除～」

【讲解】「を押して」表示勉强克服不利身体状况或困难去做；「を押し切って」表示排除反对、阻力而贯彻。

接续：病気・疲労・雨等 ＋ を押して／反対・制止・不安等 ＋ を押し切って。

彼かれは病やまいを押おして、最後さいごの講演こうえんに臨のぞんだ。

他抱病参加了最后一场演讲。

住民じゅうみんの反対はんたいを押おし切きって、建設けんせつ計画けいかくは進すすめられた。

建设计划排除居民反对后被推进。

注意：身体不适多用「病を押して」；反对阻力多用「反対を押し切って」。

12はさておき　「暂且不论～；先放下～」

【讲解】表示先把某话题搁置，转而讨论更重要或当前要处理的事项。语气较中性。

接续：名词 ＋ はさておき。

費用ひようの問題もんだいはさておき、まず安全性あんぜんせいを確認かくにんすべきだ。

费用问题暂且不论，首先应确认安全性。

責任せきにんの所在しょざいはさておき、被害ひがいの拡大かくだいを防ふせぐことが先決せんけつである。

责任归属暂且不谈，防止损害扩大才是当务之急。

13はそっちのけで　「把～抛在一边；顾不上～」

【讲解】表示本该做或关注的事情被放到一边，主体专注于别的事。常带批评或调侃。

接续：名词 ＋ はそっちのけで。

仕事しごとはそっちのけで、彼かれは新あたらしい趣味しゅみに夢中むちゅうになっている。

他把工作抛在一边，迷上了新的爱好。

議論ぎろんの本質ほんしつはそっちのけで、発言者はつげんしゃへの批判ひはんばかりが目立めだった。

讨论的本质被抛在一边，对发言者的批评反而格外突出。

辨析：「はさておき」是中性地暂放一边；「はそっちのけで」常暗示本该关注却被忽视。

✏ 自测练习

1調査ちょうさ結果けっか（　　）、改善策かいぜんさくを検討けんとうする。

  1. 1を踏まえて
  2. 2をよそに
  3. 3に引き換え
  4. 4はそっちのけで
答案与解析

正确答案：1（を踏まえて）

已知事实作为基础时用「を踏まえて」。【译文】基于调查结果研究改善措施。

2周囲しゅういの心配しんぱい（　　）、彼かれは危険きけんな挑戦ちょうせんを続つづけた。

  1. 1を前提として
  2. 2をよそに
  3. 3にも増して
  4. 4はさておき
答案与解析

正确答案：2（をよそに）

无视周围担心继续行动，用「をよそに」。【译文】他不顾周围担心，继续危险挑战。

3悪天候あくてんこう（　　）、救助隊きゅうじょたいは捜索そうさくを続つづけた。

  1. 1をものともせずに
  2. 2をいいことに
  3. 3に言わせれば
  4. 4に引き換え
答案与解析

正确答案：1（をものともせずに）

不畏困难积极行动用「をものともせずに」。【译文】救援队不畏恶劣天气继续搜救。

4管理者かんりしゃがいないの（　　）、彼かれらは勝手かってに資料しりょうを持もち出だした。

  1. 1をいいことに
  2. 2にも増して
  3. 3を押して
  4. 4はさておき
答案与解析

正确答案：1（をいいことに）

利用有利条件做不当行为用「をいいことに」。【译文】他们仗着管理人员不在，擅自把资料带走。

5費用ひようの問題もんだい（　　）、まず安全性あんぜんせいを確認かくにんしよう。

  1. 1はさておき
  2. 2を顧みず
  3. 3に言わせれば
  4. 4と相まって
答案与解析

正确答案：1（はさておき）

暂时搁置某话题用「はさておき」。【译文】费用问题先放一边，先确认安全性吧。

6住民じゅうみんの反対はんたい（　　）、計画けいかくは実行じっこうされた。

  1. 1を押し切って
  2. 2を踏まえて
  3. 3にも増して
  4. 4に言わせれば
答案与解析

正确答案：1（を押し切って）

排除反对贯彻行动用「を押し切って」。【译文】计划排除居民反对后被实施。
