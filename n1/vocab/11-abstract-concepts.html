自测练习

1議論が感情的になったため、まず（　　）を整理することにした。

  1. 1論点
  2. 2余波
  3. 3兆し
  4. 4水準
答案与解析

正确答案：1（論点）

讨论前应整理争议的核心点，即「論点」。【译文】讨论变得情绪化，因此决定先整理论点。

2一つの事例だけで全体を断定するのは論理の（　　）だ。

  1. 1妥当
  2. 2飛躍
  3. 3範疇
  4. 4推移
答案与解析

正确答案：2（飛躍）

从个例跳到整体是「飛躍」。【译文】仅凭一个事例断定整体是逻辑跳跃。

3「顕著」の正しい読み方はどれですか。

  1. 1けんちょ
  2. 2げんしょ
  3. 3けんじょ
  4. 4けんちゃく
答案与解析

正确答案：1（けんちょ）

「顕著」は「けんちょ」と読む。【译文】“顕著”读作けんちょ。

4制度の（　　）を理解しないと、条文だけ読んでも誤解しやすい。

  1. 1背景
  2. 2波紋
  3. 3誤差
  4. 4特殊
答案与解析

正确答案：1（背景）

制度产生的上下文、来龙去脉是「背景」。【译文】不了解制度背景，只读条文也容易误解。

5この提案は現場の実情に照らして（　　）だ。

  1. 1妥当
  2. 2曖昧
  3. 3甚だしい
  4. 4漠然
答案与解析

正确答案：1（妥当）

合情合理、适切可用「妥当」。【译文】这个提案从现场实际情况来看是妥当的。
