1選出「津波」の正确读音。

  1. 1つなみ
  2. 2しんぱ
  3. 3つは
  4. 4なみつ
答案与解析

正确答案：1（つなみ）

「津波」读作「つなみ」。

2火山活動が活発化し、専門家は（　　）の可能性を指摘した。

  1. 1避難
  2. 2噴火
  3. 3汚染
  4. 4干ばつ
答案与解析

正确答案：2（噴火）

「噴火」指火山喷发。

3「復旧」と意思最接近的是哪项？

  1. 1受损设施恢复原状
  2. 2资源逐渐减少
  3. 3生态系统遭破坏
  4. 4气压急剧下降
答案与解析

正确答案：1（受损设施恢复原状）

復旧指灾后基础设施等恢复原状。

4大雨で土砂災害の恐れがあり、住民に早めの（　　）が呼びかけられた。

  1. 1避難
  2. 2枯渇
  3. 3繁殖
  4. 4観測
答案与解析

正确答案：1（避難）

「避難」指为躲避灾害而撤离。

5「生態系」的中文意思是？

  1. 1生态系统
  2. 2震源
  3. 3防波堤
  4. 4气团
答案与解析

正确答案：1（生态系统）

生態系表示生物与环境相互作用形成的系统。

枯渇表示资源等枯竭。
