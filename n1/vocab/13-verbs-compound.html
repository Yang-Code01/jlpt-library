答案与解析

正确答案：1（みこむ）

「見込む」は「みこむ」と読み、「需要を見込む」のように予測を表します。

2契約を途中で（　　）ことになった。

  1. 1打ち切る
  2. 2溶け込む
  3. 3譲り合う
  4. 4煮込む
答案与解析

正确答案：1（打ち切る）

「打ち切る」は継続していたものを途中で中止する意味です。

3「耐え抜く」に最も近い意味はどれですか。

  1. 1最後まで耐える
  2. 2急に飛び出す
  3. 3相手に相談する
  4. 4費用を振り込む
答案与解析

正确答案：1（最後まで耐える）

後項「～抜く」は「最後までやり通す」意味を添えます。

4資料の誤りを（　　）ため、原本と照合した。

  1. 1洗い出す
  2. 2駆け込む
  3. 3売り切れる
  4. 4落ち合う
答案与解析

正确答案：1（洗い出す）

「洗い出す」は問題点などを詳しく調べて明らかにすることです。

5「成し遂げる」の語構成として正しい ruby はどれですか。

  1. 1成なし遂とげる
  2. 2成なし遂とげる
  3. 3成せいし遂すいげる
  4. 4成なし遂とげる
答案与解析

正确答案：1（成なし遂とげる）

訓読みの複合動詞は語幹ごとに注音し、送り仮名は ruby の外に置きます。

6資金を全部使ってしまう意味の語はどれですか。

  1. 1使い果たす
  2. 2問い合わせる
  3. 3取り上げる
  4. 4見合わせる
答案与解析

正确答案：1（使い果たす）

「使い果たす」は手元の資金・体力などをすべて使う意味です。
