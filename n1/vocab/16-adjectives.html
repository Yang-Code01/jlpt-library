✏ 自测练习

1改革の効果は（　　）く、数値にもはっきり表れた。

  1. 1著しい
  2. 2卑しい
  3. 3素っ気ない
  4. 4厄介
答案与解析

正确答案：1（著しい）

“著しい”表示显著、明显。

2厳粛で格式のある雰囲気を表す語はどれか。

  1. 1円滑
  2. 2厳か
  3. 3柔軟
  4. 4質素
答案与解析

正确答案：2（厳か）

“厳か”表示庄严、肃穆。

3説明が（　　）だと、利用者は内容を誤解しやすい。

  1. 1曖昧
  2. 2円満
  3. 3頑丈
  4. 4鮮やか
答案与解析

正确答案：1（曖昧）

“曖昧”表示含糊不清。

4「煩わしい」の読みとして正しいものはどれか。

  1. 1わずらわしい
  2. 2まぎらわしい
  3. 3あわただしい
  4. 4なやましい
答案与解析

正确答案：1（わずらわしい）

煩わしい＝わずらわしい。

5「露骨」に最も近い意味はどれか。

  1. 1遠回し
  2. 2あからさま
  3. 3穏やか
  4. 4平凡
答案与解析

正确答案：2（あからさま）

露骨＝毫不掩饰、赤裸裸。

6契約内容を確認するには、（　　）な調査が欠かせない。

  1. 1綿密
  2. 2陰気
  3. 3無邪気
  4. 4華やか
答案与解析

正确答案：1（綿密）

“綿密”表示细致周密。
