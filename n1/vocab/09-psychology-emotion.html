自测练习

1選出「憤り」の正确读音。

  1. 1いきどおり
  2. 2ふんり
  3. 3おこり
  4. 4いかどり
答案与解析

正确答案：1（いきどおり）

「憤り」读作「いきどおり」。

2試験直前になると、準備不足への（　　）が募った。

  1. 1焦り
  2. 2寛容
  3. 3健気
  4. 4陶酔
答案与解析

正确答案：1（焦り）

「焦りが募る」表示焦躁感越来越强。

3「未練」と意思最接近的是哪项？

  1. 1难以割舍的留恋
  2. 2突然的愤怒
  3. 3强烈的自卑
  4. 4冷静的判断
答案与解析

正确答案：1（难以割舍的留恋）

未練指对人或事仍恋恋不舍。

4彼は批判されても（　　）を張り、謝ろうとしなかった。

  1. 1意地
  2. 2憂鬱
  3. 3慈悲
  4. 4戸惑い
答案与解析

正确答案：1（意地）

「意地を張る」指固执己见、逞强。

5「劣等感」的中文意思是？

  1. 1自卑感
  2. 2使命感
  3. 3责任感
  4. 4亲近感
答案与解析

正确答案：1（自卑感）

劣等感表示觉得自己不如别人的心理。

6幼い子が家族を支えようとする姿は実に（　　）だった。

  1. 1健気
  2. 2陰気
  3. 3強引
  4. 4無頓着
答案与解析

正确答案：1（健気）

健気表示弱小者努力承受、令人怜爱的样子。
