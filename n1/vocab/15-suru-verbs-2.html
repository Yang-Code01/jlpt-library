自测练习

1「把握」の正しい読み方はどれですか。

  1. 1はあく
  2. 2ばあく
  3. 3はくあく
  4. 4はいあく
答案与解析

正确答案：1（はあく）

「把握」は「はあく」と読み、状況などをしっかり理解する意味です。

2「濫用する」と自然に結び付く語はどれですか。

  1. 1権限
  2. 2夕焼け
  3. 3靴下
  4. 4拍手
答案与解析

正确答案：1（権限）

「権限を濫用する」は典型的な搭配です。

3「赴任する」の意味はどれですか。

  1. 1任地へ行く
  2. 2資料を捨てる
  3. 3意見を曲げる
  4. 4市場を広げる
答案与解析

正确答案：1（任地へ行く）

「海外支社に赴任する」のように、任地へ向かう意味です。

4「漏洩」の正しい読み方はどれですか。

  1. 1ろうえい
  2. 2ろうせつ
  3. 3もれえい
  4. 4ろえい
答案与解析

正确答案：1（ろうえい）

「情報漏洩」で頻出し、「ろうえい」と読みます。

5「離脱する」に近い意味はどれですか。

  1. 1抜け出る
  2. 2守り抜く
  3. 3繰り返す
  4. 4翻訳する
答案与解析

正确答案：1（抜け出る）

「組織から離脱する」は組織を抜けることです。

6「連携する」は主に何を表しますか。

  1. 1協力して動く
  2. 2完全に否定する
  3. 3資源を埋める
  4. 4計画を廃止する
答案与解析

正确答案：1（協力して動く）

「自治体と企業が連携する」のように協力関係を表します。
