✏ 自测练习

1契約違反で相手に損害が出た場合、通常求められるのは（　　）である。

  1. 1賠償
  2. 2世論
  3. 3仮説
  4. 4余暇
答案与解析

正确答案：1（賠償）

「賠償」は相手に与えた損害を金銭などで補うこと。

2「控訴」の読み方はどれか。

  1. 1こうそ
  2. 2こくそ
  3. 3こうそう
  4. 4くうそ
答案与解析

正确答案：1（こうそ）

第一審の判決に不服があり、上級裁判所に審理を求めること。

3警察が違法薬物の密売組織を（　　）した。

  1. 1締結
  2. 2摘発
  3. 3相続
  4. 4免許
答案与解析

正确答案：2（摘発）

隠れて行われている不正や犯罪を明るみに出す場合に使う。

4「被告」と対になる、訴えを起こした側はどれか。

  1. 1原告
  2. 2検事
  3. 3弁護士
  4. 4証人
答案与解析

正确答案：1（原告）

民事訴訟で訴えを起こした側が「原告」。

5「不正」の自然な使い方はどれか。

  1. 1不正を働く
  2. 2不正を寝る
  3. 3不正を晴れる
  4. 4不正を咲く
答案与解析

正确答案：1（不正を働く）

「不正を働く」は不法・不当な行為をするという定型的な言い方。

6容疑者の身柄を一時的に自由にしないことを表す語はどれか。

  1. 1釈放
  2. 2拘束
  3. 3公正
  4. 4保証
答案与解析

正确答案：2（拘束）

「拘束」は身体の自由を制限すること。
