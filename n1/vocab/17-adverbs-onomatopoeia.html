自测练习

1会議資料は（　　）配布しておいてください。

  1. 1あらかじめ
  2. 2てっきり
  3. 3そわそわ
  4. 4ぼつぼつ
答案与解析

正确答案：1（あらかじめ）

“あらかじめ”表示事先。

2被害は町全体に及び、建物は（　　）倒壊した。

  1. 1ことごとく
  2. 2しいて
  3. 3もっぱら
  4. 4いかにも
答案与解析

正确答案：1（ことごとく）

“ことごとく”表示全部、无一例外。

3「即座に」の読みとして正しいものはどれか。

  1. 1そくざに
  2. 2しょうざに
  3. 3そくせきに
  4. 4しょくざに
答案与解析

正确答案：1（そくざに）

即座に＝そくざに。

4彼は専門外だが、（　　）意見を求めるなら簡潔に聞こう。

  1. 1しいて
  2. 2断然
  3. 3無性に
  4. 4ずらっと
答案与解析

正确答案：1（しいて）

“しいて”表示硬要、勉强。

5発表前で落ち着かない様子を表す語はどれか。

  1. 1くっきり
  2. 2そわそわ
  3. 3ぎっしり
  4. 4うっとり
答案与解析

正确答案：2（そわそわ）

“そわそわ”表示坐立不安。

6予想どおりの結果を表す表現はどれか。

  1. 1案の定
  2. 2何しろ
  3. 3かろうじて
  4. 4一概に
答案与解析

正确答案：1（案の定）

“案の定”表示果然、正如所料。
