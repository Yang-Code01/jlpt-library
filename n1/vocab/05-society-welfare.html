1年金や介護などを支える制度全体に近い語は（　　）である。

  1. 1福祉
  2. 2端末
  3. 3判決
  4. 4試薬
答案与解析

正确答案：1（福祉）

「福祉」は生活の安定や幸福を社会的に支える仕組みを指す。

  2. 2どくめい
  3. 3とくみょう
  4. 4あんめい

名前を明らかにしないこと。

3所得の差が広がることは「所得（　　）の拡大」と言う。

  1. 1格差
  2. 2取材
  3. 3端末
  4. 4量刑

6「世論」に最も近い意味はどれか。

  2. 2実験用の薬品

  4. 4機械の部品

「世論」は社会一般の人々の意見。
