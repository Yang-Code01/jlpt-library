✏ 自测练习

1「為替」の正しい読み方はどれか。

  1. 1ためかえ
  2. 2かわし
  3. 3かわせ
  4. 4いかえ
答案与解析

正确答案：3（かわせ）

「為替」は熟字訓で「かわせ」と読み、汇兑或汇率を指す。

2原油価格が急に大きく上がることを表す語はどれか。

  1. 1暴騰
  2. 2暴落
  3. 3下落
  4. 4緊縮
答案与解析

正确答案：1（暴騰）

「暴騰」は相場や価格が急激に上がること。

3企業が銀行から設備資金を借りる場合、「銀行から（　　）を受ける」という。

  1. 1関税
  2. 2融資
  3. 3配当
  4. 4歳出
答案与解析

正确答案：2（融資）

「融資を受ける」は贷款或融资を受けるという定型表現。

4財政支出を抑える政策に近い語はどれか。

  1. 1緊縮
  2. 2拡大
  3. 3上場
  4. 4出資
答案与解析

正确答案：1（緊縮）

「緊縮」は财政や金融を引き締めること。

5「破綻」に最も近い意味はどれか。

  1. 1制度や経営が立ち行かなくなる
  2. 2物価が少し下がる
  3. 3株主に利益を配る
  4. 4統計を発表する
答案与解析

正确答案：1（制度や経営が立ち行かなくなる）

「破綻」は経営・財政・交渉などが行き詰まり壊れること。

6業績予想を良い方向へ修正することは？

  1. 1下方修正
  2. 2上方修正
  3. 3景気後退
  4. 4含み損
答案与解析

正确答案：2（上方修正）

利益や売上の見通しを上へ直す場合は「上方修正」。
