✏ 自测练习

1选出「罷免」的正确读音。

  1. 1はめん
  2. 2ひめん
  3. 3ばめん
  4. 4ひまん
答案与解析

正确答案：2（ひめん）

「罷免」读作「ひめん」，指依法解除职务。

2条約を正式に承認することを何というか。

  1. 1調印
  2. 2批准
  3. 3通達
  4. 4答申
答案与解析

正确答案：2（批准）

「批准」用于国会或国家正式承认条约等。【译文】正式承认条约称为批准。

3世論の批判を受け、政府は発言を（　　）した。

  1. 1撤回
  2. 2発足
  3. 3管轄
  4. 4出馬
答案与解析

正确答案：1（撤回）

「発言を撤回する」是固定搭配，表示收回发言。

4「諮問」に最も近い意味はどれか。

  1. 1意見を求める
  2. 2議席を増やす
  3. 3警備を固める
  4. 4条約に署名する
答案与解析

正确答案：1（意見を求める）

「諮問」是向审议会等征询意见。

5（　　）は政府案に対し、説明不足だと追及した。

  1. 1野党
  2. 2財源
  3. 3領土
  4. 4官庁
答案与解析

正确答案：1（野党）

与政府案对立并追究责任的主体通常是「野党」。

6「遺憾」在政治外交语境中常表示什么？

  1. 1强烈遗憾或抗议
  2. 2财政收入
  3. 3联合组阁
  4. 4审计手续
答案与解析

正确答案：1（强烈遗憾或抗议）

外交声明中的「遺憾」常带有正式抗议色彩。
