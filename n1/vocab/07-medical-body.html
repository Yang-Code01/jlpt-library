✏ 自测练习

1選出「後遺症」の正确读音。

  1. 1こういしょう
  2. 2ごいしょう
  3. 3こうゆいしょう
  4. 4あといしょう
答案与解析

正确答案：1（こういしょう）

「後遺症」读作「こういしょう」，指疾病或事故后留下的症状。

2手術前に（　　）をかけ、痛みを感じないようにした。

  1. 1免疫
  2. 2麻酔
  3. 3疲労
  4. 4脈拍
答案与解析

正确答案：2（麻酔）

「麻酔をかける」是典型搭配，表示实施麻醉。

3「処方」と意思最接近的是哪项？

  1. 1薬の使い方を医師が指示すること
  2. 2体力を回復すること
  3. 3症状が急に出ること
  4. 4病原体に感染すること
答案与解析

正确答案：1（薬の使い方を医師が指示すること）

処方指医生开药方或指示用药。

4感染症を防ぐには、個人の（　　）だけでなく社会全体の対策も必要だ。

  1. 1食欲
  2. 2免疫
  3. 3動悸
  4. 4腫瘍
答案与解析

正确答案：2（免疫）

「免疫」指抵抗病原体的身体机能。

5「発作」的中文意思是？

  1. 1突然发作
  2. 2康复
  3. 3处方
  4. 4体检
答案与解析

正确答案：1（突然发作）

発作表示疾病症状突然发生，如心臓発作。

6医師は副作用の有無を（　　）するため、再診を求めた。

  1. 1観察
  2. 2処方
  3. 3縫合
  4. 4発熱
答案与解析

正确答案：1（観察）

「観察する」可用于医学上观察病情或副作用。
