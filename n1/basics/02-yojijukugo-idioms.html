自测练习

1信頼しんらいは（　　）に築きずけるものではない。

  1. 1一朝一夕
  2. 2右往左往
  3. 3公私混同
  4. 4喜怒哀楽
答案与解析

正确答案：1（一朝一夕）

「一朝一夕に～ない」表示“不是短时间能……”。【译文】信任不是一朝一夕能建立的。

2現場げんばでは（　　）な判断はんだんが求もとめられる。

  1. 1臨機応変
  2. 2因果応報
  3. 3絶体絶命
  4. 4自画自賛
答案与解析

正确答案：1（臨機応変）

「臨機応変」表示随机应变。【译文】现场需要随机应变的判断。

3議論ぎろんの途中とちゅうで（　　）を挟はさまないでください。

  1. 1口
  2. 2耳
  3. 3首
  4. 4腹
答案与解析

正确答案：1（口）

「口を挟む」表示插嘴。【译文】请不要在讨论中途插嘴。

4結果けっかの発表はっぴょうを（　　）を長ながくして待まつ。

  1. 1目
  2. 2首
  3. 3手
  4. 4腹
答案与解析

正确答案：2（首）

「首を長くする」表示翘首以盼。【译文】翘首等待结果公布。

5「本末転倒」の意味として最も近いものはどれか。

  1. 1本质与枝节颠倒
  2. 2心情非常激动
  3. 3准备极其周到
  4. 4意见完全一致
答案与解析

正确答案：1（本质与枝节颠倒）

「本末転倒」即本末倒置。【译文】“本末転倒”的意思最接近哪一项？
