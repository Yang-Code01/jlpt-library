二、高频多义词 10 个

1かける（掛ける・懸ける・賭ける）

【义项】挂上；花费；打电话；乘以；赌上。

  • 壁かべに絵えを掛かける。
    把画挂在墙上。
  • 時間じかんをかけて調査ちょうさする。
    花时间调查。
  • 名誉めいよを懸かけて戦たたかう。
    赌上名誉而战。

2きく（聞く・聴く・効く・利く）

【义项】听；询问；奏效；灵敏好使。

  • 講演こうえんを聴きく。
    听讲演。
  • 道みちを聞きく。
    问路。
  • 薬くすりが効きく。
    药起作用。
  • 融通ゆうずうが利きく。
    能灵活变通。

3たつ（立つ・建つ・経つ・断つ）

【义项】站立；建成；时间经过；切断。

  • 席せきを立たつ。
    离席。
  • 駅前えきまえにビルが建たつ。
    车站前建起大楼。
  • 十年じゅうねんが経たつ。
    经过十年。
  • 連絡れんらくを断たつ。
    切断联系。

4はかる（測る・量る・計る・図る・謀る）

【义项】测量；称量；计算安排；谋求；谋划。

  • 距離きょりを測はかる。
    测量距离。
  • 重おもさを量はかる。
    称重量。
  • 解決かいけつを図はかる。
    谋求解决。
  • 暗殺あんさつを謀はかる。
    策划暗杀。

5とる（取る・採る・撮る・執る）

【义项】拿取；采用；拍摄；执行掌管。

  • 資格しかくを取とる。
    取得资格。
  • 新制度しんせいどを採とる。
    采用新制度。
  • 写真しゃしんを撮とる。
    拍照。
  • 指揮しきを執とる。
    担任指挥。

6ひく（引く・弾く・挽く）

【义项】拉；查；减；弹奏；研磨。

  • 線せんを引ひく。
    划线。
  • 辞書じしょを引ひく。
    查字典。
  • 五から二を引ひく。
    从五中减二。
  • ピアノを弾ひく。
    弹钢琴。
  • 豆まめを挽ひく。
    磨豆子。

7あげる（上げる・挙げる・揚げる）

【义项】提高；列举；举行；油炸；升起。

  • 成果せいかを上あげる。
    取得成果。
  • 例れいを挙あげる。
    举例。
  • 式しきを挙あげる。
    举行仪式。
  • 天ぷらを揚あげる。
    炸天妇罗。

8おさめる（収める・納める・治める・修める）

【义项】收纳；缴纳；治理；修习。

  • 成果せいかを収おさめる。
    取得成果。
  • 税金ぜいきんを納おさめる。
    缴纳税金。
  • 国くにを治おさめる。
    治理国家。
  • 学問がくもんを修おさめる。
    修习学问。

9あたる（当たる）

【义项】碰上；命中；相当于；负责；晒取暖。

  • 予想よそうが当あたる。
    猜测命中。
  • 罰ばちが当あたる。
    遭报应。
  • 担当たんとうに当あたる。
    负责担当。
  • 日ひに当あたる。
    晒太阳。

10もつ（持つ）

【义项】拿；拥有；维持；承担。

  • 荷物にもつを持もつ。
    拿行李。
  • 責任せきにんを持もつ。
    承担责任。
  • 会議かいぎが一時間じかん持もつ。
    会议持续一小时。
  • 家庭かていを持もつ。
    成家。

✏ 自测练习

1損害そんがいを（　　）する。

  1. 1保証
  2. 2保障
  3. 3補償
  4. 4保章
答案与解析

正确答案：3（補償）

损失、损害后接「補償」表示赔偿补偿。【译文】补偿损失。

2責任せきにんを（　　）する。

  1. 1追求
  2. 2追及
  3. 3追究
  4. 4追給
答案与解析

正确答案：2（追及）

追究责任用「追及」；探究原因可用「追究」。【译文】追究责任。

3左右さゆう（　　）の図形ずけい。

  1. 1対象
  2. 2対照
  3. 3対称
  4. 4対症
答案与解析

正确答案：3（対称）

图形左右对称写作「対称」。【译文】左右对称的图形。

4薬くすりが（　　）。

  1. 1聞く
  2. 2聴く
  3. 3効く
  4. 4訊く
答案与解析

正确答案：3（効く）

药物奏效用「効く」。【译文】药起作用。

5税金ぜいきんを（　　）。

  1. 1収める
  2. 2納める
  3. 3治める
  4. 4修める
答案与解析

正确答案：2（納める）

缴纳税金用「納める」。【译文】缴纳税金。

6人事じんじ（　　）で部署ぶしょが変かわった。

  1. 1移動
  2. 2異動
  3. 3異同
  4. 4井戸
答案与解析

正确答案：2（異動）

人事调动写作「異動」。【译文】因人事调动换了部门。
