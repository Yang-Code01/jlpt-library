N5 语法 · 第 2 单元　核心助词（は・が・を・に・へ・で）

掌握は・が・を・に・へ・で的核心功能，建立日语句子中“谁、做什么、在哪里、去哪里”的骨架。

本单元共 8 个知识点，单元末附自测练习。

1 は2 が3 を4 に5 へ6 で7 で8 が✏ 自测练习

知识点详解

1は　主题标记（读作 wa）

【讲解】「は」提示句子的主题，意思是“说到……、至于……”。它写作は，读作wa，后面通常说明这个主题的身份、性质或动作。主题不一定等于语法主语，重点在“拿什么来谈”。

接续：名词 ＋ は ＋ 说明（名词句・形容词句・动词句）

私わたしは学生がくせいです。

我是学生。

今日きょうは寒さむいです。

今天很冷。

田中たなかさんは毎朝まいあさコーヒーを飲のみます。

田中先生每天早上喝咖啡。

辨析：「は」把某事物拿出来作为话题；真正执行动作或呈现状态的成分，很多时候要用「が」来标记。

2が　主语标记・新信息

【讲解】「が」标记主语，常用于疑问词作主语、第一次引入某人某物，或说明自然发生的状态和自动词动作。它把焦点放在“谁/什么”上，回答“哪个、谁、什么”。

接续：名词 ＋ が ＋ 谓语；疑问词 ＋ が；名词 ＋ が ＋ 自动词

だれが来きますか。

谁来？

教室きょうしつに学生がくせいがいます。

教室里有学生。

雨あめが降ふっています。

正在下雨。

は/が 辨析：「は」提示旧信息或话题，后面是重点；「が」提示新信息或主语本身，前面是重点。问「だれが」时，答案也常用「が」。

3を　宾语标记・经过点・离开点

【讲解】「を」读作o，基本功能是标记他动词的宾语，表示动作直接作用的对象。N5也常见“经过某处”和“离开某处”的用法，如散步经过公园、离开家。

接续：名词 ＋ を ＋ 他动词；场所 ＋ を ＋ 移动动词；场所 ＋ を ＋ 出る・降りる

水みずを飲のみます。

喝水。

公園こうえんを散歩さんぽします。

在公园散步/经过公园散步。

朝あさ、家いえを出でます。

早上离开家。

注意：「を」只标记直接对象，不用于存在地点。说“房间里有猫”要用「部屋に猫がいます」，不能说「部屋を」。

4に　存在地点・时间点・到达点・动作对象

【讲解】「に」表示静态存在的地点、具体时间点、移动的到达点，也能标记动作面向的对象。它常带有“落点、归着点”的感觉，是N5中功能最广的助词之一。

接续：地点 ＋ に ＋ いる・ある；时间点 ＋ に；地点 ＋ に ＋ 行く；对象 ＋ に ＋ 会う・話す

机つくえの上うえに本ほんがあります。

桌子上有书。

七時しちじに起おきます。

七点起床。

友達ともだちに会あいます。

见朋友。

学校がっこうに行いきます。

去学校。

注意：「今日・明日・毎日」等相对时间通常不加「に」；说「明日に行きます」一般不自然。

5へ　移动方向

【讲解】「へ」写作へ，读作e，表示移动的方向或朝向，常和「行く・来る・帰る」等移动动词一起用。它强调“往某方向去”，不一定强调最终到达。

接续：地点・方向 ＋ へ ＋ 行く・来る・帰る 等移动动词

日本にほんへ行いきます。

去日本。

来週らいしゅう、国くにへ帰かえります。

下周回国。

こちらへどうぞ。

请往这边来。

に/へ 辨析：移动场景中「に」强调到达点，使用更普遍；「へ」强调方向。日常会话里「学校に行く」比「学校へ行く」更常见。

6で　动作发生场所

【讲解】「で」表示动作进行或事件发生的场所，相当于“在……做……”。它用于动态动作，和表示存在地点的「に」不同；区分两者能避免很多初级错误。

接续：地点 ＋ で ＋ 动作动词（食べる・勉強する・買う 等）

図書館としょかんで勉強べんきょうします。

在图书馆学习。

駅えきで友達ともだちを待まちます。

在车站等朋友。

家いえで晩ばんごはんを食たべます。

在家吃晚饭。

に/で 对比：「部屋にいます」是存在；「部屋で勉強します」是在那里做动作。いる・ある通常用「に」，动作动词通常用「で」。

7で　手段・工具・材料・范围

【讲解】「で」还可表示完成动作的手段、工具、材料，以及限定比较或判断的范围。中文常译为“用……、以……、在……之中”。根据谓语类型判断具体含义。

接续：名词 ＋ で ＋ 动作；范围 ＋ で ＋ 一番・いちばん 等

ペンで名前なまえを書かきます。

用钢笔写名字。

木きで机つくえを作つくります。

用木头做桌子。

クラスで山田やまださんが一番いちばん背せが高たかいです。

班里山田个子最高。

注意：看见「で」不要只翻译成“在”。它也可能表示工具、语言、交通方式、材料或范围，要结合后面的动词和句意判断。

8が　句中接续：但是

【讲解】句中「が」可连接两个分句，表示轻微转折或铺垫，相当于“但是、不过”。在请求或开场白中常用「すみませんが」，语气比直接说出要求更委婉自然。

接续：句子 ＋ が、句子；礼貌表达 ＋ が、请求・说明

すみませんが、駅えきはどこですか。

不好意思，请问车站在哪里？

この本ほんは高たかいですが、面白おもしろいです。

这本书贵，但是有趣。

日本語にほんごの勉強べんきょうは難むずかしいですが、楽たのしいです。

学习日语很难，但是很有趣。

注意：这个「が」不是主语助词，而是接续助词。位置在分句后面，后面继续接另一个句子。

✏ 自测练习

1私わたし（　　）学生がくせいです。

  1. 1は
  2. 2を
  3. 3で
  4. 4へ
答案与解析

正确答案：1（は）

这里把「私」作为话题来说明身份，用主题助词「は」（读wa）。【译文】我是学生。

2だれ（　　）来きますか。

  1. 1は
  2. 2が
  3. 3を
  4. 4で
答案与解析

正确答案：2（が）

疑问词「だれ」作主语时通常用「が」，询问“谁来”。【译文】谁来？

3毎朝まいあさ、水みず（　　）飲のみます。

  1. 1に
  2. 2で
  3. 3を
  4. 4へ
答案与解析

正确答案：3（を）

「飲みます」是他动词，直接对象「水」用宾语助词「を」标记。【译文】每天早上喝水。

4机つくえの上うえ（　　）本ほんがあります。

  1. 1で
  2. 2に
  3. 3を
  4. 4へ
答案与解析

正确答案：2（に）

「あります」表示存在，存在地点用「に」。【译文】桌子上有书。

5図書館としょかん（　　）勉強べんきょうします。

  1. 1で
  2. 2に
  3. 3へ
  4. 4を
答案与解析

正确答案：1（で）

「勉強します」是动作，动作发生的场所用「で」。【译文】在图书馆学习。

6すみません（　　）、トイレはどこですか。

  1. 1を
  2. 2へ
  3. 3が
  4. 4に
答案与解析

正确答案：3（が）

「すみませんが」是委婉提问或请求的固定开场，句中「が」表示铺垫。【译文】不好意思，请问厕所在哪里？
