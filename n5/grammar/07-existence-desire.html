N5 语法 · 第 7 单元　存在句与愿望表达

学习「ある／いる」存在句，以及想要、想做、选择、喜欢和擅长等基础表达。

本单元共 10 个知识点，单元末附自测练习。

1 があります2 がいます3 存在句与所在句4 がほしい5 たい6 をください7 にする8 のがすき9 のが上手10 のが下手自测练习

知识点详解

1があります　「有～」（无生命物）

【讲解】「あります」表示无生命物、植物、事情或抽象事物的存在，中文可译为“有”。存在的东西通常用「が」标记，场所用「に」表示。

接续：场所 ＋ に ＋ 名词（无生命物）＋ が ＋ あります

机つくえの上うえに本ほんがあります。

桌上有书。

駅えきの前まえに銀行ぎんこうがあります。

车站前有银行。

2がいます　「有～」（有生命物）

【讲解】「います」表示人、动物等有生命物的存在。存在对象用「が」，所在场所用「に」。和动作中的「ています」不同，这里的「います」是存在动词。

接续：场所 ＋ に ＋ 名词（人・动物）＋ が ＋ います

教室きょうしつに学生がくせいがいます。

教室里有学生。

庭にわに猫ねこがいます。

院子里有猫。

注意：人和动物不用「あります」。说「学生があります」是错误的。

3存在句与所在句　「に〜が／は〜に」

【讲解】「场所に物があります」重点回答“哪里有什么”；「物は场所にあります」重点说明“某物在哪里”。两者意思接近，但话题和焦点不同。

接续：场所 ＋ に ＋ 物・人 ＋ が ＋ あります／います；物・人 ＋ は ＋ 场所 ＋ に ＋ あります／います

部屋へやにテレビがあります。

房间里有电视。（说房间里有什么）

テレビは部屋へやにあります。

电视在房间里。（说电视在哪里）

辨析：初次介绍存在常用「が」；把已知对象拿出来说明位置时常用「は」。

4がほしい　「想要～」

【讲解】「ほしい」表示第一人称想要某个东西，对象用「が」。询问第二人称愿望可用「何がほしいですか」。第三人称内心愿望不能直接断定。

接续：名词 ＋ が ＋ ほしいです

わたしは新あたらしいパソコンがほしいです。

我想要一台新电脑。

誕生日たんじょうびに何なにがほしいですか。

生日想要什么？

注意：不要直接断定「田中さんは車がほしいです」，他人愿望需用更间接表达。

5たい　「想做～」

【讲解】「たい」接动词ます形词干，表示说话人想做某事。整体活用同い形容词，如「行きたくない」。宾语可用「を」或「が」，「が」更突出愿望对象。

接续：动词ます形词干 ＋ たいです（否定：たくないです）

日本にほんへ行いきたいです。

想去日本。

ジュースを飲のみたいです。

想喝果汁。

注意：「たい」不是接动词辞书形，不能说「行くたい」，要说「行きたい」。

6をください　「请给我～」

【讲解】「をください」用于请求给自己某物，常见于购物、点餐、索取资料等场景。数量词通常放在名词后、动词前，如「りんごを三つください」。

接续：名词 ＋ を ＋ ください／名词 ＋ を ＋ 数量词 ＋ ください

コーヒーをください。

请给我咖啡。

りんごを三みっつください。

请给我三个苹果。

この切手きってを五ご枚まいください。

请给我五张这种邮票。

7にする　「决定要～」

【讲解】「にする」表示从多个选项中决定选择某物，常用于点餐、购物、选颜色或时间。礼貌体「にします」意思是“我决定要……”。

接续：名词 ＋ にします

わたしはコーヒーにします。

我选咖啡。

昼ひるごはんはカレーにします。

午饭决定吃咖喱。

8のがすき　「喜欢做～」

【讲解】动词辞书形后加「の」把动作名词化，再接「が好き」表示喜欢做某事。这里喜欢的是“做这个动作”本身，而不是某个具体物品。

接续：动词辞书形 ＋ の ＋ が ＋ 好きです

わたしは本ほんを読よむのが好すきです。

我喜欢读书。

音楽おんがくを聞きくのが好すきです。

喜欢听音乐。

9のが上手　「擅长做～」

【讲解】「动词辞书形＋のが上手」表示擅长做某事，常用于评价别人或夸奖对方。说自己时直接用「上手」容易显得自夸，可改用「得意です」。

接续：动词辞书形 ＋ の ＋ が ＋ 上手です

田中たなかさんは歌うたを歌うたうのが上手じょうずです。

田中先生很擅长唱歌。

兄あには泳およぐのが上手じょうずです。

哥哥擅长游泳。

注意：夸别人用「上手」自然；说自己建议用「得意です」，如「料理が得意です」。

10のが下手　「不擅长做～」

【讲解】「动词辞书形＋のが下手」表示不擅长做某事。它描述技能水平较弱，语气直接。若想更委婉，可说「あまり上手じゃありません」。

接续：动词辞书形 ＋ の ＋ が ＋ 下手です

わたしは絵えを描かくのが下手へたです。

我不擅长画画。

弟おとうとは漢字かんじを書かくのが下手へたです。

弟弟不擅长写汉字。

辨析：「好き／嫌い」说喜好；「上手／下手」说能力，不能混为一谈。

自测练习

1庭にわに花はなが（　　）。

  1. 1います
  2. 2あります
  3. 3します
  4. 4ほしいです
答案与解析

正确答案：2（あります）

花、树等植物的存在一般用「あります」，不是「います」。【译文】院子里有花。

2教室きょうしつに先生せんせいが（　　）。

  1. 1あります
  2. 2います
  3. 3ほしいです
  4. 4ください
答案与解析

正确答案：2（います）

「先生」是人，表示存在要用「います」。【译文】教室里有老师。

3テレビ（　　）部屋へやにあります。

  1. 1が
  2. 2を
  3. 3は
  4. 4で
答案与解析

正确答案：3（は）

说明已知对象“电视在哪里”时，用「テレビは部屋にあります」。【译文】电视在房间里。

4わたしは新あたらしい自転車じてんしゃ（　　）ほしいです。

  1. 1を
  2. 2に
  3. 3で
  4. 4が
答案与解析

正确答案：4（が）

「ほしい」表示想要东西时，对象一般用「が」标记。【译文】我想要一辆新自行车。

5週末しゅうまつ、映画えいがを見み（　　）です。

  1. 1たい
  2. 2ほしい
  3. 3ください
  4. 4にします
答案与解析

正确答案：1（たい）

「想看」用动词ます形词干「見」＋「たい」。「ほしい」用于想要东西。【译文】周末想看电影。

6わたしは本ほんを読よむ（　　）好すきです。

  1. 1ことを
  2. 2のが
  3. 3に
  4. 4を
答案与解析

正确答案：2（のが）

表示喜欢做某事用「动词辞书形＋のが好きです」。【译文】我喜欢读书。
