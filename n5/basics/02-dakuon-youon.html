N5 基础 · 02 浊音・半浊音・拗音・促音・长音

掌握清音之外的核心拼读规则：两点、圆点、小字、停顿与拉长。

本单元共 6 个知识点，单元末附自测练习。

1 浊音2 半浊音3 拗音4 促音5 长音6 常见错误自测练习

知识点详解

1浊音：が・ざ・だ・ば 行

【讲解】在假名右上角加两点「゛」形成浊音。读音从清音变为带声带振动的音。

行＼段あ段い段う段え段お段
が行が / ガgaぎ / ギgiぐ / グguげ / ゲgeご / ゴgo
ざ行ざ / ザzaじ / ジjiず / ズzuぜ / ゼzeぞ / ゾzo
だ行だ / ダdaぢ / ヂji / dziづ / ヅzuで / デdeど / ドdo
ば行ば / バbaび / ビbiぶ / ブbuべ / ベbeぼ / ボbo
注意：现代标准语里「ぢ」通常与「じ」同音（ji），为区别字形也可写 dzi；「づ」通常与「ず」同音（zu）。「ぢ」「づ」使用范围很窄，N5 阶段先认读即可。

2半浊音：ぱ行

【讲解】は行右上角加小圆点「゜」形成半浊音ぱ行。

行＼段あ段い段う段え段お段
ぱ行ぱ / パpaぴ / ピpiぷ / プpuぺ / ペpeぽ / ポpo

3拗音：小字ゃ・ゅ・ょ

【讲解】い段假名后接小写「ゃ・ゅ・ょ」组成一拍拗音。小字不能读成独立一拍。

基字ゃゅょ
ききゃkyaきゅkyuきょkyo
ぎぎゃgyaぎゅgyuぎょgyo
ししゃshaしゅshuしょsho
じじゃjaじゅjuじょjo
ぢ（稀）ぢゃja / dyaぢゅju / dyuぢょjo / dyo
ちちゃchaちゅchuちょcho
ににゃnyaにゅnyuにょnyo
ひひゃhyaひゅhyuひょhyo
びびゃbyaびゅbyuびょbyo
ぴぴゃpyaぴゅpyuぴょpyo
みみゃmyaみゅmyuみょmyo
りりゃryaりゅryuりょryo
例：「きや」是两拍 ki-ya；「きゃ」是一拍 kya。

4促音っ：停顿一拍

【讲解】小写「っ/ッ」不读出具体元音，而是在后一个音前停顿一拍，并让后音更紧。它自己也占一拍。

きって（kitte）

邮票（切手きって）：ki・っ・te，共 3 拍。

学校がっこう（gakkō）

学校：が・っ・こ・う，共 4 拍。

5长音：把元音拉长一拍

【讲解】长音不是重读，而是多占一拍。常见规则：あ段＋あ、い段＋い、う段＋う、え段＋い/え、お段＋う/お；片假名外来语多用「ー」。

类型例词说明
あ段＋あおかあさんka 后的 a 拉长
え段＋い先生せんせいせ・ん・せ・い，共 4 拍
お段＋う学校がっこうこ＋う 表长音
片假名ーコーヒー两个「ー」各拉长一拍

6常见错误

易混：病院びょういん（医院）是 びょ・う・い・ん；美容院びよういん（美容院）是 び・よ・う・い・ん。拗音「びょ」和普通「びよ」拍数不同，意思也不同。
易错：长音漏读会改变词义，如 おばさん（阿姨）与 おばあさん（奶奶）。

自测练习

1「ざ」的罗马音是？

  1. 1sa
  2. 2za
  3. 3ja
  4. 4da
答案与解析

正确答案：2（za）

さ加浊点变ざ，读 za。

2「ぴ」属于哪一类？

  1. 1清音
  2. 2浊音
  3. 3半浊音
  4. 4长音
答案与解析

正确答案：3（半浊音）

は行加小圆点形成ぱ行，ぴ读 pi。

3「しゅ」的罗马音是？

  1. 1shu
  2. 2syu
  3. 3shi-yu
  4. 4chu
答案与解析

正确答案：1（shu）

し＋小ゅ构成一拍拗音，常写作 shu。

4学校がっこう 中「っ」表示什么？

  1. 1拉长
  2. 2停顿一拍
  3. 3鼻音
  4. 4小声读
答案与解析

正确答案：2（停顿一拍）

促音「っ」在后音前停顿一拍。

5片假名外来语的长音通常用？

  1. 1ん
  2. 2っ
  3. 3ー
  4. 4゛
答案与解析

正确答案：3（ー）

如 コーヒー、タクシー，片假名长音多用长音符号「ー」。
