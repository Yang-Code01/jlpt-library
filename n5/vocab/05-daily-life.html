✏ 自测练习

1「鉛筆」的读音是？

  1. 1えんぴつ
  2. 2えいが
  3. 3でんき
  4. 4てがみ
答案与解析

正确答案：1（えんぴつ）

「鉛筆」读作「えんぴつ」，意思是铅笔。

2「財布」的意思是哪一个？

  1. 1钱包
  2. 2钥匙
  3. 3雨伞
  4. 4帽子
答案与解析

正确答案：1（钱包）

「財布（さいふ）」是钱包。

3このかばんは（　　）です。重。

  1. 1重い
  2. 2古い
  3. 3便利
  4. 4丸い
答案与解析

正确答案：1（重い）

表示“重的”用「重い（おもい）」。

4手紙てがみを（　　）。

  1. 1かきます
  2. 2いきます
  3. 3います
  4. 4あります
答案与解析

正确答案：1（かきます）

「手紙を書く」是“写信”。

5「便利」的词性是？

  1. 1な形
  2. 2い形
  3. 3动1
  4. 4量词
答案与解析

正确答案：1（な形）

「便利」是な形容词，礼貌体可说「便利です」。
