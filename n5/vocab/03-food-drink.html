✏ 自测练习

1「牛乳」的正确意思是？

  1. 1牛肉
  2. 2牛奶
  3. 3红茶
  4. 4黄油
答案与解析

正确答案：2（牛奶）

「牛乳」读作「ぎゅうにゅう」，意思是牛奶。

2「美味しい」的读音是？

  1. 1おいしい
  2. 2あまい
  3. 3からい
  4. 4まずい
答案与解析

正确答案：1（おいしい）

「美味しい」读作「おいしい」，意思是好吃。

3ごはんを（　　）で食べます。

  1. 1箸
  2. 2冷蔵庫
  3. 3八百屋
  4. 4砂糖
答案与解析

正确答案：1（箸）

用筷子吃饭：「箸で食べます」。

4（　　）で野菜を買います。

  1. 1八百屋
  2. 2カップ
  3. 3牛乳
  4. 4お弁当
答案与解析

正确答案：1（八百屋）

蔬菜水果店是「八百屋」。

5「辛い」是什么意思？

  1. 1甜
  2. 2辣
  3. 3温的
  4. 4难吃
答案与解析

正确答案：2（辣）

「辛い」表示辣。
