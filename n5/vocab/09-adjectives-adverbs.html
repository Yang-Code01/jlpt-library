✏ 自测练习

1高たかい 的意思是？

  1. 1便宜的
  2. 2高的；贵的
  3. 3快的
  4. 4热闹的
答案与解析

正确答案：2

「高い」可表示高度高，也可表示价格贵。

2静しずか 的词性是？

  1. 1い形
  2. 2な形
  3. 3动1
  4. 4量词
答案与解析

正确答案：2

接名词时说「静かな町」，所以是な形容词。

3日本語にほんごが（　　）好すきです。

  1. 1一番
  2. 2それから
  3. 3でも
  4. 4ない
答案与解析

正确答案：1

「一番好き」表示“最喜欢”。

4「ゆっくりと」最接近哪一个意思？

  1. 1马上
  2. 2慢慢地
  3. 3全部
  4. 4为什么
答案与解析

正确答案：2

表示动作慢、从容。

5今日きょうは（　　）です。仕事しごとがありません。

  1. 1暇
  2. 2速い
  3. 3弱い
  4. 4外
答案与解析

正确答案：1

没有工作，所以“有空”。
