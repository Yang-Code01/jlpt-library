✏ 自测练习

1駅えきの前まえにあります。这里「駅」的读音是？

  1. 1えき
  2. 2いえ
  3. 3みせ
  4. 4まち
答案与解析

正确答案：1（えき）

「駅」读作「えき」，意思是车站。

2「入口」的意思是哪一个？

  1. 1出口
  2. 2入口
  3. 3楼梯
  4. 4地图
答案与解析

正确答案：2（入口）

「入口（いりぐち）」是入口；「出口（でぐち）」才是出口。

3銀行ぎんこうは（　　）ですか。

  1. 1どこ
  2. 2だれ
  3. 3いつ
  4. 4なに
答案与解析

正确答案：1（どこ）

询问地点用「どこ」。

4「左」的相反方向是？

  1. 1右
  2. 2上
  3. 3下
  4. 4外
答案与解析

正确答案：1（右）

「左（ひだり）」的相反是「右（みぎ）」。

5地下鉄ちかてつで（　　）。

  1. 1いきます
  2. 2あります
  3. 3です
  4. 4います
答案与解析

正确答案：1（いきます）

交通工具后用「で」，动作可用「いきます」。
