✏ 自测练习

1「明後日」的读音是？

  1. 1あした
  2. 2あさって
  3. 3きのう
  4. 4おととい
答案与解析

正确答案：2（あさって）

「明後日」读作「あさって」，意思是后天。

2「火曜日」是什么意思？

  1. 1星期一
  2. 2星期二
  3. 3星期三
  4. 4星期五
答案与解析

正确答案：2（星期二）

「火曜日」是星期二。

3りんごが（　　）あります。＝ 有三个苹果。

  1. 1みっつ
  2. 2ふたり
  3. 3ごぜん
  4. 4らいねん
答案与解析

正确答案：1（みっつ）

数普通物品“三个”用「三つ（みっつ）」。

4「午前」的反义搭配是？

  1. 1午後
  2. 2今朝
  3. 3半分
  4. 4毎年
答案与解析

正确答案：1（午後）

「午前」是上午，下午是「午後」。

5「来週」是什么意思？

  1. 1上周
  2. 2这周
  3. 3下周
  4. 4每周
答案与解析

正确答案：3（下周）

「来週」表示下周。
