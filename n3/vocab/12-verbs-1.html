自测练习

1医者いしゃは休やすむことを（　　）。

  1. 1勧すすめた
  2. 2濡ぬらした
  3. 3建たった
  4. 4こぼした
答案与解析

正确答案：1（勧すすめた）

「勧すすめる」表示建议、劝说别人做某事。【译文】医生建议休息。

2机つくえを壁かべの近ちかくに（　　）。

  1. 1語かたった
  2. 2寄よせた
  3. 3溺おぼれた
  4. 4弱よわまった
答案与解析

正确答案：2（寄よせた）

「寄よせる」表示使某物靠近某处。【译文】把桌子靠近墙边。

3うわさが町まちに（　　）。

  1. 1避さけた
  2. 2預あずかった
  3. 3広ひろがった
  4. 4刺さした
答案与解析

正确答案：3（広ひろがった）

「広ひろがる」是自动词，表示范围扩大、传播开。【译文】传闻在镇上传开了。

4困こまった時ときは兄あにに（　　）。

  1. 1叩たたく
  2. 2断たつ
  3. 3蒸むす
  4. 4頼たよる
答案与解析

正确答案：4（頼たよる）

「頼たよる」表示依靠、求助于某人。【译文】困难时依靠哥哥。

5雪ゆきが庭にわに（　　）。

  1. 1積つもった
  2. 2祝いわった
  3. 3用もちいた
  4. 4罰ばっした
答案与解析

正确答案：1（積つもった）

「積つもる」表示雪、灰尘等自然堆积。【译文】雪积在院子里。

6名前なまえをもう一度いちど（　　）。

  1. 1与あたえる
  2. 2確たしかめる
  3. 3輝かがやく
  4. 4遭あう
答案与解析

正确答案：2（確たしかめる）

「確たしかめる」表示确认是否正确。【译文】再确认一次名字。
