自测练习

1みんなの前まえで意見いけんを（　　）する。

  1. 1主張しゅちょう
  2. 2氷こおり
  3. 3座席ざせき
  4. 4湿度しつど
答案与解析

正确答案：1（主張しゅちょう）

「主張しゅちょうする」は自分じぶんの意見いけんを強つよく言いうことです。【译文】在大家面前主张自己的意见。

2品物しなものの（　　）を払はらう。

  1. 1周囲しゅうい
  2. 2現金げんきん
  3. 3資格しかく
  4. 4結果けっか
答案与解析

正确答案：2（現金げんきん）

「現金げんきん」は紙幣しへいや硬貨こうかのお金かねです。【译文】支付商品的现金。

3仕事しごとは（　　）に進すすんでいる。

  1. 1障害しょうがい
  2. 2死し
  3. 3順調じゅんちょう
  4. 4策さく
答案与解析

正确答案：3（順調じゅんちょう）

「順調じゅんちょう」は物事ものごとが問題もんだいなく進すすむ様子ようすです。【译文】工作进展顺利。

4この計画けいかくに（　　）します。

  1. 1騒さわぎ
  2. 2腰こし
  3. 3真理しんり
  4. 4賛成さんせい
答案与解析

正确答案：4（賛成さんせい）

「賛成さんせいする」は案あんや意見いけんに同意どういすることです。【译文】我赞成这个计划。

5会社かいしゃの問題もんだいを（　　）する。

  1. 1考慮こうりょ
  2. 2小包こづつみ
  3. 3首都しゅと
  4. 4公正こうせい
答案与解析

正确答案：1（考慮こうりょ）

「考慮こうりょする」はよく考かんがえて判断はんだんすることです。【译文】考虑公司的问题。

6事故じこで道みちが（　　）した。

  1. 1商品しょうひん
  2. 2混乱こんらん
  3. 3材料ざいりょう
  4. 4幸しあわせ

正确答案：2（混乱こんらん）

「混乱こんらんする」は物事ものごとが乱みだれて分わかりにくくなることです。【译文】因为事故道路混乱了。
