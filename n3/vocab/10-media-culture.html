自测练习

1新聞しんぶんに店みせの（　　）を出だした。

  1. 1広告こうこく
  2. 2膜まく
  3. 3碁ご
  4. 4独身どくしん
答案与解析

正确答案：1（広告こうこく）

「広告こうこく」是宣传商品或店铺的信息。【译文】在报纸上登了店铺广告。

2舞台ぶたいの（　　）が静しずかに開あいた。

  1. 1ラケット
  2. 2幕まく
  3. 3郵便ゆうびん
  4. 4データ
答案与解析

正确答案：2（幕まく）

「幕まく」指舞台的幕布，也可指戏的一幕。【译文】舞台的幕布静静拉开了。

3空港くうこうで（　　）を見みせてください。

  1. 1メモ
  2. 2チーズ
  3. 3パスポート
  4. 4スキー
答案与解析

正确答案：3（パスポート）

「パスポート」是出入境时使用的护照。【译文】请在机场出示护照。

4写真しゃしんを雑誌ざっしに（　　）。

  1. 1及およぼす
  2. 2汲くむ
  3. 3描かく
  4. 4載のせる
答案与解析

正确答案：4（載のせる）

「載のせる」表示把文章、照片等刊登出来。【译文】把照片刊登在杂志上。

5友達ともだちと山やまで（　　）をした。

  1. 1キャンプ
  2. 2サイン
  3. 3インク
  4. 4関心かんしん
答案与解析

正确答案：1（キャンプ）

「キャンプをする」表示露营。【译文】和朋友在山里露营了。

6試合しあいで右みぎへ（　　）を出だした。

  1. 1ビデオ
  2. 2パス
  3. 3ワイン
  4. 4記事きじ
答案与解析

正确答案：2（パス）

「パスを出だす」在球类运动中表示传球。【译文】比赛中向右传球了。
