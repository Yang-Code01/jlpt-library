✏ 自测练习

1バスを待まつ場所ばしょは（　　）です。

  1. 1停留所ていりゅうじょ
  2. 2太陽たいよう
  3. 3丘おか
  4. 4株かぶ
答案与解析

正确答案：1（停留所ていりゅうじょ）

停留所ていりゅうじょはバスなどが止とまり、客きゃくが乗のる場所ばしょ。【译文】等公交的地方是公交站。

2車くるまが多おおくて道みちが進すすまない状態じょうたいは（　　）です。

  1. 1登山とざん
  2. 2渋滞じゅうたい
  3. 3四季しき
  4. 4券けん
答案与解析

正确答案：2（渋滞じゅうたい）

渋滞じゅうたいは車くるまなどが込こんで流ながれが悪わるい状態じょうたい。【译文】车多道路不通畅的状态是堵车。

3「太陽たいよう」の意味いみはどれですか。

  1. 1波なみ
  2. 2雷かみなり
  3. 3太陽たいよう
  4. 4道路どうろ
答案与解析

正确答案：3（太陽たいよう）

太陽たいようは昼ひるに空そらで光ひかる星ほし。【译文】太陽的意思是太阳。

4草くさが庭にわに（　　）。

  1. 1超こす
  2. 2横断おうだんする
  3. 3発車はっしゃする
  4. 4生はえる
答案与解析

正确答案：4（生はえる）

生はえるは草くさや木きなどが自然しぜんに出でて育そだつこと。【译文】草在院子里长出来。

5電車でんしゃが駅えきを出でることは（　　）です。

  1. 1発車はっしゃ
  2. 2駐車ちゅうしゃ
  3. 3訓練くんれん
  4. 4環境かんきょう
答案与解析

正确答案：1（発車はっしゃ）

発車はっしゃは電車でんしゃやバスが出発しゅっぱつすること。【译文】电车离开车站叫发车。

6雨あめが続つづく季節きせつは（　　）です。

  1. 1嵐あらし
  2. 2梅雨つゆ
  3. 3泉いずみ
  4. 4工場こうば
答案与解析

正确答案：2（梅雨つゆ）

梅雨つゆは初夏しょかに雨あめが多おおく続つづく時期じき。【译文】雨持续下的季节是梅雨季。
