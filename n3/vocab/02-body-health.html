自测练习

1熱ねつを測はかる時とき、（　　）を見みる。

  1. 1体温たいおん
  2. 2血管けっかん
  3. 3絵画かいが
  4. 4針はり
答案与解析

正确答案：1（体温たいおん）

体温たいおんは体からだの温度おんどを表あらわす語ご。【译文】量发烧时看体温。

2歯はに穴あなができて痛いたい病気びょうきは（　　）です。

  1. 1骨折こっせつ
  2. 2虫歯むしば
  3. 3徹夜てつや
  4. 4睡眠すいみん
答案与解析

正确答案：2（虫歯むしば）

虫歯むしばは歯はが悪わるくなり穴あなができること。【译文】牙上有洞而疼的病是蛀牙。

3「咳せき」の読よみ方かたはどれですか。

  1. 1かぜ
  2. 2きず
  3. 3せき
  4. 4いき
答案与解析

正确答案：3（せき）

咳せきは喉のどや胸むねから出でる症状しょうじょう。【译文】“咳嗽”的读音是せき。

4医師いしが患者かんじゃを（　　）。

  1. 1流ながす
  2. 2剥むく
  3. 3稼かせぐ
  4. 4診みる
答案与解析

正确答案：4（診みる）

診みるは医師いしが病気びょうきや体からだを調しらべる動詞どうし。【译文】医生给患者看病。

5眠ねむらずに夜よるを明あかすことは（　　）です。

  1. 1徹夜てつや
  2. 2拍手はくしゅ
  3. 3握手あくしゅ
  4. 4呼吸こきゅう
答案与解析

正确答案：1（徹夜てつや）

徹夜てつやは一晩中ひとばんじゅう寝ねないこと。【译文】不睡觉过夜叫通宵。

6「全身ぜんしん」に近ちかい意味いみはどれですか。

  1. 1顔かおだけ
  2. 2体からだ全体ぜんたい
  3. 3手ての先さき
  4. 4心こころだけ
答案与解析

正确答案：2（体からだ全体ぜんたい）

全身ぜんしんは体からだのすべてを指さす。【译文】“全身”指整个身体。
