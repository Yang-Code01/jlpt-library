✏ 自测练习

1日本語にほんごがかなり（　　）した。

  1. 1上達じょうたつ
  2. 2存在そんざい
  3. 3逮捕たいほ
  4. 4設計せっけい
答案与解析

正确答案：1（上達じょうたつ）

「上達じょうたつする」表示技能进步、变好。【译文】日语有了很大进步。

2新あたらしい計画けいかくを（　　）した。

  1. 1通過つうか
  2. 2提案ていあん
  3. 3騒音そうおん
  4. 4宝たから
答案与解析

正确答案：2（提案ていあん）

「提案ていあんする」表示提出意见或计划。【译文】提出了新的计划。

3先生せんせいに（　　）聞きいてください。

  1. 1滞在たいざい
  2. 2単純たんじゅん
  3. 3直接ちょくせつ
  4. 4制度せいど
答案与解析

正确答案：3（直接ちょくせつ）

「直接ちょくせつ」表示不经过别人或中间环节。【译文】请直接问老师。

  2. 2推薦すいせん

正确答案：4（到着とうちゃく）

「到着とうちゃくする」表示到达目的地。【译文】电车到站了。
