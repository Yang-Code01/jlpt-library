✏ 自测练习

1約束やくそくの（　　）までに来きてください。

  1. 1程度ていど
  2. 2期限きげん
  3. 3平均へいきん
  4. 4現状げんじょう
答案与解析

正确答案：2（期限きげん）

「期限きげん」表示必须完成的最后时间。【译文】请在约定期限前来。

2客きゃくの（　　）は学生がくせいでした。

  1. 1大半たいはん
  2. 2正午しょうご
  3. 3曜日ようび
  4. 4僅わずか
答案与解析

正确答案：1（大半たいはん）

「大半たいはん」表示大多数、过半。【译文】客人大多数是学生。

3雨あめは（　　）強つよくなった。

  1. 1そのうち
  2. 2普段ふだん
  3. 3一層いっそう
  4. 4前まえもって
答案与解析

正确答案：3（一層いっそう）

「一層いっそう」表示程度进一步加深。【译文】雨变得更大了。

4彼かれは（　　）遅刻ちこくしない。

  1. 1たびたび
  2. 2既すでに
  3. 3ざっと
  4. 4滅多めったに
答案与解析

正确答案：4（滅多めったに）

「滅多めったに～ない」表示很少、不常。【译文】他很少迟到。

5出発しゅっぱつの前まえに（　　）を確認かくにんした。

  1. 1スケジュール
  2. 2額がく
  3. 3夜中よなか
  4. 4限界げんかい
答案与解析

正确答案：1（スケジュール）

「スケジュール」是日程、计划，适合出发前确认。【译文】出发前确认了日程。

6この店みせは一年いちねん（　　）開あいている。

  1. 1多少たしょう
  2. 2日付ひづけ
  3. 3年中ねんじゅう
  4. 4最終さいしゅう
答案与解析

正确答案：3（年中ねんじゅう）

「年中ねんじゅう」表示全年、总是。【译文】这家店全年营业。
