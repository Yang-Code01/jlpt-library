自测练习

1頭あたまに帽子ぼうしを（　　）。

  1. 1被かぶる
  2. 2畳たたむ
  3. 3支払しはらう
  4. 4揃そろえる
答案与解析

正确答案：1（被かぶる）

被かぶるは帽子ぼうしなどを頭あたまに着つける動作どうさ。【译文】把帽子戴在头上。

2毎月まいつき会社かいしゃから受うけ取とるお金かねは（　　）です。

  1. 1小銭こぜに
  2. 2給料きゅうりょう
  3. 3硬貨こうか
  4. 4予算よさん
答案与解析

正确答案：2（給料きゅうりょう）

給料きゅうりょうは働はたらいた人ひとが会社かいしゃから受うけ取とるお金かね。【译文】每月从公司领到的钱是工资。

3商品しょうひんを家いえまで届とどけることは（　　）です。

  1. 1販売はんばい
  2. 2製造せいぞう
  3. 3配達はいたつ
  4. 4両替りょうがえ
答案与解析

正确答案：3（配達はいたつ）

配達はいたつは品物しなものを相手あいての所ところへ届とどけること。【译文】把商品送到家里叫配送。

4使つかうお金かねを少すくなくすることは（　　）です。

  1. 1流行りゅうこう
  2. 2営業えいぎょう
  3. 3注文ちゅうもん
  4. 4節約せつやく
答案与解析

正确答案：4（節約せつやく）

節約せつやくは無駄むだを減へらして使つかう量りょうを少すくなくすること。【译文】减少花钱叫节约。

5銀行ぎんこうで円えんに（　　）する。

  1. 1両替りょうがえ
  2. 2商売しょうばい
  3. 3支給しきゅう
  4. 4貯金ちょきん
答案与解析

正确答案：1（両替りょうがえ）

両替りょうがえは一ひとつの通貨つうかを別べつの通貨つうかに替かえること。【译文】在银行兑换成日元。

6洗あらった服ふくをきれいに（　　）。

  1. 1破やぶれる
  2. 2畳たたむ
  3. 3冷さめる
  4. 4流行はやる
答案与解析

正确答案：2（畳たたむ）

畳たたむは服ふくや布ぬのを折おって小ちいさく整ととのえること。【译文】把洗好的衣服叠整齐。
