✏ 自测练习

1鋭するどいナイフの意味いみはどれですか。

  1. 1よく切きれる
  2. 2温あたたかい
  3. 3においが強つよい
  4. 4静しずかだ
答案与解析

正确答案：1（よく切きれる）

「鋭するどい」は先さきがとがってよく切きれる様子ようすです。【译文】锋利的小刀是什么意思？

2「不小心忘了钥匙」に合あう副詞ふくしはどれですか。

  1. 1わざと
  2. 2うっかり
  3. 3ますます
  4. 4したがって
答案与解析

正确答案：2（うっかり）

「うっかり」は注意ちゅういが足たりず失敗しっぱいすることです。【译文】不小心忘了钥匙。

3彼かれは私わたしの（　　）だ。

  1. 1違ちがい
  2. 2たっぷり
  3. 3味方みかた
  4. 4突然とつぜん
答案与解析

正确答案：3（味方みかた）

「味方みかた」は自分じぶんを助たすける側がわの人ひとです。【译文】他是支持我的人。

4雨あめだ。（　　）試合しあいは中止ちゅうしだ。

  1. 1実じつに
  2. 2そっと
  3. 3羨うらやましい
  4. 4したがって
答案与解析

正确答案：4（したがって）

「したがって」は前まえの理由りゆうから結果けっかを導みちびきます。【译文】下雨了，所以比赛取消。

5服ふくのサイズが（　　）だ。

  1. 1ぴったり
  2. 2戦たたかい
  3. 3違ちがいない
  4. 4およそ
答案与解析

正确答案：1（ぴったり）

「ぴったり」は大おおきさなどがちょうど合あうことです。【译文】衣服尺寸正合适。

6これは捨すてるには（　　）。

  1. 1急きゅうに
  2. 2もったいない
  3. 3唯一ゆいいつ
  4. 4そこで
答案与解析

正确答案：2（もったいない）

「もったいない」は価値かちがある物ものを無駄むだにする惜おしさです。【译文】这个扔掉太可惜。
