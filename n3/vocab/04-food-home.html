✏ 自测练习

1熱あつい飯めしを作つくる時とき、米こめを（　　）。

  1. 1炊たく
  2. 2掃はく
  3. 3宛あてる
  4. 4裂さく
答案与解析

正确答案：1（炊たく）

炊たくは米こめを水みずと火ひで飯めしにする動作どうさ。【译文】做热饭时要煮米。

2部屋へやを明あかるくするものは（　　）です。

  1. 1塵ごみ
  2. 2明あかり
  3. 3幅はば
  4. 4並なみ
答案与解析

正确答案：2（明あかり）

明あかりは部屋へやを照てらす光ひかりを表あらわす。【译文】让房间明亮的是灯光。

3「引越ひっこし」の意味いみはどれですか。

  1. 1直なおすこと
  2. 2電気でんきが消きえること
  3. 3家いえを移うつること
  4. 4人前ひとまえで話はなすこと
答案与解析

正确答案：3（家いえを移うつること）

引越ひっこしは住すむ家いえを移うつること。【译文】引越し的意思是搬家。

4床ゆかの塵ごみを（　　）。

  1. 1注さす
  2. 2煮にる
  3. 3酌くむ
  4. 4掃はく
答案与解析

正确答案：4（掃はく）

掃はくはほうきなどで塵ごみを取とる動作どうさ。【译文】把地板上的垃圾扫掉。

5食たべたい気持きもちは（　　）です。

  1. 1食欲しょくよく
  2. 2住宅じゅうたく
  3. 3灯ひ
  4. 4故郷こきょう
答案与解析

正确答案：1（食欲しょくよく）

食欲しょくよくは食たべたいと思おもう気持きもち。【译文】想吃东西的心情叫食欲。

6皿さらが割われたので父ちちが（　　）する。

  1. 1帰宅きたく
  2. 2修理しゅうり
  3. 3教授きょうじゅ
  4. 4引越ひっこし
答案与解析

正确答案：2（修理しゅうり）

修理しゅうりは壊こわれた物ものを直なおすこと。【译文】盘子坏了，所以父亲修理。
