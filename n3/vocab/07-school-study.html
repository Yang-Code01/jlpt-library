自测练习

1試験しけんに（　　）して、家族かぞくが喜よろこんだ。

  1. 1合格ごうかく
  2. 2課題かだい
  3. 3単位たんい
  4. 4読書どくしょ
答案与解析

正确答案：1（合格ごうかく）

「合格ごうかくする」表示考试通过。【译文】考试合格了，家人很高兴。

2大学だいがくで歴史れきしを（　　）している。

  1. 1学期がっき
  2. 2専攻せんこう
  3. 3答案とうあん
  4. 4校舎こうしゃ
答案与解析

正确答案：2（専攻せんこう）

「専攻せんこうする」表示把某学科作为专业学习。【译文】在大学专攻历史。

3分わからない（　　）は先生せんせいに聞きこう。

  1. 1まさに
  2. 2成績せいせき
  3. 3問とい
  4. 4著者ちょしゃ
答案与解析

正确答案：3（問とい）

「問とい」是问题、提问的意思。【译文】不懂的问题就问老师吧。

4レポートの間違まちがいを（　　）した。

  1. 1通学つうがく
  2. 2納得なっとく
  3. 3留学りゅうがく
  4. 4修正しゅうせい
答案与解析

正确答案：4（修正しゅうせい）

「修正しゅうせいする」表示修改错误或不合适之处。【译文】修改了报告中的错误。

5寝ねる前まえに少すこし（　　）する。

  1. 1読書どくしょ
  2. 2転校てんこう
  3. 3体育たいいく
  4. 4級きゅう
答案与解析

正确答案：1（読書どくしょ）

「読書どくしょする」是读书、阅读的固定说法。【译文】睡前读一会儿书。

6新あたらしい方法ほうほうを（　　）みた。

  1. 1問とう
  2. 2試ためして
  3. 3説とく
  4. 4著あらわす
答案与解析

正确答案：2（試ためして）

「試ためす」表示尝试、试验方法或物品。【译文】试了试新的方法。
