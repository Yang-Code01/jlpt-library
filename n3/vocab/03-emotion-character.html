自测练习

1試合しあいに負まけて、とても（　　）。

  1. 1悔くやしい
  2. 2愉快ゆかい
  3. 3穏おだやか
  4. 4独特どくとく
答案与解析

正确答案：1（悔くやしい）

悔くやしいは失敗しっぱいや負まけで残念ざんねんに思おもう気持きもち。【译文】比赛输了，非常不甘心。

2相手あいての意見いけんを大切たいせつにすることは（　　）です。

  1. 1後悔こうかい
  2. 2尊重そんちょう
  3. 3恐怖きょうふ
  4. 4怒いかり
答案与解析

正确答案：2（尊重そんちょう）

尊重そんちょうは相手あいての考かんがえや立場たちばを大切たいせつにすること。【译文】重视对方意见就是尊重。

3「雰囲気ふんいき」の読よみ方かたはどれですか。

  1. 1ふいんき
  2. 2ふんき
  3. 3ふんいき
  4. 4ふういき
答案与解析

正确答案：3（ふんいき）

雰囲気ふんいきは場ばの空気くうきやムードを表あらわす。【译文】“气氛”的读音是ふんいき。

4良よい結果けっかを（　　）して待まつ。

  1. 1反省はんせい
  2. 2疑問ぎもん
  3. 3感動かんどう
  4. 4期待きたい
答案与解析

正确答案：4（期待きたい）

期待きたいするは良よいことが起おこるよう待まつ意味いみ。【译文】期待好结果并等待。

5失敗しっぱいの後あとで自分じぶんを見直みなおすことは（　　）です。

  1. 1反省はんせい
  2. 2歓声かんせい
  3. 3希望きぼう
  4. 4特徴とくちょう
答案与解析

正确答案：1（反省はんせい）

反省はんせいは自分じぶんの行動こうどうを振ふり返かえること。【译文】失败后重新审视自己就是反省。

6心こころが落おち着ついている様子ようすは（　　）です。

  1. 1深刻しんこく
  2. 2冷静れいせい
  3. 3正体しょうたい
  4. 4苦手にがて
答案与解析

正确答案：2（冷静れいせい）

冷静れいせいは慌あわてず落おち着ついている状態じょうたい。【译文】内心平静的样子是冷静。
