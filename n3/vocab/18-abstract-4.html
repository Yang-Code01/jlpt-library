✏ 自测练习

1新あたらしい店みせを（　　）した。

  1. 1発見はっけん
  2. 2比較ひかく
  3. 3保存ほぞん
  4. 4予防よぼう
答案与解析

正确答案：1（発見はっけん）

「発見はっけんする」表示发现以前不知道的人或事物。【译文】发现了一家新店。

2試験しけんの前まえで、少すこし（　　）だ。

  1. 1豊富ほうふ
  2. 2不安ふあん
  3. 3本物ほんもの
  4. 4用心ようじん
答案与解析

正确答案：2（不安ふあん）

「不安ふあん」表示担心、心里不踏实。【译文】考试前有点不安。

3時間じかんに（　　）があるから、歩あるこう。

  1. 1評価ひょうか
  2. 2別わかれ
  3. 3余裕よゆう
  4. 4灰はい
答案与解析

正确答案：3（余裕よゆう）

「余裕よゆう」表示时间、金钱或心情上有富余。【译文】时间有余裕，所以走路去吧。

4台風たいふうの（　　）が大おおきかった。

  1. 1目的もくてき
  2. 2理想りそう
  3. 3表情ひょうじょう
  4. 4被害ひがい
答案与解析

正确答案：4（被害ひがい）

「被害ひがい」指受灾、受损的情况。【译文】台风造成的损失很大。

5火ひの（　　）をしてください。

  1. 1用心ようじん
  2. 2発達はったつ
  3. 3文明ぶんめい
  4. 4冒険ぼうけん
答案与解析

正确答案：1（用心ようじん）

「火ひの用心ようじん」是固定说法，表示小心用火、防火。【译文】请小心用火。

6彼かれは料理りょうりの（　　）だ。

  1. 1物質ぶっしつ
  2. 2名人めいじん
  3. 3予期よき
  4. 4不平ふへい
答案与解析

正确答案：2（名人めいじん）

「名人めいじん」表示某方面技术很高的人。【译文】他是料理高手。
