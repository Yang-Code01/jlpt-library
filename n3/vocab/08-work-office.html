自测练习

1明日あした、会社かいしゃで（　　）を受うける。

  1. 1面接めんせつ
  2. 2税金ぜいきん
  3. 3部分ぶぶん
  4. 4章しょう
答案与解析

正确答案：1（面接めんせつ）

求职时接受的是「面接めんせつ」。【译文】明天在公司接受面试。

2会議かいぎの結果けっかを部長ぶちょうに（　　）する。

  1. 1引退いんたい
  2. 2報告ほうこく
  3. 3通勤つうきん
  4. 4倒産とうさん
答案与解析

正确答案：2（報告ほうこく）

「報告ほうこくする」表示汇报结果或情况。【译文】向部长汇报会议结果。

3自分じぶんの仕事しごとには（　　）を持もとう。

  1. 1契約けいやく
  2. 2作業さぎょう
  3. 3責任せきにん
  4. 4技師ぎし
答案与解析

正确答案：3（責任せきにん）

「責任せきにんを持もつ」是负责的常用搭配。【译文】要对自己的工作负责。

4新あたらしい規則きそくを来月らいげつから（　　）する。

  1. 1成功せいこう
  2. 2記録きろく
  3. 3会合かいごう
  4. 4適用てきよう
答案与解析

正确答案：4（適用てきよう）

「適用てきようする」表示把规则用于某对象。【译文】从下个月开始适用新规则。

5父ちちの店みせを（　　）ために帰かえった。

  1. 1継つぐ
  2. 2映うつす
  3. 3写うつる
  4. 4詰つめる
答案与解析

正确答案：1（継つぐ）

「継つぐ」表示继承事业、店铺或职位。【译文】为了继承父亲的店回去了。

6毎朝まいあさ、電車でんしゃで会社かいしゃへ（　　）する。

  1. 1努力どりょく
  2. 2通勤つうきん
  3. 3振興しんこう
  4. 4申告しんこく
答案与解析

正确答案：2（通勤つうきん）

「通勤つうきんする」表示上下班通勤。【译文】每天早上坐电车去公司上班。
