✏ 自测练习

1車くるまの（　　）を取とってから運転うんてんする。

  1. 1免許めんきょ
  2. 2伝統でんとう
  3. 3宗教しゅうきょう
  4. 4郡ぐん
答案与解析

正确答案：1（免許めんきょ）

「免許めんきょ」是驾驶等行为所需的执照。【译文】拿到驾照后再开车。

2日曜日にちようびに市長しちょうの（　　）がある。

  1. 1発行はっこう
  2. 2選挙せんきょ
  3. 3犯罪はんざい
  4. 4構成こうせい
答案与解析

正确答案：2（選挙せんきょ）

「選挙せんきょ」表示通过投票选出代表。【译文】星期天有市长选举。

3規則きそくに（　　）してはいけない。

  1. 1出版しゅっぱん
  2. 2共同きょうどう
  3. 3違反いはん
  4. 4左右さゆう
答案与解析

正确答案：3（違反いはん）

「違反いはんする」表示违反规则、法律等。【译文】不能违反规则。

4争あらそいのない（　　）な世界せかいを願ねがう。

  1. 1無事ぶじ
  2. 2平和へいわ
  3. 3世間せけん
  4. 4組織そしき
答案与解析

正确答案：2（平和へいわ）

「平和へいわな世界せかい」指没有战争争端的世界。【译文】祈愿没有纷争的和平世界。

5新あたらしい本ほんを来月らいげつ（　　）する。

  1. 1宣伝せんでん
  2. 2禁止きんし
  3. 3発表はっぴょう
  4. 4出版しゅっぱん
答案与解析

正确答案：4（出版しゅっぱん）

「出版しゅっぱんする」表示出版书籍等。【译文】下个月出版新书。

6自分じぶんの（　　）を守まもることは大切たいせつだ。

  1. 1権利けんり
  2. 2税ぜい
  3. 3岸きし
  4. 4年代ねんだい
答案与解析

正确答案：1（権利けんり）

「権利けんり」是依法或道理上可以主张的权利。【译文】维护自己的权利很重要。
