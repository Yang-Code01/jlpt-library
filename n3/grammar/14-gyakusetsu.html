N3 语法 · 第 14 单元　逆接与让步

学习逆接、让步、话题转换及相关副词表达，掌握转折语气的细微差别。

本单元共 12 个知识点，单元末附自测练习。

知识点详解

1くせに　「明明～却～」

【讲解】「くせに」表示前项事实与后项结果不相称，常带责备、轻蔑或不满。多用于说话人评价某人“明明如此却那样”。前后主语通常相同，或后项针对前项人物作评价。语气较强，正式场合需谨慎使用。

接续：动词普通形／い形普通形／な形词干 ＋ な ＋ くせに／名词 ＋ の ＋ くせに

彼かれは知しらないくせに、何なんでも説明せつめいしたがる。

他明明不知道，却什么都想解释。

子供こどものくせに、大人おとなみたいな話はなし方かたをする。

明明是个孩子，说话却像大人一样。

彼女かのじょは忙いそがしいくせに、手伝てつだうとは言いわない。

她明明很忙，却也不说要帮忙。

辨析：「のに」只是表示意外或遗憾；「くせに」含责备、轻蔑，且多要求前后同主语。
注意：对长辈或不熟的人直接用「くせに」容易显得失礼。

2ながらも　「虽然～但是～」

【讲解】「ながらも」表示承认前项事实，同时提出与其相反或超出预期的后项。语气比「けれども」更书面，常用于说明状态、评价或让步。后项多强调“尽管如此仍然成立”。

接续：动词ます形去「ます」／い形词干／な形词干／名词 ＋ ながらも

彼かれは新人しんじんながらも、会議かいぎで意見いけんを出だした。

他虽然是新人，却在会议上提出了意见。

狭せまいながらも、この部屋へやは住すみやすい。

这个房间虽小，但住起来方便。

残念ざんねんながらも、結果けっかを受うけ入いれるしかない。

虽然遗憾，但只能接受结果。

辨析：「ながら」也可表示同时进行；「ながらも」重点是让步转折，不表示两个动作同时发生。

3わりに（は）　「按～来说却～」

【讲解】「わりに（は）」表示以某标准衡量时，后项结果与预想不太一致。可译为“按……来说，倒是……”。常用于年龄、价格、工作量、外观等与实际结果之间的落差。语气较客观，不一定带负面评价。

接续：动词普通形／い形普通形／な形词干 ＋ な ＋ わりに（は）／名词 ＋ の ＋ わりに（は）

この店みせは値段ねだんのわりに、料理りょうりがおいしい。

这家店按价格来说，菜很好吃。

彼かれは若わかいわりに、落おち着ついている。

他按年纪来说，很沉稳。

たくさん勉強べんきょうしたわりには、点数てんすうが低ひくかった。

按学了很多来说，分数却很低。

辨析：「にしては」多以前项身份、条件为基准；「わりに」更常以程度、数量、外观等比例感作基准。

4ところが　「可是／然而」

【讲解】「ところが」用于连接两个句子，表示后项与前项预想相反。常用于叙述事情发展突然转折，带“没想到”的感觉。多放在句首或两个完整句子之间。

接续：句子。＋ ところが、＋ 意外的转折结果

朝あさは晴はれていた。ところが、昼ひるから雨あめが降ふり出だした。

早上还是晴天，可是中午开始下雨了。

約束やくそくの時間じかんに行いった。ところが、誰だれも来きていなかった。

我按约定时间去了，然而谁都没来。

注意：「ところが」后面通常接出乎意料的事实，不适合接单纯并列或补充说明。

5ところで　「话说／转换话题」

【讲解】「ところで」放在句首，用来中断当前话题并引入新话题。中文可译为“话说”“对了”。它不表示转折结果，而是会话中的话题转换标志。

接续：句子。＋ ところで、＋ 新话题

明日あしたの予定よていは決きまりました。ところで、昼ひるご飯はんはどうしますか。

明天的安排定下来了。话说，午饭怎么办？

試験しけんの話はなしはここまでにしましょう。ところで、週末しゅうまつは空あいていますか。

考试的事先说到这里。对了，周末你有空吗？

辨析：「ところが」表示意外转折；「ところで」表示转换话题，二者不可混用。

6たって　「即使～也／就算～也」

【讲解】「たって」是「ても／でも」的口语形式，表示让步条件。用于日常会话，语气轻松，有时带反驳或不在乎的感觉。书面文章中通常用「ても」。

接续：动词た形去「た」＋ たって／い形词干 ＋ くたって／な形词干・名词 ＋ だって

今いまさら謝あやまったって、許ゆるしてもらえないよ。

事到如今就算道歉，也不会被原谅的。

高たかくたって、本当ほんとうに必要ひつようなら買かう。

就算贵，如果真的需要也会买。

子供こどもだって、自分じぶんの意見いけんを持もっている。

就算是孩子，也有自己的意见。

注意：「たって」很口语，正式写作或考试作文中优先使用「ても／でも」。

7は別べつとして　「姑且不论～」

【讲解】「は別として」表示先把某个问题放在一边，不把它纳入当前判断。常用于“好坏另说”“是否成功另说”等表达。后项才是说话人真正要讨论或评价的重点。

接续：名词 ＋ は別べつとして／普通形 ＋ かどうかは別べつとして

結果けっかは別べつとして、努力どりょくしたことは大切たいせつだ。

结果姑且不论，努力过这件事很重要。

似合にあうかどうかは別べつとして、その服ふくは面白おもしろい。

合不合适另说，那件衣服很有意思。

辨析：「はともかく」也表示暂且不谈，语气更口语；「は別として」较中性、书面。

8はもちろん　「～当然不用说」

【讲解】「はもちろん」表示前项当然成立，后项也成立。常与「も」「まで」呼应，强调范围扩大。中文可译为“不用说……连……也”。

接续：名词 ＋ はもちろん、＋ 名词 ＋ も／まで

漢字かんじはもちろん、発音はつおんも練習れんしゅうしてください。

汉字当然不用说，发音也请练习。

彼かれは日本語にほんごはもちろん、英語えいごも話はなせる。

他日语不用说，英语也会说。

この店みせは味あじはもちろん、サービスもいい。

这家店味道不用说，服务也很好。

注意：前项应是说话人认为“理所当然”的内容，后项用来补充更值得强调的信息。

9は～で有名ゆうめい　「以～而有名」

【讲解】「は～で有名」表示某人、地方或事物因某特点、产物、人物而广为人知。前面的「は」提出主题，「で」标出有名的原因或方面。常用于介绍城市、学校、店铺、人物等。

接续：名词 ＋ は ＋ 名词 ＋ で有名ゆうめいだ

京都きょうとは古ふるい寺てらで有名ゆうめいだ。

京都以古老寺院而闻名。

この町まちは温泉おんせんで有名ゆうめいです。

这个城镇以温泉闻名。

田中たなか先生せんせいは厳きびしい授業じゅぎょうで有名ゆうめいだ。

田中老师以严格的课而出名。

注意：「有名ゆうめいな＋名词」修饰名词；「～で有名ゆうめいだ」说明有名的原因。

10むしろ　「倒不如说／反而」

【讲解】「むしろ」表示与其选择或评价前项，不如强调后项更合适。常用于修正判断，表达“不是那样，反而更接近这样”。语气较理性，常用于说明和比较。

接续：むしろ ＋ 句子／前项より、むしろ ＋ 后项

彼かれは怒おこっているのではなく、むしろ心配しんぱいしている。

他不是在生气，倒不如说是在担心。

この仕事しごとは大変たいへんだが、むしろ楽たのしい。

这份工作很辛苦，但反而很有趣。

辨析：「かえって」强调结果反向；「むしろ」强调重新选择更恰当的说法或评价。

11それとも　「还是～？」

【讲解】「それとも」用于疑问句中，连接两个或多个选择项。说话人要求对方在选项之间作选择。它不能用于陈述句表示“而且”。

接续：疑问句中的选项A ＋ それとも ＋ 选项B

コーヒーにしますか。それとも、お茶ちゃにしますか。

你要咖啡？还是茶？

電車でんしゃで行いきますか。それとも、バスで行いきますか。

坐电车去？还是坐公交去？

注意：「または／あるいは」可用于书面选择；「それとも」多用于会话疑问。

12だけど　「不过／但是」

【讲解】「だけど」是口语中的逆接连接词，表示前后内容相反或转折。可放在句首，也可连接两个句子。语气比「しかし」轻松，常用于朋友、同事之间的会话。

接续：句子。＋ だけど、＋ 转折内容／普通形 ＋ んだけど

この料理りょうりは辛からい。だけど、とてもおいしい。

这道菜很辣，不过非常好吃。

行いきたいんだけど、今日きょうは時間じかんがない。

我想去，不过今天没有时间。

辨析：「しかし」偏正式；「だけど」偏口语。写正式文章时用「しかし／けれども」更自然。

✏ 自测练习

1彼かれは知しらない（　　）、偉えらそうに説明せつめいしている。

  1. 1くせに
  2. 2ところで
  3. 3それとも
  4. 4むしろ
答案与解析

正确答案：1（くせに）

「くせに」表示明明如此却那样，含责备语气；本句批评“明明不知道却装懂”。【译文】他明明不知道，却一副了不起的样子在解释。

2この店みせは値段ねだんの（　　）、味あじがいい。

  1. 1だけど
  2. 2わりに
  3. 3たって
  4. 4ところが
答案与解析

正确答案：2（わりに）

「わりに」表示按某标准来看后项超出预想；这里是“按价格来说味道好”。【译文】这家店按价格来说，味道很好。

3明日あしたは電車でんしゃで行いきますか。（　　）、バスで行いきますか。

  1. 1ところが
  2. 2むしろ
  3. 3それとも
  4. 4ながらも
答案与解析

正确答案：3（それとも）

「それとも」用于疑问句中连接选择项，要求对方二选一。【译文】明天坐电车去？还是坐公交去？

4結果けっかは（　　）として、最後さいごまで頑張がんばったことは大切たいせつだ。

  1. 1もちろん
  2. 2有名ゆうめい
  3. 3むしろ
  4. 4別べつ
答案与解析

正确答案：4（別べつ）

「は別として」表示姑且不论前项，后项才是当前重点。【译文】结果姑且不论，坚持到最后这件事很重要。

5この仕事しごとは大変たいへんだが、（　　）やりがいがある。

  1. 1むしろ
  2. 2ところで
  3. 3それとも
  4. 4くせに
答案与解析

正确答案：1（むしろ）

「むしろ」用于修正判断，表示“反而、倒不如说”。【译文】这份工作很辛苦，但反而很有价值。

6日本語にほんごは（　　）、韓国語かんこくごも勉強べんきょうしている。

  1. 1別べつとして
  2. 2もちろん
  3. 3ところが
  4. 4たって
答案与解析

正确答案：2（もちろん）

「はもちろん」表示前项当然成立，并进一步补充后项也成立。【译文】日语当然不用说，我也在学韩语。
