N3 语法 · 第 11 单元　原因·目的·结果

学习「せいで」「おかげで」「ように」「ばかりに」等原因目的类句型，掌握归因与目的表达的语感差异。

本单元共 11 个知识点，单元末附自测练习。

知识点详解

1〜せいで・せいか　「都怪～／也许因为～」

【讲解】「せいで」表示不好的结果由前项造成，带有责备或遗憾语气。「せいか」表示原因不确定，语气较委婉，可译为“也许是因为～”。

接续：普通形 ＋ せいで／せいか（な形容词な・名词の ＋ せいで／せいか）

雨あめのせいで、試合しあいが中止ちゅうしになった。

都怪下雨，比赛取消了。

疲つかれているせいか、今日きょうは頭あたまが痛いたい。

也许是因为累了，今天头疼。

辨析：「せいで」多接负面结果；若结果是好事，一般不用「せいで」。

2〜おかげで　「多亏～」

【讲解】「おかげで」表示由于前项的帮助或有利条件，产生了好的结果。也可用于反语，但基础用法是表达感谢和积极原因。

接续：普通形 ＋ おかげで（な形容词な・名词の ＋ おかげで）

先生せんせいのおかげで、試験しけんに合格ごうかくできた。

多亏老师，我通过了考试。

薬くすりを飲のんだおかげで、熱ねつが下さがった。

多亏吃了药，烧退了。

辨析：「せいで」用于负面归因；「おかげで」用于正面归因，语气完全相反。

3〜ために　「由于～」

【讲解】表示原因的「ために」用于说明客观原因，语气较正式。后项多是已经发生的结果，常见于新闻、说明文和书面表达。

接续：普通形 ＋ ために（な形容词な・名词の ＋ ために）

台風たいふうのために、電車でんしゃが止とまった。

由于台风，电车停运了。

事故じこがあったために、道みちが混こんでいる。

由于发生了事故，道路很拥堵。

注意：原因用法的后项通常不是说话人的命令、意志或请求，而是客观结果。

4〜ため（に）　「为了～」

【讲解】表示目的的「ために」说明为了实现前项目标而做后项动作。前项通常是意志动词或名词，且前后主语多为同一主体。

接续：动词辞书形 ＋ ため（に）／名词の ＋ ため（に）

留学りゅうがくするために、お金かねを貯ためている。

为了留学，我正在存钱。

家族かぞくのために、毎日まいにち一生懸命いっしょうけんめい働はたらいている。

为了家人，我每天拼命工作。

辨析：「ために」强调为实现目标而采取行动；「ように」强调为达到某种状态或能力而努力。

5〜ように　「为了能～」

【讲解】目的用法的「ように」表示为了让某状态实现，常接可能形、ない形或无意志动词。它不强调直接行动目标，而强调希望达到的状态。

接续：动词辞书形／ない形 ＋ ように

日本語にほんごが話はなせるように、毎日まいにち練習れんしゅうしている。

为了能说日语，我每天练习。

忘わすれないように、予定よていを紙かみに書かいた。

为了不忘记，我把计划写在纸上。

注意：前项若是「買かう」「行いく」等意志动词目标，用「ために」更自然。

6〜のに　「用于～」

【讲解】「のに」可表示用途或目的，接在动词辞书形后，说明某物、时间或能力用于做什么。常与「使つかう」「必要ひつようだ」「便利べんりだ」等搭配。

接续：动词辞书形 ＋ のに

このはさみは紙かみを切きるのに使つかう。

这把剪刀用于剪纸。

駅えきまで行いくのに三十分さんじゅっぷんかかる。

去车站需要三十分钟。

辨析：逆接的「のに」表示“明明却”；用途的「のに」后面常接评价或使用方式。

7〜あまり　「过于～以致」

【讲解】「あまり」表示由于某种感情、状态过强，导致非理性或意外的结果。前项常是「嬉うれしさ」「心配しんぱい」等情感名词或普通形。

接续：名词の ＋ あまり／普通形 ＋ あまり

母ははは心配しんぱいのあまり、眠ねむれなかった。

妈妈过于担心，以致睡不着。

嬉うれしさのあまり、涙なみだが出でた。

因为太高兴，眼泪流了出来。

注意：「あまり」后的结果多是不寻常或控制不住的反应，不用于普通的因果关系。

8〜ばかりに　「就因为～」

【讲解】「ばかりに」表示仅仅因为前项这个原因，就导致了不好的结果。说话人带有后悔、遗憾或责备语气。

接续：普通形 ＋ ばかりに（な形容词な・名词である ＋ ばかりに）

一言ひとこと言いったばかりに、友達ともだちを怒おこらせてしまった。

就因为说了一句话，我惹朋友生气了。

近道ちかみちをしたばかりに、道みちに迷まよってしまった。

就因为抄了近路，结果迷路了。

辨析：「から」只是普通原因；「ばかりに」强调“小原因导致坏结果”的后悔感。

9〜からには　「既然～」

【讲解】「からには」表示既然已经处于前项情况，就理应承担后项的责任、决心或判断。后项常接「べきだ」「なければならない」「つもりだ」等表达。

接续：普通形 ＋ からには（な形容词である・名词である ＋ からには）

約束やくそくしたからには、必かならず守まもります。

既然约好了，我就一定遵守。

試合しあいに出でるからには、勝かちたい。

既然参加比赛，就想赢。

10〜以上いじょう（は）　「既然～就」

【讲解】「以上いじょうは」与「からには」相近，表示在前项事实成立的前提下，后项自然应当如此。语气较硬，常用于责任、义务和判断。

接续：普通形 ＋ 以上いじょう（は）（な形容词である・名词である ＋ 以上いじょうは）

学生がくせいである以上いじょう、勉強べんきょうするべきだ。

既然是学生，就应该学习。

仕事しごとを引ひき受うけた以上いじょうは、最後さいごまでやります。

既然接下了工作，就会做到最后。

辨析：「以上いじょうは」比「からには」更书面、更强调前提成立后的义务性。

11〜結果けっか　「～的结果」

【讲解】「結果けっか」表示经过前项行为、调查或变化之后，产生了后项结果。常用于说明客观结果，书面语和新闻报道中常见。

接续：动词た形 ＋ 結果けっか／名词の ＋ 結果けっか

みんなで話はなし合あった結果けっか、旅行りょこうを延期えんきすることにした。

大家商量的结果，决定推迟旅行。

検査けんさの結果けっか、大おおきな問題もんだいはなかった。

检查的结果，没有大问题。

✏ 自测练习

1雨あめの（　　）で、運動会うんどうかいは来週らいしゅうになった。

  1. 1せい
  2. 2おかげ
  3. 3ため
  4. 4結果けっか
答案与解析

正确答案：1（せい）

「せいで」表示负面结果的原因。【译文】由于下雨，运动会改到下周了。

2先生せんせいに教おしえてもらった（　　）で、問題もんだいが解とけた。

  1. 1せい
  2. 2ため
  3. 3結果けっか
  4. 4おかげ
答案与解析

正确答案：4（おかげ）

「おかげで」表示多亏前项产生好结果。【译文】多亏老师教我，题解出来了。

3風邪かぜをひかない（　　）、早はやく寝ねています。

  1. 1ように
  2. 2のに
  3. 3ばかりに
  4. 4あまり
答案与解析

正确答案：1（ように）

「ないように」表示为了不发生某状态。【译文】为了不感冒，我早早睡觉。

4この道具どうぐは野菜やさいを切きる（　　）便利べんりです。

  1. 1ように
  2. 2ために
  3. 3のに
  4. 4せいで
答案与解析

正确答案：3（のに）

用途目的的「のに」说明某物用于做什么。【译文】这个工具用于切蔬菜很方便。

5日本にほんへ行いく（　　）、少すこしでも日本語にほんごを勉強べんきょうしたい。

  1. 1せいで
  2. 2からには
  3. 3あまり
  4. 4結果けっか
答案与解析

正确答案：2（からには）

「からには」表示既然前项成立，后项理应如此。【译文】既然要去日本，就想多少学点日语。

6相談そうだんした（　　）、計画けいかくを変かえることにした。

  1. 1せいか
  2. 2ために
  3. 3ばかりに
  4. 4結果けっか
答案与解析

正确答案：4（結果けっか）

「た結果」表示经过前项后产生后项结果。【译文】商量之后，决定改变计划。
