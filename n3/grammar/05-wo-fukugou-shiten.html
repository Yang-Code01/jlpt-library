N3 语法 · 第 5 单元　を系复合助词与视点

学习を中心に、を通じて、向け、上で等表达，掌握中心、媒介、身份、对象与附加关系。

本单元共 11 个知识点，单元末附自测练习。

知识点详解

1を中心ちゅうしんに　「以～为中心」

【讲解】「を中心に」表示以某人、地点、主题或事物作为核心，周围展开活动或分布。常用于说明范围、组织结构、讨论主题。语气中性，书面口语都常用。

接续：名词 ＋ を中心ちゅうしんに（して）／を中心ちゅうしんとして

駅えきを中心ちゅうしんに、店みせが並ならんでいる。

以车站为中心，店铺林立。

若わかい人ひとを中心ちゅうしんに、この歌うたが人気にんきだ。

这首歌以年轻人为中心很受欢迎。

環境かんきょう問題もんだいを中心ちゅうしんに話はなし合あった。

围绕环境问题进行了讨论。

辨析：「について」只是关于主题；「を中心ちゅうしんに」强调该主题是核心，其他内容围绕它展开。

2をはじめ　「以～为首／以及～」

【讲解】「をはじめ」举出最具代表性的一个例子，再暗示还有同类其他对象。常用于正式介绍或列举。后项常出现「多おおくの」「さまざまな」等扩大范围的表达。

接续：名词 ＋ をはじめ（として）

校長こうちょう先生せんせいをはじめ、多おおくの先生せんせいが参加さんかした。

以校长为首，许多老师参加了。

京都きょうとをはじめ、日本にほんには古ふるい町まちが多おおい。

以京都为代表，日本有很多古老城市。

この店みせでは野菜やさいをはじめ、地元じもとの食材しょくざいを使つかっている。

这家店以蔬菜为首，使用当地食材。

注意：「をはじめ」前项应是代表性例子，不适合列举无代表性的普通项目。

3を込こめて　「带着～／倾注～」

【讲解】「を込めて」表示把感情、心意、力量等放进动作或作品中。常接感谢、爱、愿望、心、力等抽象名词。语气温暖郑重，多用于礼物、发言、创作。

接续：名词 ＋ を込こめて

感謝かんしゃの気持きもちを込こめて、手紙てがみを書かいた。

带着感谢的心情写了信。

母ははは愛情あいじょうを込こめて弁当べんとうを作つくった。

母亲满怀爱意做了便当。

選手せんしゅたちは力ちからを込こめて走はしった。

选手们倾注力量奔跑。

4を通つうじて・を通とおして　「通过～／整个～期间」

【讲解】「を通じて／を通して」可表示媒介、手段，也可表示某一期间从头到尾。表示媒介时相当于“通过……了解到、交流”。表示期间时强调整个范围内一直如此。

接续：名词 ＋ を通つうじて・を通とおして

友人ゆうじんを通つうじて、彼かれと知しり合あった。

通过朋友认识了他。

一年いちねんを通とおして、この町まちは観光客かんこうきゃくが多おおい。

一整年这座城市游客都很多。

インターネットを通つうじて、世界せかいの人ひとと交流こうりゅうできる。

通过互联网可以和世界各地的人交流。

辨析：表示媒介时两者多可互换；「を通とおして」更强调经历过程，「を通つうじて」稍书面。

5として　「作为～／以～身份」

【讲解】「として」表示身份、资格、立场或用途，相当于“作为……”。常用于介绍职业、角色、评价标准。它说明“以什么身份或名义”做某事。

接续：名词 ＋ として

彼かれは医者いしゃとして多おおくの人ひとを助たすけた。

他作为医生帮助了很多人。

この部屋へやは教室きょうしつとして使つかわれている。

这个房间被作为教室使用。

親おやとして、子供こどもを守まもりたい。

作为父母，想保护孩子。

注意：「として」表示身份或用途，不表示比较；不要和「にしては」混淆。

6とともに　「和～一起／随着～」

【讲解】「とともに」有“和……一起”的意思，也可表示两个变化同时发生。书面感比「と一緒いっしょに」强。表示变化时，常译为“随着……”。

接续：名词／动词辞书形 ＋ とともに

家族かぞくとともに新あたらしい町まちへ引ひっ越こした。

和家人一起搬到了新的城市。

年としを取とるとともに、考かんがえ方かたも変かわる。

随着年龄增长，想法也会改变。

先生せんせいとともに研究けんきゅうを進すすめた。

和老师一起推进了研究。

辨析：表示共同动作时「と一緒いっしょに」更口语；「とともに」较正式，也能表示同步变化。

7向むけ　「面向～／为～制作」

【讲解】「向け」表示某物、服务、信息是以某对象为目标而制作或提供。常接在人群、市场、等级等名词后。重点是“目标对象是谁”。

接续：名词 ＋ 向むけ

これは子供こども向むけの本ほんです。

这是面向儿童的书。

初心者しょしんしゃ向むけに、易やさしい説明せつめいを用意よういした。

为初学者准备了简单说明。

海外かいがい向むけの商品しょうひんを作つくっている。

正在制作面向海外的商品。

辨析：「向むけ」强调目标对象；「向むき」强调性质适合某对象。儿童向け＝为儿童做；儿童向き＝适合儿童。

8向むき　「适合～」

【讲解】「向き」表示某物的性质、难度、风格适合某类人或用途。它不是强调制作目标，而是强调适配性。常用于评价书、房间、工作、活动等。

接续：名词 ＋ 向むき

この仕事しごとは細こまかい作業さぎょうが好すきな人ひと向むきだ。

这份工作适合喜欢细致作业的人。

この部屋へやは一人暮ひとりぐらし向むきです。

这个房间适合独居。

この映画えいがは子供こども向むきではない。

这部电影不适合儿童。

注意：「向むき」不能直接表示“为某人特别制作”；这种目标用途要用「向むけ」。

9的てき　「～性的／～方面的」

【讲解】「的」接在汉语词后，表示“具有……性质”或“从……角度看”。它可作な形容词使用，也可接「に」作副词。常用于书面语和抽象评价。

接续：汉语名词 ＋ 的てき（な／に）

彼かれはいつも積極的せっきょくてきに話はなす。

他总是积极地说话。

この方法ほうほうは効果的こうかてきだ。

这个方法很有效。

経済的けいざいてきな理由りゆうで旅行りょこうをやめた。

因为经济方面的理由放弃了旅行。

注意：不是所有名词都能随意加「的てき」；应优先记常见固定词，如「具体的ぐたいてき」「基本的きほんてき」。

10上うえで　「在～之后／在～方面」

【讲解】「上で」有两类常见用法：一是“在做完前项之后再做后项”，二是“在某方面”。前者强调前项是必要准备，后者用于范围或角度。书面语中很常用。

接续：动词た形 ＋ 上うえで／名词の ＋ 上うえで

内容ないようを確認かくにんした上うえで、署名しょめいしてください。

请在确认内容之后签名。

生活せいかつの上うえで、睡眠すいみんは大切たいせつだ。

在生活方面，睡眠很重要。

よく考かんがえた上うえで、答こたえを出だした。

在认真考虑之后给出了答案。

辨析：「てから」只表示时间先后；「上うえで」强调前项是后项的前提或准备。

11上うえに　「不仅～而且～」

【讲解】「上に」表示在前项基础上再加上后项，相当于“不仅……而且……”。前后评价通常同方向，都是好事或都是坏事。常用于描述优点叠加或问题加重。

接续：普通形（な形な／名词の）＋ 上うえに

この店みせは安やすい上うえに、おいしい。

这家店不仅便宜，而且好吃。

彼かれは親切しんせつな上うえに、仕事しごとも速はやい。

他不仅亲切，而且工作也快。

今日きょうは雨あめが強つよい上うえに、風かぜも冷つめたい。

今天不仅雨大，而且风也冷。

注意：前后评价方向要一致；一个好一个坏时通常不用「上うえに」。

✏ 自测练习

1市役所しやくしょを中心ちゅうしん（　　）、新あたらしい店みせが増ふえています。

  1. 1に
  2. 2で
  3. 3を
  4. 4として
答案与解析

正确答案：1（に）

「を中心ちゅうしんに」表示以某处为核心展开或分布。【译文】以市政府为中心，新店正在增加。

2感謝かんしゃの気持きもち（　　）込こめて、花はなを送おくった。

  1. 1に
  2. 2を
  3. 3で
  4. 4が
答案与解析

正确答案：2（を）

「を込こめて」表示带着某种心意做事。【译文】满怀感谢之情送了花。

3友達ともだち（　　）通つうじて、この店みせを知しりました。

  1. 1に
  2. 2で
  3. 3を
  4. 4が
答案与解析

正确答案：3（を）

「を通つうじて」表示通过某媒介或中间人。【译文】我通过朋友知道了这家店。

4この本ほんは大人おとな（　　）で、子供こどもには少すこし難むずかしい。

  1. 1的てき
  2. 2上うえ
  3. 3として
  4. 4向むけ
答案与解析

正确答案：4（向むけ）

「向むけ」表示面向某对象制作或提供。【译文】这本书是面向成人的，对孩子来说有点难。

5内容ないようを読よんだ（　　）、質問しつもんしてください。

  1. 1上うえで
  2. 2向むき
  3. 3として
  4. 4をはじめ
答案与解析

正确答案：1（上うえで）

「た形＋上うえで」表示在完成前项之后再做后项。【译文】请在阅读内容之后提问。

6この部屋へやは一人暮ひとりぐらし（　　）だと思おもいます。

  1. 1向むけ
  2. 2向むき
  3. 3を込こめて
  4. 4とともに
答案与解析

正确答案：2（向むき）

「向むき」表示性质适合某类人或用途。【译文】我觉得这个房间适合独居。
