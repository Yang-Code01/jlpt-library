N3 基础 · 03 音便与口语缩约

听懂日剧和日常会话的关键：てる、ちゃう、とく、なきゃ等口语缩约形。

本单元共 6 个知识点，单元末附自测练习。

1 音便复习2 てる・てく3 ちゃう・じゃう4 とく・どく5 なきゃ・なくちゃ6 って与其他自测练习

知识点详解

1音便复习：て形的三类变化

【讲解】五段动词接「て／た」时发生音便，这是 N5 内容，先复习：促音便（う・つ・る→って）、拨音便（ぬ・ぶ・む→んで）、イ音便（く→いて、ぐ→いで）。「行いく」特殊变「行って」。口语缩约都建立在て形之上，音便不熟练则缩约必乱。

类型词尾变化例
促音便う・つ・るって買かう→買って、待まつ→待って、乗のる→乗って
拨音便ぬ・ぶ・むんで死しぬ→死んで、遊あそぶ→遊んで、飲のむ→飲んで
イ音便く・ぐいて・いで書かく→書いて、泳およぐ→泳いで
无音便すして話はなす→話して

2てる（＝ている）・てく（＝ていく）

【讲解】口语中「ている」的「い」几乎总是脱落说成「てる」，「ていく」缩为「てく」。礼貌体同样适用：「しています→してます」。这是最高频的缩约，听力中默认按缩约形出现。

缩约：～ている → ～てる／～でいる → ～でる／～ていく → ～てく

今いま何なにしてるの？

你现在在干什么？（＝何をしているの）

雨あめ、まだ降ふってる？

雨还在下吗？（＝降っている）

先さきに持もってくね。

我先拿过去啦。（＝持っていく）

3ちゃう・じゃう（＝てしまう・でしまう）

【讲解】「てしまう」表示动作彻底完成或遗憾懊悔，口语缩为「ちゃう」；拨音便动词的「でしまう」缩为「じゃう」。过去形是「ちゃった／じゃった」。语气随语境可以是"不小心～了"也可以是"干脆做完"。

缩约：～てしまう → ～ちゃう／～でしまう → ～じゃう

ケーキを全部ぜんぶ食たべちゃった。

把蛋糕全吃光了。（＝食べてしまった）

大事だいじなメールを消けしちゃった。

不小心把重要邮件删掉了。

財布さいふを家いえに忘わすれて、困こまっちゃう。

钱包忘在家里了，真伤脑筋。

注意：「飲んでしまう→飲んじゃう」，拨音便系列一律用「じゃう」，不要写成「飲んちゃう」。

4とく・どく（＝ておく・でおく）

【讲解】「ておく」表示事先准备或维持现状，口语缩为「とく」；「でおく」缩为「どく」。常见形式：「買っとく（先买好）」「言っとくけど（先说好）」。命令形「といて」也极常用。

缩约：～ておく → ～とく／～でおく → ～どく

ビールを冷ひやしといたよ。

啤酒已经先冰好了哦。（＝冷やしておいた）

ホテルを予約よやくしとくね。

我先把酒店订好哈。

そのままにしといて。

就那样放着别动。（＝しておいて）

5なきゃ・なくちゃ（＝なければ・なくては）

【讲解】表示义务的「なければならない／なくてはいけない」，口语中常缩成「なきゃ（ならない）」「なくちゃ（いけない）」，句尾的「ならない・いけない」经常整个省略，只说「行かなきゃ！」就是"必须走了"。

缩约：～なければ → ～なきゃ／～なくては → ～なくちゃ

もう帰かえらなきゃ。

我得回去了。（＝帰らなければならない）

明日あしたまでに宿題しゅくだいをやらなくちゃ。

明天之前必须把作业做完。

辨析：「てはいけない」的缩约是「ちゃいけない」（禁止别人）；「なくちゃいけない」是义务（自己必须做），形近义反，注意区分。

6って（＝と・という）与其他高频缩约

【讲解】「って」在口语中可代替引用的「と」「という」「というのは」：「田中たなかさんって人ひと」＝叫田中的人；「何なんだって？」＝你说什么？另外还有：ら抜き（食たべられる→食べれる，口语常见但书面不规范）、「んだ」（＝のだ）、「じゃ」（＝では）。

彼かれ、来こないって。

他说他不来了。（＝来ないと言った）

JLPTって何なんですか。

JLPT 是什么？（＝JLPTというのは）

それじゃ、また明日あした。

那么，明天见。（＝それでは）

注意：作文和正式邮件中应使用完整形；缩约形用于会话、聊天和小说对白。听力考试两种形式都会出现。

自测练习

1「宿題しゅくだいをやっとく」的完整形是？

  1. 1やっている
  2. 2やってしまう
  3. 3やっておく
  4. 4やっていく
答案与解析

正确答案：3（やっておく）

「とく」是「ておく」的缩约，表示事先做好。

2「電車でんしゃに乗のり遅おくれ（　　）」——"不小心没赶上电车"，空格填？

  1. 1ちゃった
  2. 2とった
  3. 3てった
  4. 4じゃった
答案与解析

正确答案：1（ちゃった）

「てしまった→ちゃった」表示遗憾。「遅れて」是て结尾，用ちゃ系而非じゃ系。

3「全部ぜんぶ飲のんでしまった」的口语缩约是？

  1. 1飲んちゃった
  2. 2飲みちゃった
  3. 3飲んじゃった
  4. 4飲んどいた
答案与解析

正确答案：3（飲んじゃった）

拨音便「んで」系列缩约用「じゃ」：飲んで＋しまった→飲んじゃった。

4もう遅おそいから帰かえら（　　）。

  1. 1ちゃう
  2. 2なきゃ
  3. 3とく
  4. 4てる
答案与解析

正确答案：2（なきゃ）

「帰らなければならない」缩约为「帰らなきゃ」。【译文】已经很晚了，我得回去了。

5「山田やまださん（　　）どんな人ひと？」——"山田是个什么样的人？"

  1. 1とは限かぎらない
  2. 2っけ
  3. 3んだ
  4. 4って
答案与解析

正确答案：4（って）

「って」提起话题，相当于「というのは／という人は」。

6「まだ雨あめ降ふってる？」中「降ってる」的完整形是？

  1. 1降っておく
  2. 2降っている
  3. 3降ってある
  4. 4降ってしまう
答案与解析

正确答案：2（降っている）

「てる」是「ている」省略「い」的缩约形。
