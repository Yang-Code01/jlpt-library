N3 基础 · 02 自动词与他动词

系统整理自他动词概念、常见成对规律与 N3 必会对照总表。

本单元共 5 个知识点，单元末附自测练习。

1 概念与助词2 成对规律3 对照总表4 ている与てある5 无对与兼用✏ 自测练习

知识点详解

1概念与助词搭配

【讲解】他动词表示某人有意作用于对象，宾语用「を」标记：「ドアを開あける」；自动词表示事物自身发生变化或状态，主体用「が」标记：「ドアが開あく」。中文里"开门／门开了"的区别与此对应，但日语用不同的动词形态区分，必须成对记忆。

私わたしは電気でんきをつけた。

我打开了灯。（他动词）

電気でんきがついた。

灯亮了。（自动词）

注意：移动动词「歩あるく・飛とぶ・渡わたる」等经过的场所用「を」（橋はしを渡る），它们仍是自动词，不要因「を」而误判。

2成对动词的形态规律

【讲解】多数自他成对动词共享词根，可按词尾规律分组记忆。以下规律覆盖大部分 N3 词对：

规律A：-aru（自）↔ -eru（他）：上あがる／上あげる、集あつまる／集あつめる
规律B：-u（自）↔ -eru（他）：開あく／開あける、届とどく／届とどける
规律C：-eru（自）↔ -u（他）：売うれる／売うる、折おれる／折おる
规律D：-reru（自）↔ -su（他）：倒たおれる／倒たおす、汚よごれる／汚よごす
规律E：-る（自）↔ -す（他）：直なおる／直なおす、戻もどる／戻もどす、出でる／出だす
辨析：「す」结尾的基本都是他动词；「～まる」结尾的基本都是自动词——考场上可用这两条快速判断。

4自他动词与「ている／てある」

【讲解】描述眼前状态时：自动词＋ている 单纯陈述状态；他动词＋てある 暗示有人为了某目的而做，结果保留着。这是 N3 考试最爱考的组合。

窓まどが開あいている。

窗户开着。（只描述状态）

窓まどが開あけてある。

窗户开着。（有人特意打开的）

辨析：他动词＋ている 表示动作正在进行：「彼かれが窓を開けている」＝他正在开窗。三者务必分清。

5无对动词与自他兼用动词

【讲解】并非所有动词都成对：「行いく・来くる・泣なく」只有自动词用法；「食たべる・読よむ・買かう」只有他动词用法。少数动词自他同形，如「開ひらく」（店みせが開く／店を開く）、「吹ふく」（風かぜが吹く／笛ふえを吹く）。

注意：没有成对他动词时，日语用使役形表达"使～"：泣く→泣かせる（惹哭）。这部分在语法「使役」单元详细学习。

✏ 自测练习

1あ、電気でんきが（　　）よ。消けしましょうか。

  1. 1ついている
  2. 2つけている
  3. 3ついてある
  4. 4つけった
答案与解析

正确答案：1（ついている）

描述灯亮着的状态用自动词「つく」＋ている。【译文】啊，灯亮着呢。要不要关掉？

2寒さむいので、窓まどを（　　）ください。

  1. 1閉まって
  2. 2閉めて
  3. 3閉まりて
  4. 4閉められて
答案与解析

正确答案：2（閉めて）

「窓を」提示需要他动词「閉める」。【译文】有点冷，请把窗户关上。

3かばんの中なかから鍵かぎが（　　）。

  1. 1見つけた
  2. 2見つけてある
  3. 3見つかった
  4. 4見つける
答案与解析

正确答案：3（見つかった）

「鍵が」提示自动词「見つかる」。【译文】在包里找到了钥匙。

4お湯ゆが（　　）から、お茶ちゃをいれよう。

  1. 1沸かした
  2. 2沸けた
  3. 3沸かれた
  4. 4沸いた
答案与解析

正确答案：4（沸いた）

「お湯が」提示自动词「沸く」。【译文】水开了，泡茶吧。

5会議かいぎの資料しりょうが机つくえに並ならべて（　　）。準備じゅんびはもういいようだ。

  1. 1ある
  2. 2いる
  3. 3おく
  4. 4みる
答案与解析

正确答案：1（ある）

他动词「並べる」＋てある表示有人准备好的状态。【译文】会议资料已摆放在桌上，看来准备好了。

6下面哪个动词是自动词？

  1. 1壊こわす
  2. 2倒たおれる
  3. 3減へらす
  4. 4沸わかす
答案与解析

正确答案：2（倒れる）

「す」结尾的壊す・減らす・沸かす都是他动词；「倒れる」（倒下）是自动词。
