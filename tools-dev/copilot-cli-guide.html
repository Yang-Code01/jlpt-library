① 启动与会话

如何启动 CLI、登录、管理会话与工作目录。启动参数和子命令完整表格在本章末尾。

copilot（启动）入门
用途
在当前目录启动交互式会话；也可以带提示启动或在脚本里一次性执行。
语法 / 子命令
copilot [选项]
copilot -i "提示"　（交互模式并立即执行该提示）
copilot -p "提示" [--allow-all-tools] [-s]　（非交互，执行完退出）
典型示例
copilot
copilot -C D:\work\repo --model auto
copilot -p "总结这个仓库" --allow-all-tools -s > summary.md
copilot --continue　（接着上次会话）
相关配置 / 快捷键
完整参数见 启动参数表；默认模型由设置 model / 环境变量 COPILOT_MODEL 决定。
易混淆点
-i 进入交互界面并执行；-p 不进界面、执行完即退出，需要 --allow-all-tools（或 --yolo）才能让工具自动运行。-s 只输出回答，适合管道。
/login入门
用途
登录 GitHub 账号以使用 Copilot。
语法 / 子命令
/login
shell：copilot login [--host HOST] [--web-flow | --device-code | --with-token]
典型示例
copilot login --device-code
相关配置 / 快捷键
环境变量 COPILOT_GITHUB_TOKEN > GH_TOKEN > GITHUB_TOKEN 存在时优先于已保存的登录；GHE 用 GH_HOST / COPILOT_GH_HOST。
易混淆点
没有系统钥匙串时 token 默认不落盘，可用设置 storeTokenPlaintext 允许明文存入 config.json（不推荐）。
/logout进阶
用途
登出当前 OAuth 登录。
语法 / 子命令
/logout
易混淆点
通过环境变量提供的 token 不受 /logout 影响，需要自行取消环境变量。

典型示例

/new别名：/clear、/reset入门
用途
开始一个新对话（新会话）。
语法 / 子命令
/new [首条提示]
/new worktree [提示]　（在新 git worktree 中开空会话，当前会话保持不变）
典型示例
/new 帮我看一下 README
相关配置 / 快捷键
会话上限计数（/limits）在 /new、/clear 后重置已用量，但保留上限值。
易混淆点
1.0.100 的 /help 把 /new（开始新对话）和 /clear（放弃当前会话重新开始）分开列出；官方文档称 /clear、/new、/reset 互为别名。旧会话仍可通过 /resume 找回（未核实是否所有情况都保留）。

/rename [名称]
典型示例
/rename 登录模块重构
相关配置 / 快捷键

/fork别名：/branch进阶
用途
把当前会话分叉成一个新会话（保留上下文）；原会话可继续在后台运行。
语法 / 子命令
/fork [名称]
/fork worktree　（分叉到基于当前分支 HEAD 的新 worktree）
典型示例
/fork 方案B尝试
相关配置 / 快捷键
worktree 位置由 worktreePathTemplate 决定。
易混淆点
/fork 复制上下文；/new 是空白会话。
/worktree进阶
用途
新建一个 git worktree 并切换进去，未提交的改动留在原工作区。
语法 / 子命令
/worktree [分支名 | 任务描述]
（旧写法 /worktree new 已弃用，改用 /new worktree）
典型示例
/worktree feature/login
/worktree 实现导出 CSV 功能
相关配置 / 快捷键
worktreeBaseRef：head（默认，从当前检出）或 defaultBranch（从远端默认分支）；worktreePathTemplate：如 ~/src/worktrees/{repo}/{branch}。
易混淆点
/worktree 把改动留下；/move 把未提交改动带走。需要 Git 仓库。
/move进阶
用途
把当前未提交的改动移动到一个新的 git worktree 并切换过去。
语法 / 子命令
/move [分支名 | 任务描述]
典型示例
/move fix/typo
相关配置 / 快捷键
同 /worktree 的两个设置。
易混淆点
与 /worktree 的区别：/move 会带走未提交改动。

/exit别名：/quit入门
用途
关闭当前会话；若还有别的会话在运行则切到最新的那个，最后一个会话时退出 CLI。
语法 / 子命令

典型示例

相关配置 / 快捷键
Ctrl+C 两次 / Ctrl+D 也可退出；代理运行中可用 Ctrl+Q 把 /exit 排队。

用途

语法 / 子命令
/restart
相关配置 / 快捷键

/keep-alive别名：/caffeinate进阶
用途

语法 / 子命令

设置入口之间的关系（都改的是同一批设置）
  • /settings（= /config）不带参数：打开可搜索的设置界面，适合“不知道有什么可改”时浏览。分 User / Repo / Repo (local) / Problems 四页。
  • /settings 键 值：会话内一行改完；/settings 键 显示可选值；/settings show 键 看当前值；/settings unset 键 删除。
  • copilot config 键 值：在 shell 里改（不用进 CLI）；copilot config --list 列出全部；列表型设置用 copilot config allowedUrls github.com 追加、--rm 删除。
  • 专用命令：/model、/statusline、/theme、/memory、/vim、/keep-alive、/subagents、/sandbox 等，本质上都是写入对应设置键。
  • 直接编辑文件：用户 ~/.copilot/settings.json；仓库共享 .github/copilot/settings.json（--repo）；仓库本地不提交 .github/copilot/settings.local.json（--local）。在设置界面按 Ctrl+E 也能打开。
  • ~/.copilot/config.json 只存内部状态，不要在里面写设置（会被忽略）。
优先级（后者覆盖前者）：内置默认值 → 组织 MDM 策略 → 用户 ~/.copilot/settings.json → 仓库 .github/copilot/settings.json → 本地 .github/copilot/settings.local.json → 环境变量 → 命令行参数。
仓库级只能覆盖这些键：companyAnnouncements、contextTier、deniedUrls、disableAllHooks、disabledMcpServers、disabledSkills、effortLevel、enabledPlugins、extraKnownMarketplaces、hooks、includeCoAuthoredBy、mergeStrategy、model、respectGitignore（其中 deniedUrls / disabled* 为并集只增不减，respectGitignore 只能收紧）。
仓库还可用 .github/allowed_models.txt 限定模型：每行一个模型 ID 或通配（如 claude-sonnet-*），必须恰好一行 fallback: 模型ID，# 为注释。（来源：官方 config-dir 文档）

环境变量（来源：copilot help environment）
变量作用
COPILOT_HOME配置与状态目录，默认 $HOME/.copilot
COPILOT_MODEL默认模型（被 --model、/model 覆盖）
COPILOT_AUTO_TIERAuto 模型路由偏好
COPILOT_GITHUB_TOKEN / GH_TOKEN / GITHUB_TOKEN认证 token（按此优先级），优先于已保存凭据
GH_HOST / COPILOT_GH_HOSTGitHub 主机名（GHE）；后者只影响 Copilot CLI
COPILOT_ALLOW_ALL允许所有工具；值恰好为 "true" 时还会信任工作目录（加载其 skills/插件/MCP/hooks）
COPILOT_AUTO_UPDATE"false" 关闭自动更新；CI 环境默认关闭
COPILOT_CLI_VERSION覆盖用于更新比较的版本号
COPILOT_CUSTOM_INSTRUCTIONS_DIRS额外的指令搜索目录（逗号分隔）
COPILOT_EDITOR / VISUAL / EDITOR外部编辑器命令（Ctrl+G、编辑计划）
COPILOT_MULTIPLEXER覆盖终端复用器识别：tmux / herdr / none
COPILOT_OFFLINE"true" 离线模式，需要本地模型提供方
COPILOT_PROVIDER_*BYOK 自带模型：BASE_URL、TYPE、API_KEY、API_KEY_COMMAND、BEARER_TOKEN、WIRE_API、TRANSPORT、AZURE_API_VERSION、MODEL_ID、WIRE_MODEL、MAX_PROMPT_TOKENS、MAX_OUTPUT_TOKENS、HEADERS（详见 copilot help providers）
HTTP_PROXY / HTTPS_PROXY / NO_PROXY代理设置（大小写均可），优先于设置 proxyUrl
NO_COLOR关闭颜色
PLAIN_DIFF"true" 关闭富文本 diff
USE_BUILTIN_RIPGREP"false" 使用 PATH 中的 ripgrep
USE_TGREP / TGREP_FILE_COUNT_THRESHOLD / USE_TGREP_WARM_STARTtgrep 索引搜索开关、自动启用的文件数阈值（Windows 默认 10,000）、启动时等待索引
COPILOT_OTEL_* / OTEL_*OpenTelemetry 监控（详见 copilot help monitoring）
COPILOT_DISABLE_TERMINAL_TITLE禁止更新终端标题（来源：copilot help config）
COPILOT_INLINE_IMAGE_LIMIT / COPILOT_INLINE_IMAGES_HERDR内联图片数量上限 / herdr 中启用内联图片（来源：copilot help config）
COPILOT_PROXY_KERBEROS_SPNKerberos 代理 SPN，优先于设置项（来源：copilot help config）
COPILOT_ASSISTED_APPROVAL等同 --assisted-approval（来源：copilot --help）
COPILOT_ENABLE_INTERRUPTED_SESSION_RESTORE"1" 恢复被中断的会话（来源：官方文档，未核实）
