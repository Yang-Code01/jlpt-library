术语速查

词本页的用法
包（package）pi 用 `pi install` 装进来的 npm 包或本地路径包，靠 package.json 的 `pi` 字段声明要加载什么。
扩展（extension）包（或 <PI_HOME>/extensions/）导出的代码，给 pi 加工具、改界面、拦事件。一个包可以带多个扩展。
插件（plugin）口语词，本页不用它做技术分类：一个包可能同时带扩展、技能和 prompt。
MCP server外部进程，按 Model Context Protocol 把工具暴露给 pi；本机由适配器包接管，不走 pi 内置实现。
技能（skill）一段带 frontmatter 的 SKILL.md，模型按需加载；来源可以是用户目录、pi 自带目录，或某个包。
工具（tool）模型在会话里能直接调用的函数。可能由 pi 核心提供，也可能由某个包注册。
真源 / 生成物真源是 data.json（手改这个）；生成物是这一页（重跑生成器才变）。

这份页怎么更新

这一页是生成物，不要直接改 tools-dev/pi-toolchain.html。真源只有一份：tools-dev/pi-toolchain.data.json。

  1. 改真源：新增一个包就往 items 里加一条，id 必须唯一且与页内锚点同名；src 一律写成 ~/、<PI_HOME>、<REPO>、<USER> 这类占位符，不许写真实路径。
  2. 重生成：node tools/pi-toolchain-gen.mjs。
  3. 校验：node tools/pi-toolchain-gen.mjs check，再跑 node tools/test.mjs。
  4. 新增包要同时动三处：真源的 items 与 packages、collectedAt 日期、以及包版本变化时的 version/versionFrom。

采集于 2026-10-24，对应 pi 核心 1.4.0。内容随版本变化：重跑生成器即刷新。
